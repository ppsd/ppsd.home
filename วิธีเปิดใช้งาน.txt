========================================================
   PPSD Construction ERP — วิธีเปิดใช้งาน (Windows)
========================================================

ครั้งแรกสุด (ติดตั้ง Node.js ก่อน 1 ครั้ง)
--------------------------------------------------------
1) ติดตั้ง Node.js จาก https://nodejs.org  (กดปุ่ม LTS สีเขียว)
2) แตกไฟล์ ZIP ของระบบไว้ในโฟลเดอร์ที่ต้องการ (เช่น C:\PPSD)
   * ให้ไฟล์ .bat ทั้งหมดอยู่ในโฟลเดอร์เดียวกับ package.json


ไฟล์ที่ใช้ (ดับเบิลคลิกได้เลย)
--------------------------------------------------------
▶ start.bat
   เปิดใช้งานบนเครื่องนี้แบบง่ายสุด — ติดตั้ง+build+เปิดเซิร์ฟเวอร์
   แล้วเปิดเบราว์เซอร์ให้อัตโนมัติ  (ใช้ตอนอยากเปิดเอง)

▶ allow-network.bat   (รันครั้งแรกครั้งเดียว, คลิกขวา > Run as administrator)
   เปิดพอร์ตให้มือถือ/เครื่องอื่นในวง LAN เข้าใช้งานได้
   เครื่องอื่นเปิดเบราว์เซอร์ไปที่  http://192.168.x.x:3001
   (เลข IP จะโชว์ตอนรัน)

▶ install-autostart.bat   ★ ตั้งให้เปิดเองตอนเปิดเครื่อง ★
   ตั้งค่าให้เซิร์ฟเวอร์เปิดเองอัตโนมัติทุกครั้งที่ล็อกอินเข้าเครื่องนี้
   และถ้าเซิร์ฟเวอร์ดับ จะเปิดใหม่ให้เองอัตโนมัติ
   * ทำครั้งเดียว, เครื่องนี้ต้องเป็น "เครื่องเซิร์ฟเวอร์กลาง" ที่เปิด+ล็อกอินค้างไว้

▶ uninstall-autostart.bat
   ยกเลิกการเปิดเองตอนบูต

▶ run-server.bat
   เปิดเฉพาะเซิร์ฟเวอร์ (ไม่เปิดเบราว์เซอร์) + รีสตาร์ทเองถ้าดับ
   (ตัวนี้คือตัวที่ install-autostart เรียกใช้)

▶ update.bat   ★ รันหลังอัปเดตเวอร์ชันใหม่ ★
   หลังแตกไฟล์ ZIP เวอร์ชันใหม่ทับของเดิม ให้ดับเบิลคลิกไฟล์นี้ 1 ครั้ง
   เพื่อ build เป็นเวอร์ชันล่าสุด (ข้อมูลเดิมไม่หาย)


ตั้งเป็นเครื่องเซิร์ฟเวอร์กลาง (แนะนำ) — ทำตามนี้
--------------------------------------------------------
1) ดับเบิลคลิก  install-autostart.bat   (กด Yes เมื่อขอสิทธิ์ผู้ดูแล)
2) ดับเบิลคลิก  allow-network.bat        (คลิกขวา > Run as administrator)
3) จำเลข http://192.168.x.x:3001 ไปให้เครื่อง/มือถือคนอื่นในบริษัท
4) เครื่องนี้เปิดทิ้งไว้ + ล็อกอินค้างไว้ตลอด


⚠ สำคัญมาก — สำรองข้อมูลออกนอกเครื่อง
--------------------------------------------------------
ระบบสำรองข้อมูลอัตโนมัติทุกวันไว้ที่  server\data\backups
แต่ถ้าเครื่องนี้พัง/หาย ข้อมูลจะหายหมด!
=> ควรก๊อปโฟลเดอร์ server\data ไปเก็บที่อื่นสม่ำเสมอ
   (External Drive / Google Drive / เครื่องอื่น)
หรือกดปุ่ม "สำรองข้อมูล" ในหน้าผู้ใช้งาน แล้วเก็บไฟล์ไว้ที่ปลอดภัย


ปัญหาที่พบบ่อย
--------------------------------------------------------
- เปิดไม่ขึ้น / ปิดไปเอง : ดูว่าติดตั้ง Node.js แล้วหรือยัง
- เครื่องอื่นเข้าไม่ได้   : รัน allow-network.bat (as administrator) +
                          ทุกเครื่องต้องอยู่ Wi-Fi/LAN วงเดียวกัน
- ลืม PIN                : กด "ลืม PIN?" ที่หน้าเข้าสู่ระบบ แล้วให้แอดมินอนุมัติ

- เปิดเครื่องแล้วไม่รันเอง :
    1) รัน install-autostart.bat อีกครั้ง (จะสร้างตัวเปิดใน Startup ให้)
    2) ตรวจว่ามีตัวเปิดจริง: กด Win+R พิมพ์  shell:startup  กด Enter
       ต้องเห็นไฟล์ "PPSD ERP Server" อยู่ในโฟลเดอร์นั้น
       (ถ้าไม่มี ให้ลากไฟล์ run-server.bat มาวาง > คลิกขวา > Create shortcut here)
    3) การเปิดเองจะทำงาน "ตอนล็อกอิน" เท่านั้น -> เครื่องต้องล็อกอินค้างไว้
       ถ้าอยากทดสอบ: ล็อกออฟแล้วล็อกอินใหม่ หรือรีสตาร์ทเครื่อง
    4) ถ้ายังไม่ขึ้น ให้เปิดเองด้วย start.bat ไปก่อน แล้วแจ้งผู้พัฒนา
