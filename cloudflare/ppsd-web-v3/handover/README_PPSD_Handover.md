## 1. สรุปสั้น ๆ ก่อนเริ่ม

- เว็บต้นแบบใหม่เสร็จถึง **เวอร์ชัน 3.1** แล้ว ดูออนไลน์ได้ที่ https://claude.ai/artifact/QA6MY8h4jPpJDxRNLUSPWp
- เว็บที่ลูกค้าเห็นตอนนี้ยังเป็น **เว็บเดิม** https://ppsd-web.pages.dev/ เพราะเว็บต้นแบบยังไม่ได้ขึ้นแทน
- ผู้บริหาร (พี่แมน) สั่งแก้มาล่าสุด **9 ข้อ** แก้แล้วบางส่วน (ดูหัวข้อ 1.1) ข้อที่เหลือต้องรอคำตอบ ดูชีต **Management Feedback** และ **Decisions**
- คำสั่งที่สำคัญที่สุด: **“แก้ระบบไม่ต้องทำอะไรทั้งนั้น เอาแบบเดิม”** ระหว่างนี้ให้ทำเฉพาะหน้าเว็บ (ข้อความ เมนู Header ดีไซน์) ห้ามพัฒนาระบบหลังบ้านหรือ ERP เพิ่ม จนกว่าจะยืนยันกับผู้บริหาร
- ส่วนที่ต้องเก็บข้อมูล (ฟอร์ม บ้านของฉัน หลังบ้าน) ยังเป็น **Mockup** คือเก็บข้อมูลไว้ในเบราว์เซอร์ ไม่ได้ส่งไปที่ไหน

## 3. วันแรก: ทำอะไรก่อน

1. อ่านไฟล์นี้ให้จบ
2. เปิด Excel ตามลำดับชีต: **Project Overview → Management Feedback → Decisions → Pending Tasks → Next Steps**
3. เปิดเว็บในเครื่องตามหัวข้อ 4 แล้วลองกดดูทุกเมนู
4. ขอสิทธิ์เข้าถึง Canva “งานฟรีม”, Drive “งานฟิล์ม”, repo GitHub `ppsd/ppsd.home` และ LINE OA (ชีต Files & Links)
5. นัดผู้บริหารเพื่อถามเรื่องที่ติดสถานะ **Need Confirmation** โดยเฉพาะขอบเขต “ระบบเอาแบบเดิม” และผังเมนูใหม่
6. กรอกชื่อผู้รับผิดชอบและกำหนดส่งในชีต **Next Steps** (ช่องสีเหลือง)

## 4. วิธีเปิดเว็บไซต์ในเครื่อง

ต้องมี Python 3 (ใช้ทำ web server ง่าย ๆ)

```bash
cd 01_Website_Source_v3
python3 -m http.server 8765
```

แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:8765/

- ต้องเปิดผ่าน server แบบนี้ **ห้ามดับเบิลคลิก `index.html`** เพราะบางส่วนโหลดไฟล์ด้วย fetch
- หน้า “ห้องรวมไอเดีย” และปุ่ม AI ออกแบบ เรียก API ของเว็บเดิม เปิดในเครื่องแล้วจะขึ้น 404 ซึ่งเป็นเรื่องปกติ
- หลังบ้านเข้าที่ http://localhost:8765/#admin (เลือกบทบาทเพื่อเข้า เป็นแค่ต้นแบบ)
- บ้านของฉันเข้าที่ `#myhome` แล้วกดปุ่ม “ดูตัวอย่าง” เพื่อดูด้วยบ้านสมมติ

## 5. วิธีแก้ไขเว็บไซต์

เว็บเขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มี build step แก้ไฟล์แล้วรีเฟรชเบราว์เซอร์ก็เห็นผลทันที

| อยากแก้อะไร | ไปที่ไฟล์ |
|---|---|
| ข้อความหน้าแรก (Hero) | `js/data.js` → `I18N.th.heroH1`, `heroBy`, `heroSub` และ `<title>` ใน `index.html` |
| ชื่อเมนูหลัก | `js/data.js` → `I18N.th.m1` … `m5` (ภาษาอังกฤษอยู่ที่ `I18N.en`) |
| เมนูย่อย | `js/data.js` → `P.NAV` (รูปแบบ `['route', 'ชื่อไทย', 'English']`) |
| Header / Dropdown / Sticky / Transparent | `js/core.js` → `renderHeader()`, `onScroll()`, `route()` และ `css/site.css` ส่วน `/* header */` |
| สีและดีไซน์ | `css/site.css` (ตัวแปรสีใน `:root`) และ `css/grand.css` |
| เนื้อหาหน้าต่าง ๆ | `js/pages.js` (ค้นหา `R.ชื่อหน้า`) · เครื่องคำนวณอยู่ใน `js/tools.js` |
| ข้อมูลบริษัท ราคาแพ็กเกจ ตารางวัสดุ | `js/data.js` → `P.CO`, `P.PKG`, `P.SPEC` |
| แบบบ้าน | `js/designs.js` |

ตัวอย่าง: ชื่อเมนู “รับออกแบบบ้าน” อยู่ที่ค่า `m2` ใน `I18N.th` ของ `js/data.js` (ถ้าต้องเปลี่ยนชื่อ ให้แก้ breadcrumb ใน `js/pages.js` ด้วย ค้นคำว่า `รับออกแบบบ้าน`)

แต่ละหน้าอยู่ไฟล์ไหนดูได้ที่ชีต **Website Structure** คอลัมน์ “ไฟล์โค้ด”

## 6. วิธีทดสอบหลังแก้

```bash
pip install playwright

# เปิด server ตามหัวข้อ 4 ไว้ก่อน แล้วรันในอีกหน้าต่าง

python3 05_QA_Tests/func.py    # ทดสอบการทำงาน 74 ข้อ
```

## 7. ข้อควรระวัง

- **ห้ามแต่งข้อมูลสำคัญ** เช่น เบอร์โทร ที่อยู่ ราคา ยี่ห้อ ชื่อพนักงาน หรือรีวิว ถ้าไม่มีข้อมูลให้ถามผู้บริหาร
- **ห้ามแก้หรือลบข้อมูลใน ERP** ที่พนักงานใช้อยู่ และตามคำสั่งล่าสุดไม่ต้องพัฒนาระบบเพิ่ม
- **repo `ppsd/ppsd.home`** ต้องทำตามกฎใน `CLAUDE.md` ของ repo ได้แก่ ห้ามแตะหรือ commit `server/data` (ppsd.sqlite, files, backups, secret.key), commit บน branch `dev/…`, เขียนข้อความ commit เป็นภาษาไทย, รัน `npm run build` ก่อน push, ห้าม force push, ห้ามลบ branch และห้ามพิมพ์ secret
- **บ้านของฉัน** เป็นข้อมูลส่วนตัว ก่อนเปิดใช้จริงต้องตั้ง `MH_DEMO_ACCESS = false` ใน `js/portal.js`
- **หลังบ้าน** ต้องไม่มีลิงก์ให้ลูกค้าเห็น
- **LINE OA** ใช้เป็นปุ่มติดต่อเท่านั้น ไม่ทำเป็นเมนูแยก ไม่มีแชทในเว็บ และไม่แสดง Rich Menu ซ้ำบนเว็บ
- **ภาพ:** ภาพจำลองต้องติดป้าย “ภาพจำลองแนวคิด” ห้ามนำภาพจาก Pinterest มาใช้ และห้ามใช้รูปบัตรประชาชนที่อยู่ใน Drive
- **Canva ขัดกับเว็บ:** ให้สรุปจุดที่ต่างแล้วถามก่อนเปลี่ยน ตอนนี้มีเรื่องที่ขัดกันอยู่ เช่น สีกรมท่าในบางหน้า ราคาแพ็กเกจ และจำนวนเมนู
- **โลโก้:** ใช้ไฟล์ `.ai` เป็นต้นฉบับ ถ้าต้องการไฟล์ SVG สำหรับเว็บให้ export จาก `.ai`

## 8. สิ่งที่ยังขาด และต้องขอเพิ่ม

- คำตอบจากผู้บริหารในทุกข้อที่ติด **Need Confirmation** (ชีต Pending Tasks และ Management Feedback)
