## 2. เริ่มในบัญชีใหม่

1. ดาวน์โหลดทุกไฟล์ในโฟลเดอร์นี้จาก Google Drive
2. เปิดแชทใหม่ใน Claude แนบไฟล์ทั้งหมด — อย่างน้อยต้องมีไฟล์ .md ทั้งหมด + `ppsd-website-v2-code.zip`
3. สั่งให้อ่าน `README_MIGRATION.md` → `PROJECT_MASTER_CONTEXT.md` → `DEVELOPMENT_STATUS.md` และแตก zip ตรวจ Source Code ก่อนแก้
4. ให้สรุปความเข้าใจและสิ่งที่ขาดก่อน แล้ว **รออนุมัติก่อนแก้โค้ด**

## 3. เปิดเว็บต้นแบบในเครื่อง

```bash
unzip ppsd-website-v2-code.zip          # ได้โฟลเดอร์ ppsd-website/
# ถ้ามีไฟล์รูป (img) แยก ให้แตกลง ppsd-website/site/img/
cd ppsd-website/site
python3 -m http.server 8765
# เปิด http://localhost:8765/index.html
```

- ไม่มี build step · ต้องเปิดผ่าน server (เปิดไฟล์ตรงๆ แบบ file:// บางส่วนจะไม่ทำงาน)
- ห้องรวมไอเดีย/AI ออกแบบจะได้ 404 ในเครื่อง เพราะ API อยู่บนเว็บเดิม — ปกติ
- ล้างข้อมูลจำลอง: หลังบ้าน → ผู้ใช้และสิทธิ์ → “ล้างข้อมูลตัวอย่างทั้งหมด” หรือ `localStorage.clear()`

## 4. รันชุดทดสอบ

```bash
pip install playwright && python3 -m playwright install chromium
# เปิด server ตามข้อ 3 ไว้ก่อน แล้วในอีกหน้าต่าง:
cd ppsd-website/qa
python3 run.py     # 45 เส้นทาง × 2 ขนาดจอ: JS error + เลื่อนแนวนอน
python3 func.py    # ทดสอบการทำงาน 51 ข้อ
```

สคริปต์ตั้ง `executable_path='/usr/bin/google-chrome'` ไว้ ถ้าเครื่องไม่มีให้ลบพารามิเตอร์นี้ออกเพื่อใช้ Chromium ของ Playwright

## 5. ข้อควรระวังก่อนใช้งานจริง

- หลังบ้าน (`#admin`) ในต้นแบบไม่มีรหัสผ่านจริง ห้ามใช้กับข้อมูลลูกค้าจริงจนกว่าจะทำเฟส 1 ตามแผน
- `js/portal.js` → `MH_DEMO_ACCESS = true` (ปุ่มโหมดทดลองบ้านของฉัน) **ต้องตั้งเป็น `false`** ก่อนเปิดให้ลูกค้าจริง
- `index.html` มี `<meta name="robots" content="noindex">` สำหรับช่วงต้นแบบ — เอาออกเมื่อขึ้นเว็บจริง
- ข้อมูลฟอร์ม/บ้านของฉัน/หลังบ้านเก็บในเบราว์เซอร์เท่านั้น ห้ามใช้กับข้อมูลลูกค้าจริงจนกว่าจะทำเฟสเชื่อมระบบตามแผน
- ERP ที่พนักงานใช้ (ระบบ RQ และ ERP ออฟฟิศ): ห้ามแก้/ลบข้อมูลจริง สำรองและทดสอบบนสำเนาก่อนเสมอ

## 6. สิ่งที่ไม่อยู่ในชุดนี้

- โค้ด ERP ออฟฟิศและเว็บเดิม → อยู่ใน GitHub `ppsd/ppsd.home`
- โค้ดและฐานข้อมูลระบบ RQ (Cloudflare Worker + D1) → ยังไม่ได้รับ ต้องขอจากผู้ดูแลระบบ
- ไฟล์ต้นฉบับใน Canva (ตารางวัสดุ, งานฟรีม) → เปิดจากลิงก์ใน `PROJECT_MASTER_CONTEXT.md`
- ภาพต้นฉบับใน Google Drive ของบริษัท → ภาพที่ใช้แล้วอยู่ใน `site/img/` ครบ
- ประวัติการสนทนาเดิม → สรุปไว้ในเอกสารชุดนี้แล้ว
