## 1. โปรเจกต์นี้คืออะไร

เว็บไซต์ใหม่ของ **บริษัท พีพีเอสดี คอนสตรัคชั่น จำกัด** (แบรนด์ **PPSD HOME BUILDER**) — รับสร้างบ้านพรีเมียม ออกแบบอิงหลักฮวงจุ้ย สโลแกน “บ้านดี ดวงดี By PPSD”
เจ้าของโปรเจกต์: พี่แมน (ผู้ก่อตั้ง PPSD Group)

ภาพรวมระบบที่ต้องการ (ตามคำสั่งเจ้าของ):

1. **เว็บไซต์สาธารณะ** ระดับ Luxury สำหรับลูกค้าทั่วไป
2. **บ้านของฉัน (Customer Portal)** เฉพาะลูกค้าที่สร้างบ้านกับ PPSD จริง เห็นความคืบหน้า รูปหน้างาน รายงาน งวดชำระ และเอกสารที่บริษัทอนุญาต — เห็นเฉพาะบ้านตัวเอง
3. **Admin Dashboard** ซ่อนจากลูกค้า ต้องล็อกอินตามสิทธิ์ แก้เนื้อหา แบบบ้าน ราคา รูป รีวิว และอนุมัติรูป/รายงานจาก ERP ก่อนลูกค้าเห็น โดยไม่ต้องแก้ Source Code
4. **เชื่อมกับ ERP เดิมที่พนักงานใช้อยู่** ไม่สร้าง ERP ใหม่ และห้ามแก้/ลบข้อมูลจริง
5. **LINE OA บัญชีเดียว** แบ่ง 3 กลุ่ม (ผู้สนใจ / กำลังก่อสร้าง / ส่งมอบแล้ว) เป็นช่องทางติดต่อหลัก

## 5. กติกาที่เจ้าของกำหนด (ใช้ทุกครั้ง)

1. รักษาดีไซน์และฟังก์ชันเดิม ห้ามลบหรือเปลี่ยนฟังก์ชันเดิมโดยไม่ได้รับอนุญาต
2. ห้ามเริ่มสร้างเว็บใหม่โดยไม่จำเป็น — พัฒนาต่อจาก Source Code ในชุดนี้
3. ห้ามเปลี่ยนสิ่งที่ทำตามคำสั่งเจ้าของไปแล้ว (รายการในหัวข้อ 6)
4. ตรวจ Source Code ก่อนแก้ทุกครั้ง
5. แยกให้ชัดว่าส่วนไหนใช้งานได้จริง ส่วนไหนเป็น Mockup (ดู `DEVELOPMENT_STATUS.md` หัวข้อ 2)
6. ข้อมูลขาดให้ถามเจ้าของ ห้ามเดา
7. พัฒนาต่อเนื่องโดยไม่ทำให้งานเดิมเสียหาย · วางแผน/สรุปก่อน แล้ว **รออนุมัติก่อนแก้จริง** เมื่อเจ้าของสั่งไว้
8. **ERP ที่พนักงานใช้อยู่: ห้ามแก้หรือลบข้อมูลจริง** ต้องสำรองข้อมูลและทดสอบบนสำเนาก่อนเชื่อมจริง
9. **บ้านของฉัน** เป็นข้อมูลส่วนตัว เข้าได้เฉพาะลูกค้าจริงที่ยืนยันตัวตนแล้ว เห็นเฉพาะบ้านตัวเอง
10. **หลังบ้าน** ต้องไม่มีลิงก์ให้ลูกค้าเห็น
11. **LINE OA** ไม่ทำเป็นเมนูหรือส่วนแยกบนเว็บ ใช้เป็นช่องทางติดต่อ/เข้าถึงบริการ · ไม่มีแชทในเว็บ · ปุ่มลอยเปลี่ยนเป็น Help Center + LINE OA · ไม่แสดง Rich Menu ซ้ำบนเว็บ
12. ถ้าข้อมูลใน Canva ขัดกับเว็บ ให้สรุปจุดต่างแล้วถามก่อนเปลี่ยน
13. Repo `ppsd/ppsd.home` (ตาม CLAUDE.md ของ repo): ห้ามแตะ/commit `server/data` (ppsd.sqlite, files, backups, secret.key), เทสต์ห้ามแตะข้อมูลจริง, commit เฉพาะไฟล์ตัวเองบน branch `dev/…`, ข้อความ commit ภาษาไทย, `npm run build` ก่อน push, ห้าม force push, ห้ามลบ branch, ห้ามพิมพ์ secret
14. รูปบัตรประชาชนที่อยู่ใน Drive ห้ามนำมาใช้
15. **ทุกครั้งที่ทำงานหรืออัปเดตเสร็จ ให้อัปโหลดของที่อัปเดตขึ้นโฟลเดอร์ Drive ชุดส่งมอบ** (ลิงก์ในหัวข้อ 2) · เวอร์ชันล่าสุดอยู่ชั้นนอก เวอร์ชันเก่าย้ายเข้า `_เวอร์ชันเก่า` · บันทึกใน `CHANGELOG.md`

- (เวอร์ชัน 2) ปุ่มลอยเป็น Help Center + LINE OA, ตัดแชทในเว็บ และ LINE จำลอง/Rich Menu ออกจากบ้านของฉัน
- (เวอร์ชัน 2) ใส่ตารางรายละเอียดวัสดุจริงจาก Canva (Premium/Elite) ในหน้าวัสดุ และฤกษ์/พิธี/ฮวงจุ้ยในแพ็กเกจในหน้าฮวงจุ้ย · **ราคาแพ็กเกจต่อ ตร.ม. ยังไม่เปลี่ยน** (รอเจ้าของตัดสิน)

## 7. โครงสร้าง Source Code (เว็บต้นแบบ)

Static SPA ไม่มี build step เปิด `index.html` ผ่าน static server ได้ทันที

```
index.html          โครงหน้า + โหลด css/js ตามลำดับ
css/site.css        ดีไซน์หลัก + CSS variables
css/grand.css       ชั้นดีไซน์แกรนด์ + motion hero + ส่วนเพิ่มบ้านของฉัน (ถอดออกได้ถ้าจะกลับโทนเดิม)
js/data.js          ข้อมูลบริษัท (P.CO), ผลงาน (P.WORKS), ข้อความ TH/EN
js/designs.js       ข้อมูลแบบบ้าน (ชุดเดิม 28 แบบ)
js/core.js          router (hash), header/footer, เมนู, ปุ่มลอย, ไอคอน, helper (ph, istrip)
js/pages.js         หน้าเว็บสาธารณะทั้งหมด (R.home, R.designs, …)
js/tools.js         เครื่องคำนวณ (สินเชื่อ, งบ, ผ่อนไหวไหม, วางแผนการเงิน), ฟอร์ม, wizard 7 ขั้น
js/portal.js        บ้านของฉัน (R.myhome, mh-*) + ระบบหลังบ้าน (R.admin) เมนูเดิม + กลไกเสียบโมดูลเพิ่ม P.ADMIN_EXT
js/cms.js           (v2) ชั้นเนื้อหาที่แก้จากหลังบ้าน (P.applyContent, P.pageOv) + โมดูล รออนุมัติ / ใบเสนอราคา / แคตตาล็อก / เนื้อหา / ผลงานและรีวิว
css/cms.css         (v2) สไตล์หลังบ้านใหม่ ตารางวัสดุ Help Center
house/viewer.js     ตัวดู 3D/แปลน (build จาก src/web-house ใน repo เดิม)
plans/*.json        ข้อมูลแปลนแบบบ้าน
img/ fonts/         ภาพและฟอนต์
docs/PPSD-handoff.md  บันทึกส่งมอบรอบ 12 พ.ย. 2569
```

- Routing: `location.hash` (เช่น `#designs`, `#design-37`; ลิงก์เก่า `#design/37` ยังใช้ได้) · มี hook `P._leave` สำหรับเก็บกวาดเมื่อเปลี่ยนหน้า
- ข้อมูลจำลองทั้งหมดอยู่ใน localStorage คีย์ `ppsdDemoDB.v1` (v2 เพิ่ม `content` ขยาย, `customDesigns`, `quotes`, สถานะ `status: pending/approved/rejected` บนรายงาน/รูป/เอกสาร — ข้อมูลเก่าที่ไม่มีสถานะถือว่าอนุมัติแล้ว) · คีย์อื่น: `ppsdAdmin`, `ppsdFav`, `ppsdCmp`, `ppsdLang`, `ppsdWizard`, `ppsdMhLock`, `ppsdConsent`, `ppsdCookieConsent` ฯลฯ · เซสชันบ้านของฉันใช้ sessionStorage `ppsdPortal`
- API ที่เรียก (มีเฉพาะบนโดเมนเว็บเดิม): `/api/public/house-concept`, `/api/public/house-ideas`, `ideas.json`
