# ส่วนที่ 1 · เริ่มต้นใช้งาน

## 1.1 เปิดระบบ
- เครื่องเซิร์ฟเวอร์ในออฟฟิศ: ดับเบิลคลิก **`start.bat`** (หรือตั้ง `install-autostart.bat` ให้เปิดเองตอนเปิดเครื่อง)
- เครื่องอื่น/มือถือในวง LAN: เปิดเบราว์เซอร์ไปที่ `http://192.168.x.x:3001` (เลข IP แสดงตอนเปิดเซิร์ฟเวอร์ · ครั้งแรกรัน `allow-network.bat` แบบ Run as administrator)
- นอกออฟฟิศ: ใช้ลิงก์สาธารณะ (ดูส่วนที่ 9) หรือ Tailscale
- **ติดตั้งเป็นแอปบนมือถือ:** iPhone (Safari) → แชร์ → "เพิ่มไปยังหน้าจอโฮม" · Android (Chrome) → ⋮ → "ติดตั้งแอป"
- หลังอัปเดตเวอร์ชันใหม่: ดับเบิลคลิก **`update.bat`** แล้วทุกคนกด F5

## 1.2 เข้าสู่ระบบ
1. กรอก **ชื่อผู้ใช้** และ **PIN 4 หลัก** → `เข้าสู่ระบบ`
2. ผิด 5 ครั้ง → ล็อกชื่อผู้ใช้นั้น 5 นาที · เข้าระบบค้างได้ 7 วัน
3. หน้าแรกหลังเข้าระบบคือ **บ้าน**

**ลืม PIN:** กด `ลืม PIN?` → กรอกชื่อผู้ใช้ → `ส่งคำขอรีเซ็ต PIN` → ติดต่อผู้ดูแลให้ยืนยันตัวตน → ผู้ดูแลให้ **PIN ชั่วคราว** → เข้าระบบแล้วระบบ **บังคับตั้ง PIN ใหม่** (ตัวเลข 4 หลัก ห้ามซ้ำ PIN ชั่วคราว)

**เปลี่ยน PIN ของฉัน:** ไอคอนกุญแจ 🔑 มุมขวาบน → PIN ปัจจุบัน · PIN ใหม่ · ยืนยัน
> 💡 **PIN เข้าเว็บ = PIN ลงเวลา** เป็นเลขเดียวกัน

## 1.3 หน้าจอหลัก

**แถบด้านบน (Topbar)**
- ☰ เมนู (จอแคบ) · ชื่อหน้า
- **ช่องค้นหา "ค้นหาบ้าน / ลูกค้า"** — ค้นจากชื่อ/รหัส/โครงการ/ลูกค้า คลิกผลเพื่อเปิดบ้านหรือลูกค้า
- **🔔 กระดิ่งแจ้งเตือน** — งวดเลยกำหนด · PR/OT/ลา รออนุมัติ · ใบสั่งงานใหม่ · งานด่วน · Lead เงียบ · นัดติดตามลูกค้า · เคสเกิน SLA · คะแนนต่ำ ฯลฯ (จุดแดง = อันตราย · ส้ม = เตือน · น้ำเงิน = ทั่วไป) คลิกเพื่อไปหน้าที่เกี่ยวข้อง
- ชื่อ + บทบาท · **💬 ผูก LINE ของฉัน** (เขียว = ผูกแล้ว) · 🔑 เปลี่ยน PIN · ออกจากระบบ

**เมนูซ้าย (Sidebar)**

| กลุ่ม | เมนู |
|---|---|
| (บนสุด) | **บ้าน** |
| ภาพรวม / ข้ามบ้าน | หน้าสรุป · แผนงาน · สรุป QC (ผู้บริหาร) · สั่งงานด้วยเสียง (CEO) |
| งานหน้างาน (ข้ามบ้าน) | ปัญหาหน้างาน · ใบสั่งงาน (WO) · ตรวจงาน QC · เอกสารหน้างาน · รายงานหน้างาน · ความปลอดภัย · ส่งมอบ / รับรองงาน |

| อื่นๆ | รายงาน · คลังรหัสผ่านบริษัท |

**ย่อเมนูเหลือแถบไอคอน (จอคอม):** กดปุ่ม **«** ที่หัวเมนู → เมนูเหลือแค่ไอคอน (ชี้เมาส์เพื่อดูชื่อ · กดไอคอนกลุ่มเพื่อขยายกลับ) · กด **»** เพื่อขยาย · ระบบจำค่าไว้ในเบราว์เซอร์ · จอแคบ (< 1024px) เมนูยังเป็นลิ้นชักเลื่อนออกเหมือนเดิม

ท้ายเมนูแสดง **เวอร์ชัน** · ถ้าขึ้นกล่องแดง "⚠ อัปเดตโค้ดแล้ว แต่เซิร์ฟเวอร์ยังรันตัวเก่า" ให้ผู้ดูแลกด `↻ รีสตาร์ทเซิร์ฟเวอร์`

**หน้าต่างฟอร์ม (Modal)**
- กดปุ่มย่อ หรือ **Esc** = ย่อพับเป็นแถบมุมขวาล่าง ข้อมูลไม่หาย · เปลี่ยนหน้าแล้วกลับมาเปิดต่อได้ · เปิดหลายฟอร์มซ้อนได้
- คลิกพื้นหลังไม่ปิดฟอร์ม · กด F5 / ปิดเบราว์เซอร์ = ข้อมูลที่ยังไม่บันทึกหาย

**หน้าพิมพ์เอกสาร** (ใบเสร็จ สลิป ใบ PO ฯลฯ): `🖨 พิมพ์` → เลือก "บันทึกเป็น PDF" ได้ · ปิดด้วยปุ่ม `ปิด`, กด **Esc** (ปิดหน้าพิมพ์บนสุดก่อน) หรือ **คลิกพื้นที่นอกเอกสาร** · เอกสารยาวพิมพ์ได้ครบทุกหน้า

**อัปเดตสด:** เมื่อคนอื่น (หรือบอท LINE) แก้ข้อมูล หน้าจอโหลดเฉพาะส่วนที่เปลี่ยนเอง ไม่ต้องกด F5

## 1.4 บทบาทและสิทธิ์

# ส่วนที่ 2 · บ้าน / โครงการ (หัวใจของระบบ)

> ระบบออกแบบแบบ **house-first** — หลังล็อกอินจะเปิดหน้า **บ้าน** ก่อนเสมอ ทุกอย่างของบ้าน 1 หลัง (เงิน งวด ช่าง QC เอกสาร ฯลฯ) รวมอยู่ในหน้ารายละเอียดบ้าน

## 2.1 หน้า "บ้าน" (รายการบ้าน)

**ใครใช้ได้:** ทุกบทบาทเปิดดูได้ · เพิ่มบ้าน/ใส่รูปต้องมีสิทธิ์เขียน (admin / accounting / site)

**องค์ประกอบหน้าจอ**
- **ช่องเลือกบ้าน (dropdown)** "🏠 บ้านทั้งหมด (N หลัง)" — เลือกบ้านจากรายชื่อ (แสดง ชื่อ · รหัส · ลูกค้า) เพื่อดูหลังเดียว
- **ปุ่มกรอง** พร้อมจำนวนหลัง: `ทั้งหมด` · `เพิ่งเริ่ม` · `กำลังสร้าง` · `ส่งมอบแล้ว` · `After-service` · `Test` · `🏢 ออฟฟิศ`
  - `ทั้งหมด` = **บ้านจริงเท่านั้น** (ไม่รวมโครงการออฟฟิศและบ้านทดสอบ — ดูได้จากปุ่มของตัวเอง)
  - `Test` = บ้านทดสอบ (สถานะ "test" สีม่วง) ใช้ลองระบบโดยไม่ปนตัวเลขจริงในหน้ารวมบ้าน
  - `🏢 ออฟฟิศ` = โครงการประเภท ออฟฟิศ / ค่าใช้จ่ายภายใน
- ข้อความ "พบ N หลัง" และปุ่ม **`+ เพิ่มบ้าน`**
- **การ์ดบ้าน** แต่ละใบ: รูปบ้าน + รหัสบ้าน · ป้ายสถานะ (บ้านออฟฟิศขึ้น "🏢 ออฟฟิศ") · ปุ่ม `ใส่รูป` / `เปลี่ยนรูป` · ชื่อบ้าน · โครงการ · ลูกค้า
  - บ้านขาย/CM: **มูลค่าสัญญา**, แถบ **ความคืบหน้า %** (ส้ม < 20% · น้ำเงิน ระหว่างทาง · เขียว 100%), **เก็บแล้ว**, **ค้างเก็บ**
  - บ้านออฟฟิศ: "ค่าใช้จ่ายออฟฟิศ (รายจ่ายที่บันทึก)" แยกหมวด เบิกค่าน้ำมัน · ซ่อมแซมออฟฟิศ · ของใช้สำนักงาน · อื่นๆ

**ขั้นตอน: เพิ่มบ้านใหม่**
1. กด **`+ เพิ่มบ้าน`** → หน้าต่าง "เพิ่มบ้าน / โครงการใหม่"
2. กรอก

| ช่อง | ความหมาย |
|---|---|
| ชื่อบ้าน / โครงการ * | บังคับกรอก |
| ประเภทโครงการ | `ขายบ้าน (รับสร้างบ้าน)` = ใช้งวดลูกค้า-ช่าง + คิดกำไร · `ควบคุมงาน (CM)` = คิดค่าบริการควบคุมงาน · `ออฟฟิศ / ค่าใช้จ่ายภายใน` = แยกของที่ซื้อเข้าออฟฟิศ |
| โครงการ | ใช้จัดกลุ่มในหน้าสรุปและรายงาน |
| ชื่อลูกค้า / ผู้ว่าจ้าง | |
| มูลค่าตัวบ้าน — ขายลูกค้า / จ่ายช่าง | เฉพาะบ้านขาย (โรงจอดรถ / ถนน-รั้ว เพิ่มทีหลังที่ "แก้ไขข้อมูล") |
| ค่าบริการควบคุมงาน | เฉพาะ CM |

3. กดบันทึก → ระบบตั้งรหัสบ้าน `NEW-0001`, `NEW-0002` … ต่อเลขให้อัตโนมัติ (**รหัสบ้านห้ามซ้ำ** — ถ้าซ้ำระบบแจ้งว่าใช้กับบ้านไหนแล้ว), สถานะเริ่มต้น "เพิ่งเริ่ม", บันทึกประวัติ "เพิ่มบ้าน"

**ใส่/เปลี่ยนรูปบ้าน:** กด `ใส่รูป` บนการ์ด → เลือกไฟล์ → ระบบย่อรูปให้อัตโนมัติ (กว้างไม่เกิน 1400px)

> 💡 บ้านที่ได้จาก **เอกสารขาย → เซ็นสัญญา** จะถูกสร้างพร้อมงวดลูกค้าให้อัตโนมัติ

## 2.2 หน้า "รายละเอียดบ้าน"

คลิกการ์ดบ้าน → เปิดหน้ารายละเอียด (แท็บ "งวดงาน" เป็นค่าเริ่มต้น)

**แถบหัวเรื่อง:** ปุ่ม `กลับ` · ชื่อบ้าน/โครงการ/ลูกค้า/รหัส · **ป้ายสถานะเป็น dropdown** (เลือกเปลี่ยนสถานะได้ทันที: เพิ่งเริ่ม / กำลังสร้าง / ส่งมอบแล้ว / After-service / Test — สำหรับ admin / บัญชี / หน้างาน / ผู้จัดการ) · ป้ายประเภท · ปุ่ม **`🖨 พิมพ์สรุป`** · ปุ่ม **`แก้ไขข้อมูล`** · บ้าน CM แสดงกล่องข้อมูลสัญญา (เลขที่สัญญา เจ้าของ ที่ตั้ง ผู้ควบคุมงาน วิศวกร ขอบเขตงาน)

> 💡 ถ้าบ้านยังเป็น "เพิ่งเริ่ม" แต่ความคืบหน้าเกิน 0% แล้ว จะมีปุ่มเตือน **"คืบหน้า N% แล้ว → เปลี่ยนเป็น “กำลังสร้าง”"** กดครั้งเดียวเปลี่ยนให้

**ใบสรุปบ้าน (`🖨 พิมพ์สรุป`)** — เอกสาร A4: ข้อมูลโครงการ (รหัส ลูกค้า สถานะ/คืบหน้า แบบบ้าน พื้นที่ วันเริ่ม กำหนดส่งมอบ ผู้จัดการ · บ้าน CM มีข้อมูลสัญญา) · การเงินแยกหมวด · ตารางงวดลูกค้า และงวดช่าง (จำนวนเงิน / เก็บ-จ่ายแล้ว / สถานะ) · รายจ่าย · ปัญหาที่ยังค้าง — ตัวเลข **กำไร/ต้นทุน แสดงเฉพาะผู้จัดการ** เหมือนบนหน้าจอ

### แก้ไขข้อมูลบ้าน (`แก้ไขข้อมูล`)
ช่องตามลำดับ: ชื่อ * · ประเภท · ลูกค้า · ค่าบริการ CM · **ตัวบ้าน / โรงจอดรถ / ถนน-รั้ว** (แต่ละหมวดมี "ขายลูกค้า" และ "จ่ายช่าง") · พื้นที่ใช้สอย · ที่ตั้งโครงการ · เลขที่สัญญา · เจ้าของ · ผู้ควบคุมงาน · วิศวกร · ขอบเขตงาน · **สถานะ** · แบบบ้าน · เริ่มก่อสร้าง · กำหนดส่งมอบ · ผู้จัดการโครงการ

> 💡 ช่อง **สถานะ** เป็นตัวเลือก (เพิ่งเริ่ม / กำลังสร้าง / ส่งมอบแล้ว / After-service / Test) — สถานะ **ตั้งเองต่อหลัง** ไม่ได้คำนวณจากความคืบหน้า
> 💡 ช่องเงินพิมพ์คอมม่าได้ · ช่องที่เว้นว่างจะคงค่าเดิม · กำหนดส่งมอบควรใส่แบบ ปี-เดือน-วัน (CRM ใช้คำนวณประกัน)

### การคำนวณอัตโนมัติ (ทำใหม่ทุกครั้งที่แก้บ้าน/งวด)
- **มูลค่าสัญญา** = ตัวบ้าน + โรงจอดรถ + ถนน/รั้ว (ฝั่งขาย) · บ้าน CM = ค่าบริการ · ถ้ายังไม่กรอกราคา ใช้ยอดรวมงวดลูกค้า
- **ต้นทุนช่าง** = ผลรวมฝั่งจ่ายช่าง 3 หมวด
- **เก็บแล้ว** = ยอดที่เก็บจริงของงวดลูกค้า (รวมเก็บบางส่วน) · **ค้างเก็บ** = มูลค่า − เก็บแล้ว
- **จ่ายช่างแล้ว** = ยอดจ่ายจริงของงวดช่าง
- **ความคืบหน้า %** = เก็บแล้ว ÷ มูลค่า × 100 → **คิดจากเงินที่เก็บ ไม่ใช่จากหน้างาน**

### กล่องสรุปการเงิน (บ้านขาย/CM) — การ์ด 6 ช่อง
1. ขายลูกค้า (มูลค่าสัญญา) 2. เก็บจากลูกค้าแล้ว (+ค้างเก็บ) 3. **กำไรโครงการ** + มาร์จิน % (*เฉพาะผู้จัดการ* คนอื่นเห็น "-") 4. ต้นทุนช่าง 5. จ่ายช่างแล้ว (+ค้างจ่าย) 6. ความคืบหน้า (+ค่าใช้จ่ายย่อย)

ตาราง **"มูลค่าแยกตามหมวดงาน"**: ตัวบ้าน / โรงจอดรถ / ถนน / รั้ว → รวมทั้งหลัง (กำไรขั้นต้น) → **กำไรสุทธิ** = ขาย − จ่ายช่าง − ค่าใช้จ่ายจริง

**ค่าใช้จ่ายจริงของบ้าน** = รายจ่ายของบ้าน (ไม่นับที่ "ปฏิเสธ") + ใบจ่ายเงิน/หัก ณ ที่จ่ายที่ผูกบ้าน (ยอดก่อนหัก) — *ไม่นับใบชำระ PO ซ้ำ* เพราะต้นทุน PO ถูกนับแล้วตอน "รับของ"

**บ้านประเภทออฟฟิศ:** แสดงการ์ด รายจ่ายออฟฟิศ / PR ที่อนุมัติ / PO และตาราง "ค่าใช้จ่ายแยกตามหมวด (ออฟฟิศ)"

### คอลัมน์ซ้าย (กว้าง 340–400px)
- กล่อง **ข้อมูลบ้าน** (รหัส แบบบ้าน พื้นที่ วันเริ่ม กำหนดส่งมอบ ผู้จัดการ)
- กล่อง **ไฟล์แบบบ้าน / สัญญา** (ดู 2.5)

### แท็บด้านขวา
`งวดงาน` · `ใบสั่งงาน` · `ช่าง / ผู้รับเหมา` · `ปัญหา` · `BOQ` · `QC ตรวจงาน` · `เอกสารหน้างาน` · `รายงานหน้างาน` · `ความปลอดภัย` · `ส่งมอบงาน` · `จัดซื้อ` · `รายจ่าย`

แท็บส่วนใหญ่ใช้หน้าจอเดียวกับเมนูหลัก (ดูส่วนที่ 3–5) แต่ **กรองเฉพาะบ้านนี้** และล็อกช่อง "บ้าน" ให้อัตโนมัติ · แท็บ `ปัญหา` และ `รายจ่าย` เป็นแบบดูอย่างเดียว

## 2.3 แท็บ "งวดงาน" (ในบ้าน)

**โครงสร้าง**
- งวดแบ่งเป็น **หมวด**: `ตัวบ้าน` · `โรงจอดรถ` · `ถนน / รั้ว` + **หัวข้อใหญ่ที่เพิ่มเอง** (เช่น สระว่ายน้ำ)
- แต่ละหมวดมี 2 ตาราง: **งวดงานลูกค้า (รับเงิน)** สีเขียว และ **งวดงานช่าง (จ่ายให้ช่าง)** สีส้ม
- **กดหัวหมวดเพื่อย่อ/ขยาย** — หมวดที่ย่อจะแสดงสรุป "ลูกค้า N งวด · เก็บแล้ว x / y · ช่าง N งวด · จ่ายแล้ว x / y" · ปุ่ม **ย่อ/ขยายทุกหมวด** · ระบบจำการย่อไว้ต่อบ้านในเบราว์เซอร์นั้น
- คอลัมน์: งวด · รายละเอียด (ฝั่งช่างแสดง 👷 ชื่อช่าง) · ระยะเวลา (วัน) · กำหนด (แดง = เลยกำหนด) · จำนวนเงิน · สถานะ · จัดการ

**เพิ่ม/ลบหัวข้อใหญ่:** ท้ายแท็บ "+ เพิ่มหัวข้อใหญ่:" พิมพ์ชื่อ → `เพิ่มหัวข้อ` (ห้ามซ้ำหมวดมาตรฐาน/หัวข้อเดิม) · `ลบหัวข้อ` ได้เมื่อไม่มีงวดเหลือ

**เพิ่ม/แก้งวด**
1. `+ เพิ่มงวด` (ระบบเติมเลขงวดถัดไป) หรือ `แก้ไข` ที่แถว
2. กรอก (ทุกช่องมีป้ายกำกับ) **งวด** · **รายละเอียดงาน** · **ระยะเวลา (วัน)** — ตัวเลขเท่านั้น เช่น 30 (ข้อมูลประกอบตามสัญญา ไม่ใช้คำนวณ) · **วันครบกำหนด** (ใช้คำนวณเลยกำหนด/อายุหนี้) · **จำนวนเงิน**
3. ฝั่งช่าง: เลือก **จ่ายให้ช่าง** จากรายชื่อในแท็บช่าง — ระบบแสดง "ตกลงจ้าง … · ตั้งงวดแล้ว … · เหลือ …" และเตือน "⚠ เกินยอดตกลง" (ยังบันทึกได้)
4. `บันทึก`

กฎ: สถานะเริ่มต้น ลูกค้า = "รอเก็บเงิน" / ช่าง = "รอจ่าย" · ลดมูลค่างวดให้ต่ำกว่ายอดที่เก็บแล้วไม่ได้ · สถานะ "เก็บแล้ว/จ่ายแล้ว/บางส่วน" ตั้งเองไม่ได้ ระบบคิดจากเงินจริง

**ปุ่มในคอลัมน์จัดการ**

| ปุ่ม | ทำอะไร |
|---|---|
| `ตรวจรับ` (ลูกค้า) | เปิดใบตรวจรับงวดงาน — ปุ่มเปลี่ยนเป็น "ตรวจรับ: ผ่าน/ผ่านบางส่วน/ไม่ผ่าน" |
| `เก็บเงินเต็ม` / `จ่ายเงินเต็ม` | บันทึกว่าเก็บ/จ่ายครบทั้งงวด |
| `บางส่วน` | ใส่จำนวนเงินครั้งนี้ (ค่าตั้งต้น = ยอดคงเหลือ) → "เก็บบางส่วน" จนครบเป็น "เก็บแล้ว" |
| `ยกเลิก` | รีเซ็ตยอดเป็น 0 กลับเป็นรอเก็บ/รอจ่าย |
| `ใบเสร็จ` | พิมพ์ใบเสร็จรับเงิน (เมื่อมียอดเก็บแล้ว) |
| `ลบ` | ถอนรายการบัญชีของงวดแล้วลบ |

> ⚠️ **ต้องตรวจรับก่อนเก็บเงิน** — ค่าเริ่มต้นระบบเปิดกติกา "ต้องตรวจรับงวดก่อนเก็บเงิน" ถ้าผลตรวจรับล่าสุดไม่ใช่ **ผ่าน** หรือ **ผ่านบางส่วน** ระบบจะไม่ยอมให้เก็บเงิน (เครื่องหมาย `*` บนปุ่ม = ยังไม่ตรวจรับ) · ผู้ดูแลปิดกติกานี้ได้ที่หน้า **ตรวจสอบ** · ฝั่งช่างไม่ต้องตรวจรับ

**ผลอัตโนมัติทุกครั้งที่เก็บ/จ่าย:** คำนวณยอดบ้านใหม่ · **ลงบัญชีให้เอง** (ลูกค้า: Dr ธนาคาร / Cr รายได้ 4010 · ช่าง: Dr ต้นทุน 5030 / Cr ธนาคาร) — ถ้าลงไม่สำเร็จจะขึ้น "ลงบัญชีค้าง" ที่แถบสุขภาพระบบ · บันทึกประวัติตรวจสอบ

### ใบตรวจรับงวดงาน
- หัวเอกสาร "ใบตรวจรับงวดงาน (Work Progress Acceptance)"
- รายการตรวจตั้งต้น 4 ข้อ (ถูกต้องตามแบบ · คุณภาพเรียบร้อย · เก็บงาน/ทำความสะอาด · เอกสาร/รูปครบ) — แก้ข้อความได้, ติ๊ก ผ่าน/ไม่ผ่าน, `+ เพิ่มรายการตรวจ`
- ผู้ตรวจสอบ · **ผลการตรวจรับ** ผ่าน / ผ่านบางส่วน / ไม่ผ่าน · ความเห็น
- `บันทึกผลตรวจรับ` → ได้เลข `AC-ปี-NNN` · ตรวจซ้ำได้ (ระบบใช้ผล **ใบล่าสุด**) · `🖨 พิมพ์` หลังบันทึก

### ใบเสร็จรับเงิน
เลขที่ `RC-ปี-รหัสงวด` · ได้รับเงินจาก · โครงการ/บ้าน · "งวดที่ N" · จำนวนเงิน = ยอดที่เก็บจริง (ระบุถ้าเป็นรับบางส่วน) · ช่องเซ็น
> ⚠️ ช่อง "วันที่" บนใบเสร็จใช้ **วันครบกำหนดของงวด** ไม่ใช่วันรับเงินจริง และไม่แยก VAT (ถ้าต้องการใบที่มี VAT ใช้ **เอกสารขาย**)

## 2.4 นำเข้างวดงาน (อัปโหลดสัญญา / วางจาก Excel)

1. แท็บงวดงาน → **`⬆ นำเข้างวดงาน (อัปโหลดสัญญา)`**
2. เลือก "งวดงานนี้เป็นของ:" `ลูกค้า (รับเงิน)` หรือ `ช่าง (จ่ายเงิน)`
3. เลือกวิธี
   - **`📄 อัปโหลดสัญญา (AI อ่านให้)`** — PDF/รูป ไม่เกิน 40MB · ต้องตั้งกุญแจ AI แล้ว (ผู้ดูแล → ตั้งค่า AI)
   - **`📋 วางจาก Excel / Word`** — วางข้อความ → `แปลงเป็นงวดงาน →` (รองรับตาราง Excel, ย่อหน้า "งวดที่ 1 … บาท", บรรทัดละงวด; ตัดบรรทัด "รวมทั้งสิ้น" ออกให้)
4. ตรวจ/แก้ตาราง "ตรวจสอบ/แก้ไขก่อนบันทึก" (ลบแถวด้วย ✕)
5. **`✓ สร้างงวดงานทั้งหมด (N)`**

> ⚠️ งวดที่นำเข้าจะเข้าหมวด **"ตัวบ้าน"** และไม่ผูกชื่อช่าง — แก้รายงวดภายหลังถ้าต้องการ · ผู้ใช้ที่ไม่ใช่ admin อาจเห็นข้อความ "ยังไม่ได้ตั้งกุญแจ AI" แม้ตั้งไว้แล้ว (ยังใช้งานได้)

## 2.5 ไฟล์แบบบ้าน / สัญญา

- เลือก **หมวดที่จะอัปโหลดเข้า** (อยู่บรรทัดล่าง): ค่าเริ่มต้น **`อัตโนมัติ (ตามชนิดไฟล์)`** — DWG/DXF/SKP/RVT/IFC → แบบก่อสร้าง · รูปภาพ → รูปหน้างาน · อื่นๆ → อื่นๆ · หรือเลือกเอง: `สัญญา` · `แบบก่อสร้าง` · `ใบอนุญาต` · `สเปก/วัสดุ` · `รูปหน้างาน` · `เอกสารการเงิน` · `อื่นๆ`
- กด **`+ อัปโหลด`** — เลือกได้หลายไฟล์ ไฟล์ละไม่เกิน 200MB
- **ย้ายหมวด:** แต่ละไฟล์มีป้ายหมวดเป็น dropdown — เลือกหมวดใหม่เพื่อย้ายไฟล์ที่อัปโหลดผิดหมวด
- ปุ่มกรองตามหมวดพร้อมจำนวน — รวมหมวดที่มาจากส่วนอื่นของระบบด้วย (เช่น "ใบส่งของ" จากตรวจรับ PO · "ส่งงาน" จากใบสั่งงาน · "เอกสารขาย (ใบเก่า)") · ไฟล์ไม่มีหมวด = อื่นๆ
- `ดู` (PDF/รูป) · ⬇ ดาวน์โหลด · ✕ ลบ (**ลบถาวร กู้ไม่ได้**)

## 2.6 แท็บ "ช่าง / ผู้รับเหมา"

**จ้างช่าง (`+ จ้างช่าง`)**
1. **ช่าง / ผู้รับเหมา *** — เลือกจากทะเบียน (จัดซื้อ → ผู้ขาย หมวด "ผู้รับเหมา") หรือ "— พิมพ์ชื่อใหม่ —"
2. **หมวดงานที่จ้าง (ราคากลาง)** — "เหมายกหลัง" / "แยกแต่ละงาน" → ระบบเติมงานและราคาแนะนำ ("💡 ต้องหาช่างที่ราคาถูกกว่าหรือเท่ากับราคากลาง")
3. **ประเภท:** `เหมารวม` (ของ+แรง) / `เฉพาะค่าแรง`
4. งานที่รับผิดชอบ · ปริมาณ · ราคาตกลง/หน่วย · ยอดตกลงจ้างรวม (เว้นว่าง = ปริมาณ × ราคา)
5. ป้ายเทียบราคา: ถูกกว่าราคากลาง / ตามราคากลาง / **สูงกว่าราคากลาง +x%** / เสนอราคา
6. ถ้าสูงกว่าราคากลาง **ต้องกรอกเหตุผล** และยืนยัน (ระบบบันทึกลงประวัติตรวจสอบ)
7. `บันทึก`

**การ์ดช่าง:** ยอดตกลงจ้าง · ตั้งงวดแล้ว · ยังตั้งงวดได้อีก · งวดงานรวม · จ่ายช่างแล้ว · คงค้างจ่าย · จ่ายเงินสดจริง · ปุ่ม `ค่าของออกให้ก่อน` · `ประเมิน` · `✎ แก้ไข` · `✕`

**ค่าของออกให้ก่อน** (ช่างเหมารวม): บันทึกของที่บริษัทออกให้ → `+ ออกค่าของ` · หักคืน → `− หักจากงวด` (ไม่เกินยอดคงเหลือ)

**ประเมินผู้รับเหมา:** 10 หัวข้อ คะแนน 1–5 (คุณภาพ · ตรงเวลา · ตามแบบ · สื่อสาร · คุมแรงงาน · ความปลอดภัย · ตอบสนองการแก้ไข · ความสะอาด · กฎระเบียบ · ความร่วมมือ) → เกรด ≥4.5 ดีมาก · ≥3.5 ดี · ≥2.5 ปานกลาง · ต่ำกว่า = ควรปรับปรุง

> 💡 ยอดจ่ายช่างผูกกับ **ชื่อช่าง** ในงวดงาน — ระบุช่างในงวดช่างทุกครั้ง ตัวเลขในการ์ดช่างจึงจะถูก

## 2.7 ส่งมอบงาน / หนังสือรับรองผลงาน

ใช้ได้ทั้งแท็บ `ส่งมอบงาน` ในบ้าน และเมนู **ส่งมอบ / รับรองงาน**

**ใบส่งมอบงาน** (`+ ออกเอกสาร` ที่แท็บ `ใบส่งมอบงาน`)
1. บ้าน · ชื่อเรื่อง (เช่น "ส่งมอบงานงวดที่ 3") · ขอบเขต · การรับประกัน · ผู้ส่งมอบ · ผู้รับมอบ
2. รายการตรวจรับ (สลับ ✓ ผ่าน / ✗ ไม่ผ่าน, `+ เพิ่มรายการ`) · ข้อบกพร่อง
3. **`↻ ดึงข้อมูลจริง`** — ดึงจากใบตรวจรับงวดที่ผ่านล่าสุด (ตรวจทานผลแต่ละข้อก่อนบันทึก)
4. `บันทึก` → เลข `HD-ปี-NNN`

**หนังสือรับรองผลงาน** (แท็บ `หนังสือรับรองผลงาน`): ผู้รับการรับรอง · โครงการ · มูลค่า · ระยะเวลา · ขอบเขต · ระดับผลงาน (ดีเยี่ยม/ดีมาก/ดี/พอใช้) · ผู้ออกหนังสือ · ข้อความรับรอง (เว้นว่าง = ข้อความมาตรฐาน) · `↻ ดึงข้อมูลจริง` (ดึงช่าง ยอดจ่าย วันที่ เกรดประเมิน) → เลข `CERT-ปี-NNN`

**พิมพ์:** "ใบส่งมอบงาน (WORK HANDOVER)" (เซ็น 3 ช่อง ผู้ส่งมอบ/ผู้รับมอบ/พยาน) · "หนังสือรับรองผลงาน (WORK CERTIFICATE)"
> ⚠️ ยังไม่มีปุ่มแก้ไขเอกสารที่ออกแล้ว — ผิดต้องลบแล้วออกใหม่

## 2.8 เมนู "งวดงาน" (รวมทุกบ้าน)

- การ์ด 4 ใบ: `รอเก็บเงิน` · `เลยกำหนด` · `เก็บแล้ว` · `ยังไม่ถึงกำหนด`
- **ช่องเลือกบ้าน (dropdown)** "🏠 ทุกบ้าน (N หลังที่มีงวด)" — แต่ละบ้านแสดงจำนวนงวด / "ยังไม่มีงวด" · เลือกบ้านแล้ว **การ์ดสรุปและตารางคิดเฉพาะบ้านนั้น** · ตัวกรอง `ทั้งหมด / รอเก็บเงิน / เลยกำหนด / เก็บแล้ว / ยังไม่ถึง` · ปุ่ม **`ส่งออก Excel`**
- ตาราง: บ้าน · งวด · รายละเอียด · วันกำหนด · ตรงเวลา · จำนวนเงิน · สถานะ + ปุ่ม `เก็บเงิน` / `จ่ายช่าง` (บันทึกเต็มจำนวน)
- **เลยกำหนด** = มีวันครบกำหนด + วันนั้นผ่านไปแล้ว + ยังเก็บ/จ่ายไม่ครบ (งวดที่ไม่มีวันครบกำหนดไม่ถูกนับ)

> 💡 เก็บบางส่วน, ยกเลิก, ตรวจรับ, พิมพ์ใบเสร็จ ต้องทำใน **หน้ารายละเอียดบ้าน** · ปุ่ม `เก็บเงิน` หน้านี้ไม่เตือนเรื่องตรวจรับ ถ้ายังไม่ตรวจรับระบบจะปฏิเสธ

## 3.1 ปัญหาหน้างาน

ใช้บันทึก/ติดตามปัญหา เช่น น้ำรั่วซึม · ข้อมูลอยู่ชุดเดียวกับ **เคสบริการลูกค้า (CRM)** — เคสที่ลูกค้าแจ้งทาง LINE/พอร์ทัลจึงขึ้นที่นี่ด้วย

**หน้าจอ:** การ์ด 4 ใบ (ค้างอยู่ทั้งหมด · ด่วนมาก · กำลังแก้ไข · แก้ไขแล้ว) · ตัวกรอง ทั้งหมด/ด่วนมาก/ปานกลาง/ทั่วไป · ปุ่ม **`+ แจ้งปัญหา`** · ตาราง บ้าน · ปัญหา · ผู้แจ้ง · วันแจ้ง · ความเร่งด่วน (แดง/เหลือง/เทา) · สถานะ

**แจ้งปัญหาใหม่**
1. `+ แจ้งปัญหา` → เลือก **บ้าน** · **หัวข้อปัญหา *** · รายละเอียด · **ความเร่งด่วน** (ทั่วไป/ปานกลาง/ด่วนมาก)
2. บันทึก → ผู้แจ้ง = คุณ, สถานะ **"รอช่าง"**

**สถานะ:** รอช่าง → กำลังแก้ไข → แก้ไขแล้ว (ฝั่ง CRM มี ปิดเคส / ยกเลิก)
> 💡 การเปลี่ยนสถานะ มอบหมายผู้รับผิดชอบ และปิดเคส ทำที่ **ลูกค้า (CRM) → เคสบริการ** · ลูกค้าที่ผูก LINE จะได้รับแจ้งอัตโนมัติ และเมื่อปิดเคสระบบขอคะแนน 0–10

## 3.2 ใบสั่งงาน (WO) + ควบคุมคุณภาพ

ใช้สั่งงานพนักงาน → ผู้รับกดรับทราบ → ส่งงานพร้อมหลักฐาน → ผู้สั่งตรวจรับ → ระบบคิด **คะแนน KPI** ให้

**สิทธิ์รายใบ**

| บทบาทในใบ | ใคร | ทำอะไรได้ |
|---|---|---|
| สิทธิ์เต็ม | ผู้สั่งงาน/ผู้สร้างใบ · ผู้บริหาร (ผู้จัดการ/CEO/ประธาน/กรรมการผู้จัดการ/ผู้บริหาร/เจ้าของ) · ผู้ดูแลระบบ | แก้ทุกช่อง · ลบ · รับงาน |
| ผู้รับงาน | ผู้รับผิดชอบ หรือคนสำรองที่งานด่วนไล่มาถึง | รับทราบ · ส่งงาน · แก้เฉพาะส่วน "2) บันทึกการดำเนินงาน" |
| คนอื่น | | ดูได้อย่างเดียว |

**หน้าจอ:** ปุ่ม **`+ ออกใบสั่งงาน`** · ตาราง เลขที่ · งาน (ครบกำหนด) · ผู้รับผิดชอบ (✓ รับทราบ / รอรับทราบ) · ความสำคัญ · สถานะ (+🔗 ลิงก์งาน / 📎 ไฟล์ / KPI +x) · จัดการ

| ปุ่ม | ขึ้นเมื่อ |
|---|---|
| **รับทราบ** | คุณเป็นผู้รับ และยังไม่รับทราบ |
| **ส่งงาน** | คุณเป็นผู้รับ รับทราบแล้ว และยังไม่ส่ง |
| **✓ รับงาน** | สถานะ "ส่งงาน" และคุณมีสิทธิ์ตรวจรับ |
| **เปิด/บันทึกผล** · **🖨** · **✕** | ทุกแถว |

### ขั้นตอนครบวงจร
**ก) ผู้สั่ง — ออกใบ**
1. `+ ออกใบสั่งงาน` → **ผู้รับผิดชอบ *** (จากทะเบียนพนักงาน) · ระดับความสำคัญ (ปกติ/ด่วน/ด่วนที่สุด) · บ้าน · ชื่องาน · กำหนดส่ง + เวลา · LINE Group (อ้างอิง)
2. **1) เป้าหมายและมาตรฐาน:** ขอบเขตงาน · Definition of Done (ความถูกต้อง / ความสะอาด / หลักฐาน) · งบประมาณ/ทรัพยากร
3. **`สั่งงาน + แจ้งเตือน`** → เลข `WO-ปี-ลำดับ` สถานะ "สั่งงาน" · ส่ง LINE ถึงผู้รับ ("📌 งานใหม่ … ตอบ 'รับ' เพื่อรับทราบ") + สำเนาถึงผู้สั่ง + กระดิ่ง

**ข) ผู้รับ — รับทราบ:** กด `รับทราบ` หรือตอบใน LINE **"รับ"** / **"รับ WO-69-012"** · พิมพ์ **"งาน"** ใน LINE เพื่อดูงานค้าง → ผู้สั่งได้ LINE "✓ … รับทราบงานแล้ว"

**ค) ผู้รับ — บันทึกการดำเนินงาน:** `เปิด/บันทึกผล` → ส่วน 2) เวลาเริ่ม/เสร็จจริง · รวมเวลา · ปัญหา/อุปสรรค · การแก้ไข → `บันทึก`

**ง) ผู้รับ — ส่งงาน:** `ส่งงาน` → แนบไฟล์ (`+ เลือกไฟล์` หลายไฟล์ได้ — เข้าคลังไฟล์บ้านหมวด "ส่งงาน") **หรือ** ใส่ลิงก์ (Google Drive/รูป/วิดีโอ) + หมายเหตุ → **`ส่งงาน ✓`** (ต้องมีไฟล์หรือลิงก์อย่างน้อย 1)

**จ) ผู้สั่ง — ตรวจรับ:** เปิดไฟล์/ลิงก์ตรวจ → **`✓ รับงาน`** → ยืนยัน → สถานะ **"เสร็จ"** + คิดคะแนน KPI

**ฉ) ผู้สั่ง — QC และประเมิน (ไม่บังคับ)**
- **3) ตรวจสอบคุณภาพ:** Accuracy · Neatness · Timeliness · Perfection (ผ่าน/ไม่ผ่าน + หมายเหตุ) · สรุปผลตรวจรับ Approved / Conditional / Rejected
- **4) ประเมินเพื่อพัฒนา:** คะแนน (1–10) · สถานะงาน · สิ่งที่ทำได้ดี · สิ่งที่ต้องปรับปรุง

**คะแนน KPI ใบสั่งงาน**

| กรณี | คะแนน |
|---|---|
| ไม่มีกำหนดส่ง | +5 |
| ตรงเวลา | +10 |
| ส่งก่อนกำหนด | +10 และ +2/วัน (สูงสุด +20) |
| ส่งช้า | −5/วัน (ต่ำสุด −25) |
| งานด่วนที่ถูกไล่ระดับ/เกินเวลา | หักเพิ่ม −10 |

```
สั่งงาน ─(รับทราบ)─► รับทราบ ─► กำลังทำ ─(ส่งงาน)─► ส่งงาน ─(รับงาน)─► เสร็จ (+KPI)
   └─(งานด่วน ไม่มีคนรับทัน)─► เกินเวลา          (เลือกเองได้: ตรวจผ่าน / ตีกลับ)
```

> ⚠️ **ต้องผ่าน "ส่งงาน" → "รับงาน" เท่านั้นถึงจะได้ KPI** — เปลี่ยนสถานะเป็น "เสร็จ" เองในฟอร์มไม่ได้คะแนน · ช่อง "คะแนน (1–10)" จะถูกแทนด้วยคะแนน KPI เมื่อกดรับงาน
> ⚠️ ใบที่ตรวจรับแล้ว **ผู้สั่งงานลบไม่ได้** (เก็บเป็นประวัติ) — **เฉพาะผู้ดูแลระบบ (admin)** ลบได้ โดยระบบเตือนก่อนว่าคะแนน KPI ของใบนั้นจะหาย และบันทึกประวัติไว้ · ผู้รับต้องผูก LINE (ไอคอน 💬 มุมขวาบน) จึงจะได้รับงานทาง LINE

**พิมพ์:** "ใบสั่งงานและควบคุมคุณภาพ (WORK ORDER & QC)" — ลงชื่อ ผู้สั่งงาน / ผู้รับงาน / ผู้ตรวจสอบ

## 3.3 ตรวจงาน QC (Checklist)

ตรวจคุณภาพตาม **ฟอร์มมาตรฐาน PPSD 60 ฟอร์ม** แบ่ง งวด → หมวด → ฟอร์ม

| งวด | ชื่องวด |
|---|---|
| 0 | ก่อนเริ่มก่อสร้าง (เอกสาร-เตรียมพื้นที่) |
| 1 | งานฐานราก |
| 2 | งานโครงสร้างชั้น 1 |
| 3 | งานโครงสร้างชั้น 2 |
| 4 | คานหลังคา / ดาดฟ้า |
| 5 | งานหลังคา |
| 6 | งานก่อ-ฉาบ + ระบบฝังผนัง |
| 7 | งานฝ้า-พื้น-กระเบื้อง-ราวกันตก |
| 8 | งานติดตั้ง-ตกแต่ง-สี |
| 9 | งานภายนอก-ส่งมอบบ้าน |

ฟอร์มส่วนใหญ่ผลเป็น **ผ่าน/ไม่ผ่าน** · ฟอร์มเอกสารงวด 0 เป็น **มี/ไม่มี** · บางฟอร์มมี **ช่องพิเศษ** เช่น วันเทปูน, จำนวนคิวปูน, วันขุดดิน

**หน้าจอ**
- (ในบ้าน) **การ์ดความคืบหน้าตามงวด** — "ผ่านแล้ว/ฟอร์มทั้งหมด" สี เขียว = ผ่านครบ · แดง = มีใบต้องแก้ · เหลือง = เริ่มตรวจ · เทา = ยังไม่เริ่ม · กดการ์ดเพื่อกรอง
- ตัวกรองงวด (หน้าข้ามบ้าน) · ปุ่ม **`+ สร้างใบตรวจ QC`**
- ตาราง เลขที่ · ฟอร์มตรวจ · บ้าน/โซน · ผล (✓ผ่าน/✎ต้องแก้/ทั้งหมด) · สถานะ (+ "เลยกำหนด") · `ตรวจ/แก้` `🖨` `✕`

**สร้างใบตรวจ**
1. `+ สร้างใบตรวจ QC` → เลือก **บ้าน → งวดงาน → หมวดงาน → ฟอร์มตรวจ**
2. โซน/ชั้น (เติมให้อัตโนมัติ) · ช่างหน้างาน · วันเริ่ม · วันกำหนดเสร็จ · รูปหน้างาน (สูงสุด 3)
3. **`สร้าง + ดึงเช็กลิสต์`** → เลข `QC-ปี-ลำดับ` สถานะ "กำลังตรวจ" · **ผู้ตรวจ = ผู้สร้างใบ**

**บันทึกผลตรวจ**
1. `ตรวจ/แก้` → แต่ละข้อกด **ผ่าน / ไม่ผ่าน** (หรือ มี/ไม่มี) กดซ้ำเพื่อยกเลิก
2. ทางลัด **"ข้อที่ยังไม่ได้ตรวจทั้งหมด → ผ่านทั้งหมด"**
3. **📷 รูป** รายข้อ (ข้อละ ≤3) · เหตุผล/สิ่งที่ต้องแก้ไข
4. ท้ายใบ: ช่องพิเศษ · กำหนดการแก้ไข · กำหนดเข้าตรวจซ้ำ · ช่าง · สรุป ☐ผ่านมาตรฐาน/☐ไม่ผ่าน · หมายเหตุ
5. **`บันทึกผลตรวจ`**

**สถานะคำนวณอัตโนมัติ:** มีข้อไม่ผ่าน → **ต้องแก้ไข** · ทุกข้อผ่าน → **ผ่าน** · ยังมีข้อว่าง → **กำลังตรวจ**

> 💡 เมื่อใบที่ผ่านทำให้ **ทั้งงวดของบ้านผ่านครบ** ระบบส่ง LINE แจ้งลูกค้า (ถ้าผูก LINE และเปิดการแจ้ง QC) ครั้งเดียวต่องวด · รูปหน้างานแสดงในพอร์ทัลลูกค้า · ผลตรวจนับเข้า KPI ผู้ตรวจ — **ให้คนที่ตรวจจริงเป็นคนสร้างใบ**

**พิมพ์:** "เอกสารตรวจ<ชื่อฟอร์ม>" ตามแบบฟอร์มกระดาษ PPSD (ตาราง ลำดับ/รายการ/ผล/เหตุผล + รูป + ช่องลงชื่อตามฟอร์ม)

## 3.4 เอกสารหน้างาน (RFI / RFA / NCR / VO)

| แท็บ | ความหมาย | สถานะ (ตัวแรก = เริ่มต้น) |
|---|---|---|
| **RFI** | สอบถามแบบ | รอตอบ → ตอบแล้ว → ปิด |
| **RFA** | ขออนุมัติ (วัสดุ/Shop Drawing) | รออนุมัติ → อนุมัติ / อนุมัติมีเงื่อนไข / ให้แก้ไข / ไม่อนุมัติ |
| **NCR** | งานไม่เป็นไปตามข้อกำหนด | เปิด → เสนอแก้ไข → อนุมัติแก้ไข → ปิด |
| **VO** | งานเปลี่ยนแปลง | เสนอ → อนุมัติ / ไม่อนุมัติ |

**ออกเอกสาร:** เลือกแท็บ → `+ ออก …` → บ้าน · หมวดงาน · ผู้รับ · **เรื่อง *** · รายละเอียด · (VO: ผลต่อค่าก่อสร้าง ± บาท และระยะเวลา ± วัน) → **`บันทึก + ออกเลขที่`**

**ตอบ:** ปุ่ม `ตอบ` → พิมพ์คำตอบ/ผลอนุมัติ/วิธีแก้ (ระบบบันทึกผู้ตอบ+วันที่) · **เปลี่ยนสถานะ:** เลือกจากดรอปดาวน์ในตาราง (บันทึกทันที) · ค้นหา "ค้นหาเลขที่/เรื่อง/หมวด"

**พิมพ์:** ใบ RFI/RFA/NCR/VO — ลงชื่อ ผู้ออกเอกสาร / ผู้ควบคุมงาน / ผู้อนุมัติ
> ⚠️ ยังแก้หัวข้อ/รายละเอียดหลังออกไม่ได้ · RFI/RFA/VO ถูกดึงไปรายงานประจำสัปดาห์

## 3.5 รายงานหน้างาน (Daily / Weekly)

1. เลือกแท็บ **รายงานประจำวัน (Daily)** / **ประจำสัปดาห์ (Weekly)** → `+ เขียนรายงาน` → เลือกบ้าน
2. **Daily:** สภาพอากาศ · เวลาเริ่ม–เลิก · สรุปงานวันนี้ · จำนวนคนงาน · เครื่องจักร · ความคืบหน้า % · ความปลอดภัย · ผู้เข้าเยี่ยม · หมายเหตุ
   **Weekly:** สัปดาห์ที่ · ช่วงวันที่ · ความคืบหน้าตามแผน % · จริง % · สรุปงาน · แรงงาน/ผู้รับเหมาช่วง · RFI/RFA/VO · งานความปลอดภัย · หมายเหตุ
3. กด **`↻ ดึงข้อมูลจริง`** — เติม จำนวนคนลงเวลาวันนี้, % จาก S-curve แผนงาน, รายการเอกสารหน้างาน, บันทึกความปลอดภัยล่าสุด
4. ตรวจทาน → **`บันทึกรายงาน`** → เลข `DR-` / `WR-ปี-ลำดับ`

> ⚠️ จำนวนคนงานที่ดึงมาคือ **คนลงเวลาทั้งบริษัท** วันนี้ (ไม่แยกบ้าน) ให้แก้ให้ตรงหน้างาน · "ความคืบหน้าตามแผน" ต้องกรอกเอง · ยังแก้รายงานที่บันทึกแล้วไม่ได้

**พิมพ์:** Daily Report / Weekly Report — ลงชื่อ ผู้รายงาน / ผู้อนุมัติ

# ส่วนที่ 4 · จัดซื้อ / วัสดุ

## 4.0 ภาพรวมขั้นตอนจัดซื้อ 5 ขั้น

```
① โฟร์แมนสั่งของ (LINE หรือเว็บ)  → PR สถานะ "รอตรวจสอบ"
② ผู้ตรวจสอบตรวจ (การ์ด LINE)      → "รออนุมัติ"   (หรือ ↩ ส่งกลับแก้ไข)
③ ผู้บริหารอนุมัติ PR (การ์ด LINE)  → "อนุมัติ" + รูปใบ PR เข้า LINE จัดซื้อ
④ ส่งรูปใบเสนอราคา → AI เทียบราคา  → ร่าง PO จากร้านที่คุ้มสุด
⑤ ผู้บริหารอนุมัติ PO               → สั่งของ → ตรวจรับของ → (เครดิต) จ่ายเงิน + 50 ทวิ
```

## 4.1 สิทธิ์

| บทบาท | เห็น/ทำอะไรได้ |
|---|---|
| admin | ทุกอย่าง รวม "🗑 ล้างข้อมูลจัดซื้อ (PR/PO)" และลบ PR |
| accounting | ทุกแท็บ · สร้าง PO / จ่ายเงิน / ผู้ขาย / ราคากลาง · ตรวจ PR ได้ |
| site (โฟร์แมน) | เฉพาะแท็บ **ใบขอซื้อ (PR)** — สร้าง PR ได้ |
| viewer | ไม่มีสิทธิ์เข้าจัดซื้อ (ดูสต๊อกได้อย่างเดียว) |
| **ผู้จัดการ/CEO** (ตามตำแหน่ง) หรือ admin | **อนุมัติ/ปฏิเสธ PR, PO, ใบจ่ายเงิน** (ทั้งเว็บและ LINE) · override การตรวจรับ |
| **ผู้ตรวจสอบใบขอซื้อ** (แอดมินตั้ง 1 คน) | ตรวจ PR · อัปโหลดใบเสนอราคา/AI เทียบ · ออก PO จากใบเทียบราคา |

> ⚠️ บัญชีที่ไม่มีตำแหน่งผู้จัดการจะเห็นปุ่ม "อนุมัติ" แต่ระบบจะตอบ "อนุมัติได้เฉพาะตำแหน่งผู้จัดการ/CEO เท่านั้น"
> เมนู **ราคากลาง** เห็นเฉพาะ admin / บัญชี / ผู้จัดการ · เปิดจัดซื้อจากในบ้าน = เห็นเฉพาะ PR/PO ของบ้านนั้น

## 4.2 หน้า "จัดซื้อ / จ่าย" — แท็บ
**ใบขอซื้อ (PR)** · **ใบสั่งซื้อ (PO)** · **ประวัติการซื้อ / ราคา** · **จ่ายเงิน / หัก ณ ที่จ่าย** · **ยอดค้างจ่าย** · **ผู้ขาย / ผู้รับเหมา** · **รายงานภาษี**

### แท็บ ใบขอซื้อ (PR)
คอลัมน์: เลขที่ PR · วันที่ · บ้าน (+หมวด, ป้ายออนไลน์) · ผู้ขอ · รายการ (📷) · จำนวนเงิน · **สถานะ / อนุมัติ**

ในช่องสถานะจะเห็น: "🔍 รอตรวจสอบ · ชื่อ" + สถานะการส่ง LINE (+ปุ่ม **↻ ส่ง LINE อีกครั้ง**) · ปุ่ม **✓ ตรวจแล้ว ออก PR** / **↩ ส่งกลับ** · แถบ "รออนุมัติ n/N" + **อนุมัติ (ขั้น n)** / **ปฏิเสธ** · หลังอนุมัติ: แถบขั้นตอน เทียบราคา → PO → PO อนุมัติ + ปุ่ม **📤 ส่งใบเข้า LINE**

ปุ่มประจำแถว: **⚖ เทียบราคา** · **🖨 ใบ PR** · 🗑 (แอดมิน) · **→ PO** (เมื่ออนุมัติครบ)

### สร้างใบขอซื้อ (PR) บนเว็บ
1. **`+ ขอซื้อ (PR)`**
2. เลือก **บ้าน** และ **หมวด** (บ้านลูกค้า: ตัวบ้าน/โรงจอดรถ/ถนน/รั้ว · ออฟฟิศ: เบิกค่าน้ำมัน/ซ่อมแซมออฟฟิศ/ของใช้สำนักงาน/อื่นๆ)
3. **ช่องทางจัดซื้อ:** ร้านค้าในระบบ / ออนไลน์ (AI หา 3 ร้านดีที่สุด) / ทั้งสองอย่าง
4. รายการ: **สินค้า · จำนวน · หน่วย · ราคา/หน่วย** (`+ เพิ่มรายการ`) — ระบบเทียบราคากลาง: "⚠ สูงกว่าราคากลาง n%" (เกิน 10%) หรือ "✓ ไม่เกินราคากลาง" · **ราคาเว้นว่างได้** (รอใบเสนอราคา)
5. **ส่วนลด** และ **ภาษีซื้อ** 3 แบบ

| โหมด | วิธีคิด |
|---|---|
| ไม่มี VAT | รวม = ยอด − ส่วนลด |
| ราคารวม VAT แล้ว | ก่อน VAT = (ยอด − ส่วนลด) ÷ 1.07 |
| ราคาก่อน VAT (+7%) | รวม = (ยอด − ส่วนลด) × 1.07 |

6. แนบรูปสินค้า (สูงสุด 3 รูป ≤ 8MB) → **บันทึก** → เลข `PR-69-0001`
   - มีผู้ตรวจสอบ → "รอตรวจสอบ" + การ์ด LINE ถึงผู้ตรวจ · ไม่มี → "รออนุมัติ" + การ์ดถึงผู้บริหาร

### ตรวจ / อนุมัติ PR
- **ผู้ตรวจสอบ:** `✓ ตรวจแล้ว ออก PR` → "รออนุมัติ" · หรือ `↩ ส่งกลับ` + เหตุผล → "ส่งกลับแก้ไข" (**ต้องสร้างใบใหม่**)
- **ผู้อนุมัติ:** `อนุมัติ (ขั้น n)` / `ปฏิเสธ` — จำนวนผู้อนุมัติ PR ค่าเริ่มต้น **1 คน** · ห้ามอนุมัติใบที่ตัวเองขอ · แต่ละขั้นต้องคนละคน
- อนุมัติครบ → สถานะ **อนุมัติ** → ระบบส่งรูปใบ PR เข้า LINE "ผู้รับใบ PR" (จัดซื้อ)
- ปฏิเสธ → PO ร่างของใบนั้นถูกยกเลิก + แจ้งผู้ขอ

### เทียบราคา (⚖)
- **📷 อัปโหลดรูปใบเสนอราคา** (หลายรูป) → **🤖 AI เทียบราคา** → บันทึกใบเทียบ (ป้าย AI) + ⭐ ร้านคุ้มสุด (เลือกให้อัตโนมัติถ้ายังไม่มีใครเลือก)
- **🔎 AI หาของออนไลน์** — 3 ร้านดีที่สุดต่อรายการ (`+ ใช้เทียบราคา`)
- **🕘 เคยซื้อมาก่อน** — PO เก่าที่รายการใกล้เคียง ป้าย "ถูกสุด" + **`+ ใช้ราคานี้`**
- ตาราง "เปรียบเทียบราคาผู้ขาย" — **เลือก** · **→ ออก PO** · ✕ · เพิ่มเอง (ชื่อ/ราคา/เงื่อนไข → `+ เพิ่ม`)

### แท็บ ใบสั่งซื้อ (PO)
คอลัมน์: เลขที่ · วันที่ · ผู้ขาย · รายการ (🏠) · มูลค่า · การชำระ (เงินสด / เครดิต n วัน + ครบ) · สถานะ (`รอส่งของ` / `รับของแล้ว` / `ปิดงาน` / ✗ ยกเลิก) · จัดการ (แถบอนุมัติ · ✓ รับของตรง/✗ ไม่ตรง · **📦 ตรวจรับของ** · **🖨 พิมพ์ PO**)

**ออก PO**
- วิธี A: ในแผงเทียบราคา กด **→ ออก PO** ที่ร้านที่เลือก (ใช้ราคา/รายการจากใบเทียบ · ผู้ขายมีเครดิต = PO เครดิต · ผู้ขายจด VAT = คิด 7/107)
- วิธี B: ปุ่ม **→ PO** ที่แถว PR → ฟอร์ม "ออกใบสั่งซื้อ (PO)": ผู้ขาย * · รายการ (พิมพ์ค้นหาราคากลาง) · มูลค่า · อ้างอิง PR · ซื้อให้บ้าน · การชำระ เงินสด/เครดิต · ส่วนลด · ภาษีซื้อ · เลขที่ใบกำกับ · รูป → **บันทึก** → `PO-69-xxxx` สถานะ "รอส่งของ" + การ์ดอนุมัติทาง LINE

**กติกาที่อาจบล็อก** (ตั้งที่หน้า ตรวจสอบ): ต้องอ้าง PR ที่อนุมัติครบ (เปิดไว้ตั้งแต่ต้น) · ห้าม PO เกินยอด PR (เฉพาะ PR ที่มียอด) · PO ≥ 100,000 บาท ต้องมีใบเทียบ ≥ 3 เจ้า + เลือกผู้ขาย · VAT ต้องไม่เกินมูลค่า

**อนุมัติ PO:** ค่าเริ่มต้นต้อง **3 คนที่ต่างกัน** → ครบแล้วรูปใบ PO เข้า LINE จัดซื้อ + ผู้ขอ ("สั่งของกับร้านได้เลยค่ะ") · **ปฏิเสธ = ยกเลิกทันที**
> ⚠️ ถ้าบริษัทมีผู้อนุมัติน้อยกว่า 3 คน ให้ลดจำนวนที่หน้า **ตรวจสอบ → กติกา** ไม่อย่างนั้น PO จะค้าง

### ตรวจรับของ (📦)
1. ดูตาราง "รายการที่สั่งใน PO"
2. **📷 อัปโหลดรูปใบส่งของ** (รูป/PDF) → AI อ่านรายการ · หรือ **+ กรอกรายการเอง**
3. แก้ตาราง "รายการในใบส่งของ" ให้ตรงใบจริง + หมายเหตุ
4. **ตรวจสอบ** → เทียบ ชื่อ · จำนวน (ต้องเท่ากัน) · ราคา/หน่วย และยอดรวม (ต่างได้ ≤ 2%) · รายการที่ไม่ได้สั่ง = ไม่ผ่าน
5. ✅ **ผ่าน** → PO เป็น **รับของแล้ว** → `เสร็จสิ้น` · ⛔ **ไม่ผ่าน** → ยังเป็นรอส่งของ (ผู้จัดการกด **ผู้จัดการยอมรับรับของ (override)** ได้)

วิธีลัด: เปลี่ยนสถานะในตาราง PO เป็น "รับของแล้ว" (admin/บัญชี · PO ต้องอนุมัติครบ)

> 💡 **ผลทางบัญชีเกิดตอน "รับของแล้ว" ไม่ใช่ตอนออก PO** — ระบบสร้างรายจ่ายหมวด "วัสดุ" ผูกบ้าน (เข้าต้นทุนบ้าน) · PO เงินสด: Dr ต้นทุน / Cr เงินสด · PO เครดิต: Dr ต้นทุน / **Cr เจ้าหนี้การค้า 2010** (ขึ้นแท็บยอดค้างจ่าย) · PO ไม่ผูกบ้าน → ของเข้า **สต๊อกกลาง** · เปลี่ยนกลับ/ปฏิเสธ = ถอนรายการให้

### แท็บ จ่ายเงิน / หัก ณ ที่จ่าย
1. **`+ บันทึกจ่ายเงิน`** หรือ **💸 จ่าย** จากแท็บยอดค้างจ่าย (เติมข้อมูลให้)
2. **ผู้รับเงิน *** · ป้าย "ชำระ PO-…" · **ประเภทหัก** ภงด.53 / ภงด.3 / ไม่หัก · **ยอดก่อนหัก** · **อัตรา %** (ค่าเริ่มต้น 3) · ผูกบ้าน (ไม่บังคับ — เข้าต้นทุนบ้าน) · รายละเอียด
3. **บันทึก** → `PV-69-xxxx` · หัก = ยอด × อัตรา (ปัดบาท) · สุทธิ = ยอด − หัก · การ์ดอนุมัติทาง LINE
- ผูกได้เฉพาะ **PO เครดิตที่รับของแล้ว** · PO เงินสด **ไม่ต้องทำใบจ่าย** (ตัดเงินแล้ว) · จ่ายเกินยอดค้างไม่ได้
- บัญชี: ผูก PO → Dr 2010 / Cr 2040 + ธนาคาร · ผูกบ้าน → Dr 5020 · ไม่ผูก → Dr 6090
- ปุ่ม **ใบจ่ายเงิน** และ **50 ทวิ** (หนังสือรับรองหัก ณ ที่จ่าย ติ๊กแบบ ภงด. ตามประเภท ดึงลายเซ็นพนักงานถ้าผู้รับเป็นพนักงาน)

### แท็บ ยอดค้างจ่าย
- แถบตรวจ "✓ ยอดเจ้าหนี้ตรงกับบัญชี (2010)" / "⚠️ ไม่ตรง — กด สร้างบัญชีจากข้อมูลเดิม"
- เฉพาะ **PO เครดิตที่รับของแล้ว/ปิดงาน** · คอลัมน์ ผู้ขาย · PO · ครบกำหนด (แดง=เกิน) · มูลค่า · จ่ายแล้ว · คงเหลือ · สถานะ (ค้างจ่าย/เกินกำหนด/จ่ายครบ) · **💸 จ่าย**

### แท็บ ผู้ขาย / ผู้รับเหมา
- ชิป ทั้งหมด / 🏪 ผู้ขาย / 🔨 ผู้รับเหมา (กดป้ายในตารางเพื่อย้ายหมวด) · **`+ เพิ่มผู้ขาย/ผู้รับเหมา`**
- คอลัมน์: ชื่อ (+หมวดสินค้า, ที่อยู่) · นิติบุคคล/บุคคล · เลขผู้เสียภาษี · หมวด · **เครดิต (วัน)** (แก้ในช่อง; 0 = เงินสด) · **จด VAT** (ติ๊ก) · ยอดซื้อสะสม · ค้างจ่าย · ✎ แก้ไข
> 💡 ตั้ง **เครดิต** และ **จด VAT** ให้ถูก PO จะตั้งเงินสด/เครดิตและ VAT ให้อัตโนมัติ · ชื่อร้านในใบเทียบราคาต้องตรงกับทะเบียน · ผู้รับเหมาในทะเบียนใช้ตอน "จ้างช่าง" ในบ้าน

### แท็บ ประวัติการซื้อ / ราคา
ค้นหา "ชื่อวัสดุ หรือผู้ขาย" → การ์ดสรุป (ซื้อกี่ครั้ง · ราคาต่ำ–สูง/เฉลี่ย · ผู้ขาย · ล่าสุด) + ตาราง (PO / รายจ่าย / PR) สูงสุด 300 แถว

### แท็บ รายงานภาษี
การ์ด ภงด.3 · ภงด.53 (นำส่งภายในวันที่ 7) · ภาษีซื้อ · กล่อง e-Filing ไฟล์ ภงด.3 / ภงด.53 / ภพ.30 → **ดาวน์โหลด** (ระบบสร้างไฟล์ ไม่ได้ยื่นแทน)

## 4.3 จัดซื้อผ่าน LINE (ขั้นตอนจริงในแชท)

**สิ่งที่ต้องตั้งก่อน** (ดูส่วนที่ 8): LINE token/secret + ลิงก์สาธารณะ · ทุกคนผูก LINE (💬 มุมขวาบน → ส่งรหัส 6 หลักในแชทบอท) · กุญแจ AI · ผู้ตรวจสอบ PR + ผู้รับใบ PR

**① โฟร์แมนสั่งของ** — พิมพ์ในแชทบอท เช่น
> *สั่งของ ปูนซีเมนต์ 50 ถุง, เหล็กเส้น 12 มม. 10 เส้น บ้านคุณพร*

(คำนำ: สั่งของ / ขอซื้อ / ขอจ้าง / ออก PR … · โฟร์แมนพิมพ์ภาษาคนได้เลยไม่ต้องมีคำนำ · ผู้บริหารถ้าไม่ชัด บอทจะถาม 1 = PR / 2 = ใบสั่งงาน)

บอทถามต่อทีละขั้น: บ้านไหน → (ออฟฟิศ) หมวด 1–4 → "📷 มีรูปสินค้าไหม" (ส่ง ≤3 รูป แล้วพิมพ์ **ครบ** / **ไม่มี**) → สรุปร่าง → ตอบ **ตกลง** (หรือพิมพ์ใหม่เพื่อแก้ / **ยกเลิก**) → "✅ สร้าง PR-… แล้ว" → ถามช่องทาง **1** ร้านในระบบ / **2** ออนไลน์ / **3** ทั้งสอง

**② ผู้ตรวจสอบ** ได้การ์ด "ตรวจสอบใบขอซื้อ" → **ตรวจแล้ว ออก PR** / **ส่งกลับแก้ไข** (บอทถามเหตุผล)

**③ ผู้บริหาร** ได้การ์ดสีส้ม "ใบขอซื้อ PR-…" → **อนุมัติ** / **ยังไม่อนุมัติ** · หรือพิมพ์ *"อนุมัติ PR-69-0144"* / *"ปฏิเสธ PV-69-0208 ราคาสูงไป"* (ใช้กับ PR, PO, PV, EXP) · พิมพ์ **รออนุมัติ** เพื่อดูรายการค้าง

**④ จัดซื้อ** ได้รูปใบ PR → **ส่งรูปใบเสนอราคาของแต่ละร้านตอบกลับในแชทเดิม** (ระบบจำ 48 ชม.) → ครบตามจำนวน (ปกติ 2 ร้าน; PR ≥ 100,000 ต้อง 3) ระบบรอ 1 นาทีแล้ว AI เทียบให้เอง → "🤖 ผลเทียบราคา" + การ์ด **ออก PO (ชื่อร้าน)** → ถ้า PR อนุมัติแล้ว **ระบบร่าง PO จากร้านที่ AI แนะนำให้อัตโนมัติ**
- คำสั่ง: *"ใบเสนอราคา PR-69-0012"* (ระบุใบ) · พิมพ์เลข PR เพื่อสลับใบ · **เทียบราคา** · **เอาร้านนี้** · *"เอาร้านที่ 2"* (จากผลค้นออนไลน์) · *"ออก PO PR-…"*

**⑤ ผู้บริหาร** ได้การ์ด "ใบสั่งซื้อ PO-…" (มีผลเทียบทุกร้าน) → **อนุมัติ** / **ยังไม่อนุมัติ** / **เลือกร้านอื่น** → ครบแล้วรูปใบ PO เข้า LINE จัดซื้อ → สั่งของ → **ตรวจรับในเว็บ**

> 💡 คุยหลาย PR พร้อมกัน ให้ **พิมพ์เลข PR ก่อนส่งรูป** · บอทจำบริบท ~30 นาที · **ช่วย** = ดูคำสั่ง · **ยกเลิก** = ล้างบริบท · ผู้บริหารพิมพ์ **สรุป** = เรื่องค้างวันนี้
> ⚠️ ถ้าการ์ดไม่เด้ง ดูเหตุผลใต้สถานะในเว็บ (โควตาหมด / token ผิด / ผู้รับยังไม่เพิ่มเพื่อน / ยังไม่ผูก LINE) แล้วกด **↻ ส่ง LINE อีกครั้ง**

### เบิกค่าน้ำมันผ่าน LINE
1. โฟร์แมนพิมพ์ *"เบิกน้ำมัน 1500 บ้านคุณพร ทะเบียน กข1234"*
2. บอทสรุป (+ยอดกองคงเหลือ, "⚠ ไม่พอ") → ตอบ **ตกลง**
3. ได้ `FR-69-xxxx` → การ์ดถึงผู้บริหาร **อนุมัติ** / **ปฏิเสธ**
4. อนุมัติ = ตัดเงินจากกองค่าน้ำมันทันที (Dr 6030 / Cr 1031) + แจ้งผู้ขอ · กองไม่พอ = อนุมัติไม่ได้ ต้องเติมกองก่อน
5. ในเว็บ: **บัญชีแยกประเภท → แท็บ ค่าน้ำมันรถ → คำขอเบิกค่าน้ำมัน**

## 4.4 สต๊อกวัสดุ

- ของจาก PO ที่ **ไม่ผูกบ้าน** เข้าสต๊อกอัตโนมัติเมื่อตรวจรับผ่าน (PO ละครั้งเดียว) · PO ผูกบ้าน = ส่งตรงหน้างาน ไม่เข้าสต๊อก
- **บันทึกรายการ:** เลือก **เบิกออก** / **รับเข้า** / **ตรวจนับ (ตั้งยอด)** → วัสดุ (รับเข้าพิมพ์ชื่อใหม่ได้) → จำนวน → (เบิกออก) บ้าน + ใครเบิก/เอาไปทำอะไร → **บันทึก** (เบิกเกินคงเหลือไม่ได้)
- **วัสดุคงเหลือ:** คอลัมน์ วัสดุ · คงเหลือ · หน่วย · จุดสั่งซื้อ · อัปเดตล่าสุด · **ตั้งจุดสั่งซื้อ** (0 = ไม่เตือน) → แถวเหลือง + แถบ "⚠️ วัสดุใกล้หมด"
- **ประวัติเข้า-ออก** 300 รายการล่าสุด (คลิกชื่อวัสดุเพื่อกรอง)
- สต๊อกนับ **จำนวน** เท่านั้น ไม่มีผลบัญชี

## 4.5 ราคากลาง (วัสดุ / ค่าแรง)

**วัสดุ** — อ้างอิงจากประวัติสั่งซื้อจริง
- **↻ อัปเดตจากประวัติจริง** (ค่าเฉลี่ยถ่วงน้ำหนักจาก PO ทุกใบ ไม่ทับรายการ "ตั้งราคาเอง") · **+ เพิ่มรายการ**
- ตัวกรอง ความเชื่อมั่น สูง (≥4 PO) / ปานกลาง (2–3) / ซื้อครั้งเดียว · ค้นหา
- คอลัมน์: รายการ · หน่วย · ราคากลาง · ต่ำสุด–สูงสุด · ล่าสุด · ครั้งที่ซื้อ · ความเชื่อมั่น · **÷ ต่อชิ้น** (แปลงราคาแพ็ค) / **แก้** / **ลบ**
- ใช้ที่: ป้ายเตือนใน PR · ช่องค้นหาใน PO · ราคาประเมินของ PR จาก LINE · กล่อง "เคยซื้อมาก่อน"

**ค่าแรงช่าง** — ตาราง **เหมายกหลัง** และ **แยกแต่ละงาน** (`+ เพิ่มในหมวดนี้`, `+ เพิ่มหมวดงาน`) · ราคาเป็นตัวเลข / ช่วงราคา / "เสนอราคา" · หน่วย ตร.ม./เมตร/ชุด/บาน/ห้อง/หลัง/จุด/เหมา · ใช้เป็น **ราคาแนะนำตอนจ้างช่าง** ในบ้าน · แก้ไขได้เฉพาะ admin/บัญชี

## 4.6 เอกสารที่พิมพ์ได้ (จัดซื้อ)
| เอกสาร | ปุ่ม |
|---|---|
| ใบขอซื้อ / ขอจ้าง (PR) — รายการ VAT ส่วนลด รูป ลายเซ็นผู้ขอ/ผู้ตรวจ/ผู้อนุมัติ | 🖨 ใบ PR |
| ใบสั่งซื้อ (ต้นฉบับ) — ที่อยู่/เลขภาษีผู้ขาย รายการหลายบรรทัด ยอดตัวอักษร | 🖨 พิมพ์ PO |
| ใบจ่ายเงิน | ใบจ่ายเงิน |
| หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) | 50 ทวิ |

## 4.7 เคล็ดลับจัดซื้อ
1. PO ที่ของมาแล้ว **ต้องตรวจรับ / กด "รับของแล้ว"** ต้นทุนบ้านและเจ้าหนี้จึงจะขึ้น
2. PO เงินสดไม่ต้องทำใบจ่ายเงิน (ไม่อย่างนั้นจ่ายซ้ำ)
3. PR ไม่จำเป็นต้องมียอด (0 ได้)
4. ผลค้นออนไลน์เป็นราคาประมาณ — กดลิงก์เช็คราคา/ค่าส่งจริงก่อนสั่ง
5. รูปใบเสนอราคาต้องชัด เห็นชื่อร้าน รายการ ราคา ยอดรวม
6. "🗑 ล้างข้อมูลจัดซื้อ" ลบถาวร ใช้เฉพาะตอนเริ่มระบบใหม่
7. แถว "รวมหัก ณ ที่จ่ายเดือนนี้" รวมทุกรายการที่แสดง (ไม่กรองเดือน) — ใช้ไฟล์ e-Filing สำหรับยื่น

# ส่วนที่ 5 · บัญชี / การเงิน

**ใครใช้ได้:** หน้า **รายจ่าย** และ **เอกสารขาย** ทุกคนเห็น · **ทะเบียนเอกสาร / ต้นทุน-การเงิน** = admin / บัญชี / ผู้จัดการ · **บัญชีแยกประเภท (GL) / ส่งออก Express / e-Filing** = admin / บัญชี เท่านั้น (ผู้จัดการเห็นเมนูแต่ข้อมูลไม่ขึ้น) · แอดมินปิดโมดูล "บัญชี / รายจ่าย" รายคนได้

## 5.1 รายจ่าย

**หน้าจอ:** การ์ด 4 หมวด (วัสดุ/ค่าแรง/ขนส่ง/อื่นๆ) · ค้นหา "ค้นหาบ้าน หรือ รายการ" · ตัวกรองหมวด · ส่งออก Excel · **`+ เพิ่มรายจ่าย`** · ตาราง วันที่ · บ้าน · รายการ · หมวด · ผู้ขาย/ผู้รับ · จำนวนเงิน · พิมพ์ (แถบอนุมัติ + ปุ่ม "ใบจ่าย") · แถวอนาคตมีป้าย "กำหนดจ่าย"

**เพิ่มรายจ่าย**
1. `+ เพิ่มรายจ่าย`
2. **วันที่จ่าย** (ย้อนหลัง/ล่วงหน้าได้) · **บ้าน** · **รายการ *** · **หมวด** (วัสดุ / ค่าแรง / ขนส่ง / อื่นๆ / ออฟฟิศ · เบิกค่าน้ำมัน / ซ่อมแซมออฟฟิศ / ของใช้สำนักงาน) · ผู้ขาย/ผู้รับ · **จำนวนเงิน** (ยอดรวม VAT แล้ว)
3. ถ้ามีใบกำกับภาษี: กรอก **เลขที่ใบกำกับภาษี** · **ยอด VAT ตามใบ** (เว้นว่าง = คิด 7/107 ให้) — เว้นว่างทั้งสองช่อง = ไม่มี VAT
4. บันทึก → แจ้งผู้อนุมัติ

**บัญชีอัตโนมัติ:** Dr บัญชีตามหมวด / Cr เงินสด (1010) — PO เครดิต Cr 2010

| คำในชื่อหมวด | บัญชี |
|---|---|
| วัสดุ | 5010 |
| แรง | 5020 |
| เหมาช่วง/ผู้รับเหมา | 5030 |
| เครื่องจักร/อุปกรณ์ | 5040 |
| ขนส่ง/น้ำมัน | 6030 |
| บริการ/ธรรมเนียม | 6040 |
| ดำเนินการ/สำนักงาน | 6020 |
| อื่นๆ | 6090 |

> ⚠️ VAT ของรายจ่ายทั่วไปถูกใช้ในรายงานภาษีซื้อ แต่ใน GL ทั้งยอดลงบัญชีค่าใช้จ่าย (ไม่แยก 1160) · รายจ่ายถูกปฏิเสธ = ถอนรายการบัญชี
**พิมพ์:** "ใบจ่ายค่าใช้จ่ายอื่น ๆ" เลขที่ OE-xxxxxx

## 5.2 บัญชีแยกประเภท (GL) — ระบบบัญชีคู่

**หัวหน้า:** ปุ่ม **`↻ สร้างบัญชีจากข้อมูลเดิม`** (สร้าง/ซ่อมรายการบัญชีจากงวดงาน รายจ่าย ใบจ่ายเงิน — กดซ้ำได้ ไม่ซ้ำ) · แถบแดง "⚠️ มีรายการที่ลงบัญชีไม่สำเร็จ N รายการ" (ส่วนใหญ่ติดงวดที่ปิดแล้ว — แก้ต้นเหตุแล้วกดสร้างบัญชีใหม่)

**14 แท็บ**

| แท็บ | ใช้ทำอะไร |
|---|---|
| **งบการเงิน** | เลือกช่วงวันที่ → งบกำไรขาดทุน + งบแสดงฐานะการเงิน ("✓ งบดุลสมดุล") · `🖨 พิมพ์งบการเงิน` |
| **งบกระแสเงินสด** | วิธีตรง: ยกมา → ดำเนินงาน / ลงทุน / จัดหาเงิน → คงเหลือปลายงวด |
| **กำไรรายโครงการ** | รายได้ · ต้นทุน · ค่าใช้จ่าย · กำไร ต่อบ้าน + ส่งออก Excel |
| **ลูกหนี้/เจ้าหนี้** | อายุหนี้ ยังไม่ถึง / 1–30 / 31–60 / 61–90 / >90 วัน / ไม่ระบุกำหนด (จากวันครบกำหนดงวด) |
| **กระทบยอดธนาคาร** | ตั้งบัญชีธนาคารตั้งต้น (1020) / เงินสดตั้งต้น (1010) · ใส่ยอด statement → ติ๊ก "เคลียร์" ทีละรายการ → "✓ ตรงกับ statement" |
| **เงินสดย่อย** / **ค่าน้ำมันรถ** | สองกองแยกกัน (ดู 5.3) |
| **งบทดลอง** | เดบิต/เครดิตทุกบัญชี "✓ สมดุล" + Excel |
| **สมุดรายวัน** | ดูรายการทั้งหมด (ที่มา: อัตโนมัติ / บันทึกเอง) · **`+ ลงรายการเอง`** |
| **แยกประเภท** | เลือกบัญชี → รายการ + ยอดคงเหลือสะสม |
| **ผังบัญชี** | ดู/เพิ่มบัญชี (`+ เพิ่มบัญชี` รหัส · ชื่อ · ประเภท) |
| **สินทรัพย์/ค่าเสื่อม** | `+ เพิ่มสินทรัพย์` (Dr 1210) · `↻ ลงค่าเสื่อมราคา ณ วันนี้` (Dr 6050 / Cr 1220, เส้นตรง) · จำหน่าย |
| **สรุปภาษี** | ภ.พ.30 (ภาษีขาย − ภาษีซื้อ — ภาษีซื้อรวมรายจ่าย + เงินสดย่อย/น้ำมัน) · ภงด.1/3/53 · ภ.ง.ด.50 ประมาณการ · `🔧 เติมภาษีซื้อย้อนหลัง` |
| **ปิดบัญชี/ยอดยกมา** | ยอดยกมา · ปิดงวด (ล็อกย้อนหลัง) · ปิดบัญชีสิ้นปี |

**ลงรายการเอง (สมุดรายวัน)**
1. `+ ลงรายการเอง` → วันที่ · คำอธิบาย
2. แต่ละบรรทัด เลือกบัญชี + เดบิต หรือ เครดิต (`+ เพิ่มบรรทัด`)
3. ปุ่ม **บันทึกรายการ** กดได้เมื่อ "✓ สมดุล" เท่านั้น → เลข `JV-ปี-ลำดับ`

**ยอดยกมา** (ย้ายจากระบบเดิม/Express): เลือก "ณ วันที่" → บัญชี + ยอดคงเหลือ → `บันทึกยอดยกมา` (ส่วนต่างลง 3020 อัตโนมัติ)

**ปิดงวด:** เลือก "ปิดถึงวันที่" (ได้ถึงเมื่อวาน) → `ปิดงวด` · `ยกเลิกการปิด` — เมื่อปิดแล้ว รายการในงวดลงบัญชีไม่ได้ · เอกสารในงวดปิดที่ถูกแก้/ยกเลิก ระบบลง **"กลับรายการ"** วันที่วันนี้แทน
**ปิดบัญชีสิ้นปี:** เลือกวันสิ้นปี → `ปิดบัญชีสิ้นปี` → ปิดรายได้/ค่าใช้จ่ายเข้า 3020 กำไรสะสม

| วงเงินเริ่มต้น | 10,000 | 5,000 |

| ใบสำคัญรับเงิน RV | ออกให้อัตโนมัติเมื่อไม่มีเลขบิลร้าน | ไม่ออก |
| ทะเบียนรถ | – | มี |

**หน้าจอ:** ชิปทุกกอง "💵 ยอด / วงเงิน" (แดง "ใกล้หมด" เมื่อเหลือ < 30%) · การ์ด คงเหลือ · วงเงิน (`ตั้ง`) · ต้องเติมให้เต็ม · **`↑ เติมเงินเข้ากอง`**

**ตั้งวงเงิน:** แก้ตัวเลข → `ตั้ง`
**เติมเงิน:** `↑ เติมเงินเข้ากอง` → เงินเข้ากอง (เว้นว่าง = เติมให้เต็ม) · อ้างอิง OE/PS · หมายเหตุ → `บันทึกเงินเข้า` (Dr กอง / Cr ธนาคาร)

**บันทึกจ่ายจากกอง**
1. วันที่ · **เลขที่บิลร้าน** (เงินสดย่อย: เว้นว่าง = ออก RV ให้) · ร้านค้า · **ผู้เบิก** · บ้าน (ไม่เลือก = ส่วนกลาง) · ทะเบียนรถ (น้ำมัน) · หมวด
2. ตารางรายการ: สินค้า · จำนวน · หน่วย · ราคา/หน่วย (`+ เพิ่มรายการ`) หรือ "หรือยอดรวม" — ปัดเป็นบาทเต็ม (≥ 50 สต. ปัดขึ้น)
3. ส่วนลด · ภาษีซื้อ (ไม่มี VAT / รวม VAT แล้ว / ก่อน VAT +7%)
4. (เงินสดย่อย) **ราคาตามบิล** / **ราคาจ่ายจริง** — ตัดเงินตามจ่ายจริง แสดงส่วนต่าง
5. **อ้างอิง** RR ใบรับของ / PO / OE / PS → ระบบดึงรายการ ร้าน บ้าน มาใส่ให้
6. `บันทึกจ่าย` → (ถ้าได้ RV ระบบเปิดหน้าพิมพ์ให้ทันที) · บัญชี: Dr ค่าใช้จ่าย (ก่อน VAT) + Dr 1160 / Cr กอง

**แก้ไข/ลบ:** ✎ (กรอบส้ม → `บันทึกการแก้ไข`) / ✕ — ระบบถอน/กลับรายการบัญชีให้ · รายการเติมเงินแก้ได้เช่นกัน

**ใบสรุป:** เลือกรอบวันที่ → **`🖨 ออกใบสรุป`** (ยอดยกมา · ก่อน VAT · VAT · ส่วนลด · รับ · จ่าย · คงเหลือ · สรุปแยกตามบ้าน · "ต้องเติมอีก x บาท" · ลงชื่อ 3 ช่อง)

**คำขอเบิกค่าน้ำมัน** (แท็บค่าน้ำมันรถ): คำขอจาก LINE (FR-) อนุมัติ/ปฏิเสธได้ที่นี่ — กองไม่พอ อนุมัติไม่ได้

## 5.4 ต้นทุน / การเงิน

### BOQ / ตีราคา
1. **`+ สร้าง BOQ`** → บ้าน · ชื่อ BOQ · **ดำเนินการ+กำไร %** (ค่าเริ่มต้น 20) · **VAT %** (7)
2. รายการ: **ชั้น** · หมวด (โครงสร้าง/สถาปัตยกรรม/ไฟฟ้า/ประปา/อื่นๆ) · **ส่วนงาน** (เช่น เสา คาน พื้น) · รายการ · จำนวน · หน่วย · ค่าวัสดุ/หน่วย · ค่าแรง/หน่วย
   - ชั้นที่เลือกได้: ฐานราก/ใต้ดิน · ชั้น 1 · ชั้น 2 · ชั้น 3 · หลังคา · ภายนอก · ทั้งหลัง (+ ชั้นอื่นที่มีในรายการ เช่น ชั้นลอย)
3. สรุป: วัสดุรวม · แรงรวม · ต้นทุน · +กำไร · +VAT · **รวมทั้งสิ้น** → `บันทึก BOQ` (เลข BOQ-ปี-ลำดับ)
4. **`→ ราคาขาย`** — ตกลง = สร้างงวดลูกค้า 1 งวดเท่ายอด BOQ · ยกเลิก = ตั้งราคาขายตัวบ้านเท่ายอด BOQ

**ปุ่มในรายการ BOQ:** `→ ราคาขาย` · `แก้ไข` · **`📄 สรุปวัสดุ`** · `🖨` (พิมพ์ BOQ) · **`Excel`** · `✕`
- **🖨 พิมพ์ BOQ** — "รายการประมาณราคาก่อสร้าง (BILL OF QUANTITY)" จัดกลุ่มตามหมวด
- **Excel** — ไฟล์หลาย sheet: **สรุป** (ชั้น × ประเภทงาน) · **รวมทั้งงาน** · **ข้อมูลทั้งหมด** (กรอง/ทำ Pivot ได้) · **แยกชั้น** (sheet ละชั้น) · **แยกระบบงาน** — ชุดนี้เป็น **ปริมาณอย่างเดียว** · ท้ายไฟล์มี sheet **"BOQ (ราคา)"** แบบเดิมที่มีราคา

### 📄 สรุปวัสดุ (PDF / Excel)
เปิดได้จากปุ่ม **`📄 สรุปวัสดุ`** ในรายการ BOQ หรือจากหน้าถอดแบบ — เอกสาร A4 "สรุปปริมาณวัสดุ" 3 ส่วน
1. **ภาพรวม** แยก ชั้น × ประเภทงาน (จำนวนรายการวัสดุ · หรือมูลค่าเมื่อแสดงราคา)
2. **รายการวัสดุรวมทั้งงาน** — วัสดุชนิดเดียวกันจากทุกชั้นรวมเป็นแถวเดียว แยกตามประเภทงาน
3. **รายการวัสดุแยกตามชั้น · ประเภทงาน · ส่วนงาน** — หัวส่วนงานแสดงเลขแผ่นแบบและ **ปริมาณงานที่วัดจากแบบ** (เช่น พื้นที่พื้น 25.5 ตร.ม. · คานยาว 42 ม.) ใต้ชื่อวัสดุคือวิธีคิดปริมาณ

- ค่าเริ่มต้น **ไม่แสดงราคา** — มีแค่ ชั้น · ประเภทงาน · ส่วนงาน · วัสดุ · จำนวน · หน่วย (ชื่อ/สเปกตามแบบ) เหมาะส่งให้ช่าง/ร้านค้า
- ติ๊ก **`แสดงราคา`** เพื่อดู ค่าวัสดุ · ค่าแรง · รวมต้นทุน (ราคาเป็นต้นทุนก่อนค่าดำเนินการ/กำไร และ VAT · ชื่อวัสดุเป็นชื่อตามราคากลางที่ผูกไว้)
- **`🖨 พิมพ์ / PDF`** → เลือกปลายทาง "บันทึกเป็น PDF" (พิมพ์ได้ครบทุกหน้าแม้รายการยาว) · **`⬇ Excel`** → หลาย sheet แบบเดียวกับข้างบน (ราคาออกตามที่ติ๊ก "แสดงราคา")

### 📐 ถอดจากแบบ → BOQ ร่าง (ใหม่)
ให้ระบบอ่านไฟล์แบบ ถอดปริมาณงาน และจับคู่ราคากลางวัสดุ/ค่าแรงให้ แล้วคนตรวจแก้ก่อนสร้าง BOQ

1. หน้า BOQ (หรือแท็บ BOQ ในบ้าน) กด **`📐 ถอดจากแบบ`**
2. ส่วน **"ไฟล์แบบ + ข้อมูลบ้าน"**
   - เลือก **บ้าน / โครงการ** แล้ว **ติ๊กไฟล์แบบที่อยู่ในเอกสารของบ้าน** หรือ **อัปโหลดไฟล์ใหม่**
   - ชนิดไฟล์: **PDF / รูป เลือกหลายไฟล์ได้** (AI อ่านพร้อมกัน) · **DWG / DXF ถอดได้ทีละ 1 ไฟล์** (DWG แปลงเป็น DXF ด้วย ODA File Converter บนเครื่องเซิร์ฟเวอร์) · ไฟล์ใหญ่ได้ถึงประมาณ 210MB
   - ข้อมูลบ้านคร่าวๆ: **พื้นที่ใช้สอย (ตร.ม.)** · **จำนวนชั้น** · **สูงฝ้า (ม.)** · **ยกพื้น (ม.)** · หน่วยในไฟล์ (มิลลิเมตร/เซนติเมตร/เมตร — เฉพาะ DWG/DXF) · **สเปก / หมายเหตุ** (เช่น ท่อ PVC ชั้น 13.5 · สุขภัณฑ์ COTTO · ผนังอิฐมอญ)
3. กด **`ถอดแบบ`** → ระบบทำงานเบื้องหลัง แสดง "กำลังถอดแบบ…" พร้อมเวลาที่ผ่านไป (AI อ่านแบบได้นานถึง 10 นาที · ปิดหน้าต่างค้างไว้ได้)
4. ผลลัพธ์ (แต่ละส่วนยุบ/ขยายได้ · ปุ่ม `ยุบทุกหมวด` / `ขยายทุกหมวด`)
   - **ข้อสังเกตจาก AI**
   - (DXF) **อ่านจากไฟล์:** ความยาวตาม Layer (ม.) · พื้นที่ตาม Layer (ตร.ม.) · วงกลม · บล็อก
   - **รายการที่ถอดได้ — วัสดุ** จัดกลุ่ม **ชั้น → ประเภทงาน → ส่วนงาน** (AI ระบุชั้นและส่วนงานให้ทุกแถว พร้อม **เลขแผ่นแบบ** · แก้ชั้น/ส่วนงานได้) · หัวแต่ละกลุ่มแสดง **ปริมาณงาน** ที่วัดจากแบบ (ตร.ม. / ม. / ต้น) · ในแต่ละแถว: ติ๊กใช้/ไม่ใช้ · รายการ · จำนวน · หน่วย · วิธีคิดปริมาณ (เช่น "ผนังยาว 40 ม. x สูง 2.8 ม.") · ความเชื่อมั่น (สูง/กลาง/ต่ำ) · **ราคากลางวัสดุ** (เลือกตัวที่จับคู่ หรือ "— ไม่มีในราคากลาง (กรอกเอง) —") · ตัวกรอง **เฉพาะยังไม่มีราคา**
   - **🌐 ราคาจากเว็บ** — วัสดุที่ไม่มีในราคากลาง ให้ AI ค้นราคาตลาดจากร้านวัสดุไทย (แสดงร้าน / ลิงก์ / ช่วงราคา · ใช้ชั่วคราว ไม่บันทึกเข้าราคากลางเอง) · ต้องการเก็บถาวรกด **`+ เพิ่มเข้าราคากลาง`**
   - **ค่าแรง (ค่าแรง + วัสดุสิ้นเปลือง)** — คิดตาม **ปริมาณงาน** (ตร.ม. ผนัง / พื้นที่บ้าน / เมตร / ชุด) ตามราคากลางค่าแรง ไม่ได้คิดตามจำนวนวัสดุ · `+ เพิ่มค่าแรง` แล้วเลือกหมวดค่าแรง
   - สรุป ค่าวัสดุ · ค่าแรง · **รวมต้นทุน** (ค่าดำเนินการ/กำไร และ VAT ตั้งในขั้นถัดไป)
5. ดู **สรุปวัสดุ** จากผลถอดแบบได้ทันที (PDF/Excel — ดูหัวข้อถัดไป)
6. กดสร้าง → เปิดฟอร์ม BOQ ร่างพร้อมรายการ (เก็บ ชั้น / ส่วนงาน / ปริมาณงาน ไว้ด้วย) → ตรวจ ตั้ง % กำไร/VAT → `บันทึก BOQ`

> 💡 AI ถอดเฉพาะงานใหม่ตามแบบ (ไม่ถอดโครงสร้างเดิมที่มีอยู่แล้ว) และแยกปริมาณตามชั้น ไม่ได้รวมทั้งหลังเป็นก้อนเดียว
> 💡 งานถอดแบบไม่หายแม้เซิร์ฟเวอร์รีสตาร์ต · DXF นับเฉพาะ Model space (ไม่นับหน้า Layout) และนับบล็อกซ้อน/บล็อกในกลุ่มที่ copy มาได้ถูกต้อง
> ⚠️ ผลถอดแบบเป็น **ร่าง** — ตรวจปริมาณและราคาทุกแถวก่อนใช้เสนอราคา · ต้องตั้งกุญแจ AI แล้ว · ถ้าเกิดข้อผิดพลาดระบบแจ้งเป็นข้อความไทย (เช่น "อัปโหลดไม่สำเร็จ") · กด `ถอดใหม่` เพื่อทำซ้ำ

### กระแสเงินสด (ประมาณการ)
1. เลือกเดือนเริ่ม + จำนวนเดือน (3/6/9/12) → `+ สร้างตาราง`
2. เลือกบ้าน · เงินยกมา · กรอกเงินรับ (งวดงาน/เงินดาวน์/อื่นๆ) และเงินจ่าย (วัสดุ/แรงงาน/รับเหมาช่วง/เครื่องจักร/Office Site/บริหาร/ขนส่ง/ธรรมเนียม)
3. ระบบคิด รวมรับ · รวมจ่าย · สุทธิ · คงเหลือปลายงวด · **`↻ ดึงยอดจริง`** เติมยอดจริงให้ตามปี-เดือนของแต่ละช่อง (ไม่นับรายจ่ายที่ถูกปฏิเสธ) → `บันทึก` (CF-ปี-ลำดับ)

### บัญชีรับ-จ่าย
การ์ด รายรับ/รายจ่าย/คงเหลือ · ตัวกรอง บ้าน/ประเภท/ช่วงเวลา · ตาราง (รายการ "อัตโนมัติ" ดึงจากงวดและรายจ่าย ลบไม่ได้) · กล่อง "งบ vs ใช้จริง" · **`+ บันทึกรายการ`** (ไม่ลงบัญชี GL)

- **`↻ ดึงสัญญาจากบ้าน`** (สร้างทะเบียนจากบ้านที่มีเลขที่สัญญา)
- **`+ ขึ้นทะเบียนเอกสาร`** → หมวด · ชื่อ * · เลขที่ · เวอร์ชัน (A) · วันที่ · เจ้าของ · บ้าน · สถานะ · **วันหมดอายุ** (ใบอนุญาต — ขึ้นป้ายแดงเมื่อเลย) · หมายเหตุ
- **`+ เวอร์ชัน`** (Rev. ใหม่ + รายละเอียดการแก้) · **ประวัติ** · สถานะเปลี่ยนในตาราง (ใช้งาน/ยกเลิก/ฉบับร่าง/รออนุมัติ)

## 5.8 เคล็ดลับบัญชี
1. ปิดงวดแล้ว รายการย้อนหลังลงไม่ได้ — เลื่อนวันปิดก่อน แล้วกด `↻ สร้างบัญชีจากข้อมูลเดิม`
2. สงสัยยอดไม่ตรง กด `↻ สร้างบัญชีจากข้อมูลเดิม` ได้เสมอ (ไม่สร้างซ้ำ)
3. ตั้ง **วันครบกำหนด** ให้งวดงานทุกงวด อายุหนี้และการเตือนจึงจะถูก
4. เงินสดย่อยที่ร้านไม่มีบิล ให้เว้นเลขบิลว่าง จะได้ RV ให้ผู้รับเงินเซ็น

# ส่วนที่ 6 · การขาย / ลูกค้า (CRM)

## 6.1 เอกสารขาย

**ใครใช้ได้:** ทุกคนเห็น · สร้าง/แปลง/เซ็นสัญญา = admin / บัญชี / site · ลบ = admin / บัญชี

**หน้าจอ:** "เอกสารทั้งหมด x/y ฉบับ" · ค้นหา "ค้นหาเลขที่/ลูกค้า/สถานะ" · **`+ สร้างเอกสาร`** · ตาราง ประเภท · เลขที่ (📎 ไฟล์ใบเก่า, อ้างอิง) · ลูกค้า (🏠) · วันที่ · ยอดสุทธิ · สถานะ · ปุ่ม `เซ็นสัญญา` / `→ ใบแจ้งหนี้` / `→ ใบเสร็จ` / `พิมพ์` / `ลบ`

**สร้างเอกสาร**
1. `+ สร้างเอกสาร` → **ประเภท** ใบเสนอราคา / ใบแจ้งหนี้ / ใบเสร็จรับเงิน
2. **ผูกกับบ้าน** (เติมชื่อลูกค้าให้) · **ชื่อลูกค้า ***
3. รายการ · จำนวน · ราคา/หน่วย (`+ เพิ่มแถว`)
4. **ภาษีมูลค่าเพิ่ม:** `รวม VAT — บวก 7%` (ค่าเริ่มต้น) / `ไม่รวม VAT` (ไม่มีบรรทัดภาษี) / `ราคาที่กรอกรวม VAT แล้ว (ถอด 7/107)`
5. **`บันทึก + พิมพ์`** → เลข `QT-` / `INV-` / `RC-ปี-ลำดับ` · สถานะเริ่มต้น QT/INV = "รออนุมัติ" · RC = "ชำระแล้ว"

**นำเข้าใบเก่าด้วย AI** (กล่อง "📄 มีใบเก่า (PDF/รูป)?")
1. `📤 อัปโหลดไฟล์` (≤ 40MB)
2. เลือก ประเภท / แบบภาษี / บ้าน **ก่อน**
3. `🤖 ให้ AI อ่านรายการ` (ดึงรายการ จำนวน ราคา ชื่อลูกค้า) หรือ `📎 แนบอย่างเดียว`
4. ตรวจ/แก้ราคาให้เป็นปัจจุบัน → บันทึก (ไฟล์แนบอยู่กับเอกสาร 📎)

**Workflow:** ใบเสนอราคา **→ ใบแจ้งหนี้** (คัดลอกรายการ+โหมด VAT, ใบเดิมเป็น "ออกใบแจ้งหนี้แล้ว") **→ ใบเสร็จ** (ใบแจ้งหนี้เป็น "ชำระแล้ว") · ออกซ้ำจากใบเดิมไม่ได้

**เซ็นสัญญา** (ใบเสนอราคาที่ยังไม่เซ็น): ตั้งชื่อบ้าน → ระบบ **สร้างบ้านใหม่** (NEW-0001 ต่อเลข, เพิ่งเริ่ม, มูลค่า = ยอดใบ) + **งวดลูกค้า 7 งวด** มาตรฐาน

| งวด | % |
|---|---|
| มัดจำ | 10 |
| ฐานราก | 15 |
| โครงสร้าง | 20 |
| ก่อผนัง/หลังคา | 20 |
| งานระบบ/ฝ้า | 15 |
| สี/สุขภัณฑ์ | 15 |
| ส่งมอบ | 5 |

> ⚠️ ลบไม่ได้ถ้ามีใบที่ออกต่อแล้ว (ลบใบปลายทางก่อน) หรือเซ็นสัญญาแล้ว · เอกสารขาย **ไม่ลงบัญชี GL** แต่ VAT ของ INV/RC นับเป็นภาษีขายใน "สรุปภาษี" และไฟล์ Express · ใบเสร็จของงวดงาน (ในบ้าน) เป็นคนละใบกับใบเสร็จของเอกสารขาย

## 6.2 ลูกค้า (CRM)

**แท็บ:** 👤 ลูกค้า (360°) · 🎯 Lead / Pipeline · 🛠 เคสบริการ / แจ้งซ่อม (ทุกคน) · ⭐ NPS / บอกต่อ · 💬 LINE ลูกค้า & อัตโนมัติ · 📊 รายงาน CRM (admin / บัญชี / ผู้จัดการ)

> 💡 **ผูกลูกค้ากับบ้านอัตโนมัติ** จากชื่อลูกค้าในบ้าน (ตัดคำนำหน้า นาย/นาง/คุณ) — ไม่มีชื่อในทะเบียน ระบบสร้างให้ · ลูกค้าทุกรายได้ รหัส `CUS-xxxx`, รหัสบอกต่อ `REF-xxxxx`, ลิงก์พอร์ทัลส่วนตัว

### 👤 ลูกค้า 360°
- ค้นหา "ชื่อ/เบอร์/รหัส/โครงการ" · **`+ เพิ่มลูกค้า`** (ชื่อ * · เบอร์ · อีเมล · โครงการ/แบบบ้าน · สถานะ สนใจ/กำลังคุย/ปิดการขาย/ยกเลิก · ที่อยู่)
- **คลิกลูกค้า → แผง 360°**
  - หัว: ข้อมูลติดต่อ · ผู้ดูแล · ช่องทาง · ● LINE · รหัสบอกต่อ · **🔗 พอร์ทัลลูกค้า ↗**
  - ปุ่ม **💬 ผูก LINE ลูกค้า** · **📬 ส่งความคืบหน้า** · **✉ ส่งข้อความ** · **⭐ ขอคะแนน** · **✎ แก้ไข** (รวม วันเกิด YYYY-MM-DD, ติ๊กบ้านของลูกค้า) · ✕
  - **📌 ต้องทำต่อ** (⛔ เลยกำหนด) → `✓ ทำแล้ว`
  - **การ์ดบ้าน:** ความคืบหน้าจาก QC x/10 เฟส · งวดเงิน · เคสค้าง · รูป QC ล่าสุด · 🛡 ประกัน · ปุ่ม `กำลังแก้` / `✓ ปิดเคส`
  - **🗒 บันทึกการติดต่อ / Timeline:** ช่องทาง (โทร/LINE/นัดพบ/ไซต์วิสิต/อีเมล) · คุยอะไร · **ต้องทำต่อ + วันนัด** (ขึ้นกระดิ่ง) · บ้าน → `+ บันทึก`
  - 📄 เอกสารขาย (จับคู่ด้วยชื่อลูกค้า) · 🤝 ลูกค้าที่แนะนำมา

**ผูก LINE ลูกค้า**
1. `💬 ผูก LINE ลูกค้า` → ได้รหัส 6 หลัก (ใช้ได้ 24 ชม.)
2. ส่งรหัสให้ลูกค้า → ลูกค้าเพิ่มเพื่อน LINE OA บริษัท แล้วพิมพ์รหัสส่งมา
3. ระบบผูก + ส่งข้อความทักทายพร้อมเมนู

**คำสั่งที่ลูกค้าพิมพ์ใน LINE ได้**
| คำสั่ง | ระบบตอบ |
|---|---|
| ความคืบหน้า | % + ขั้นตอน QC + งวดถัดไป + รูปล่าสุด |
| งวด | ตารางงวดเงิน |
| เอกสาร | เอกสารขาย + ไฟล์บ้าน + ลิงก์พอร์ทัล |
| แจ้งซ่อม … (+รูป, พิมพ์ "ส่ง") | เปิดเคส |
| เคส | สถานะเรื่องที่แจ้ง |
| ประกัน | รายการรับประกัน + วันหมด |
| บอกต่อ | รหัส REF |
| ติดต่อ | เบอร์/LINE ทีมงาน |
| ช่วย | เมนูคำสั่ง |

ข้อความอื่นเข้า timeline และแจ้งโฟร์แมน/ผู้ดูแลบ้าน + ผู้บริหาร

### 🎯 Lead / Pipeline
**ขั้น:** สนใจ → นัดคุย → เสนอราคา/แบบ → ต่อรอง → เซ็นสัญญา (· ยกเลิก)
**ช่องทาง:** Facebook · LINE OA · เว็บไซต์ · บอกต่อ · ป้าย/หน้างาน · โทรเข้า · อื่นๆ

1. **`+ เพิ่ม Lead`** → ชื่อ * · เบอร์ · LINE ID · ช่องทาง · แบบบ้านที่สนใจ · มูลค่าประมาณ · **นัดติดตามครั้งถัดไป** · รหัสบอกต่อ (ใส่ REF → ผูกผู้แนะนำอัตโนมัติ) · โน้ต → เลข `LD-ปี-ลำดับ`
2. มุมมอง **☰ ตาราง** / **▦ Kanban** — การ์ดเลื่อนขั้นด้วย ◀ / ▶ · Lead เงียบเกิน 3 วันขึ้น ⚠ + กระดิ่ง
3. คลิกการ์ด → แก้ข้อมูล · **ประวัติติดตาม** (`+`) · **`✓ ปิดการขาย → ลูกค้า`** (ใส่รหัสบ้าน/ชื่อบ้าน/มูลค่า → สร้างลูกค้า + บ้านให้)

### 🛠 เคสบริการ / แจ้งซ่อม (SLA)
- "เคสค้าง n · เกิน SLA n" · `ดูทั้งหมด` / `เฉพาะค้าง` · **`+ เปิดเคสให้ลูกค้า`** (บ้าน · เรื่อง * · ความเร่งด่วน · ประเภท แจ้งซ่อม/สอบถาม/ร้องเรียน/ตรวจบ้านหลังส่งมอบ · รายละเอียด)
- ตาราง: เคส `CS-ปี-ลำดับ` · บ้าน/ลูกค้า · เรื่อง (📷) · ผู้รับผิดชอบ · SLA · สถานะ (⛔ เกิน SLA / 🟡 รอรับเรื่อง / 🔧 / ✅)
- แผงรายละเอียด: เปลี่ยน **ผู้รับผิดชอบ** · **สถานะ** รอช่าง / กำลังแก้ไข / รออะไหล่ / นัดลูกค้า / แก้ไขแล้ว / ยกเลิก · บันทึกความคืบหน้า · ประวัติ

**Workflow เคส:** ที่มา LINE / พอร์ทัล / เว็บ / นัดตรวจอัตโนมัติ → สถานะ "รอช่าง" · **SLA 24 ชม.** (ตั้งได้) · ผู้รับผิดชอบเริ่มต้น = ผู้จัดการบ้าน · แจ้ง LINE ทีม → ทุกการเปลี่ยนสถานะแจ้งลูกค้าอัตโนมัติ → ปิดเคส = ขอคะแนน NPS

### ⭐ NPS / บอกต่อ
- **NPS** = %ผู้ให้ 9–10 − %ผู้ให้ 0–6 · เฉลี่ย · ประทับใจ · ไม่พอใจ · Lead จากการบอกต่อ
- ระบบถามคะแนนทาง LINE อัตโนมัติเมื่อ: ผ่าน QC เฟส 5 · ส่งมอบบ้าน · ปิดเคส · หรือกด ⭐ ขอคะแนน
- คะแนน **≤ 6** → LINE เตือนผู้บริหารให้โทรหาลูกค้าภายในวัน

### 💬 LINE ลูกค้า & อัตโนมัติ (เปิด-ปิดรายข้อ)
- ความคืบหน้าประจำสัปดาห์ (+รูป, เลือกวัน) · เตือนงวดเงินล่วงหน้า n วัน · แจ้งผ่าน QC ครบเฟส · ส่งมอบบ้าน (ยินดี + ประกัน + NPS) · ครบรอบเข้าบ้าน/วันเกิด · ประกันใกล้หมด 30 วัน · **นัดตรวจบ้านฟรี 6/12 เดือน** (เปิดเคสให้อัตโนมัติ)
- ตั้งค่า: เวลาส่ง · SLA (ชม.) · เดือนตรวจบ้าน · เบอร์ทีมงาน · LINE ทีมงาน
- **🛡 รายการรับประกัน** (นับจากวันส่งมอบ): โครงสร้าง 5 ปี · หลังคา/รั่วซึม 1 ปี · ไฟฟ้า-ประปา 1 ปี · สี-ฝ้า 1 ปี (เพิ่ม/ลบได้)
- `บันทึกการตั้งค่า` · `▶ รันตอนนี้` (ปกติรันอัตโนมัติทุก 10 นาที)

> ⚠️ ประกันเริ่มนับเมื่อบ้านสถานะ "ส่งมอบแล้ว"/"after-service" และ **กำหนดส่งมอบเป็นวันที่ที่อ่านได้** (ปี-เดือน-วัน)

### 📊 รายงาน CRM
ลูกค้าทั้งหมด (ผูก LINE) · Lead เปิดอยู่ · อัตราปิดการขาย · เวลาปิดเฉลี่ย · มาจากบอกต่อ · เคสค้าง/เกิน SLA/เวลาแก้เฉลี่ย · NPS · กราฟ Lead 6 เดือน · ช่องทางที่ได้ลูกค้า · Pipeline ตามขั้น

# ส่วนที่ 7 · ภาพรวม / ผู้บริหาร

## 7.1 หน้าสรุป (Dashboard)

**ใครใช้ได้:** ทุกคน · ตัวเลขเงินรวมเห็นเฉพาะ admin / บัญชี / ผู้จัดการ / ตำแหน่ง "บุคคล" (คนอื่นเห็น "—") · ตาราง "สรุปกำไรทุกหลัง" เห็นเฉพาะผู้จัดการ

**องค์ประกอบ (บนลงล่าง)**
1. **แถบ "สุขภาพระบบ:"** ป้ายเขียว ✓ / แดง ✕
   - `เจ้าหนี้ตรงบัญชี` / `เจ้าหนี้เพี้ยน …`
   - `ลงบัญชีครบ` / `ลงบัญชีค้าง N รายการ`
   - `สำรองล่าสุด <วันที่>` / `สำรองค้าง` (เกิน 2 วัน)
   - `สำรองนอกเครื่องปกติ` / `ล้มเหลว` / `ยังไม่ตั้งสำรองนอกเครื่อง`
   - `งวดข้อมูลแย้ง N งวด` · `วัสดุใกล้หมด N รายการ`
2. **การ์ด 8 ใบ:** กำลังสร้าง · ส่งมอบแล้ว · After-service · รายรับสะสม · เงินรอเก็บ · รายจ่าย · **เงินสดสุทธิ** (= เงินสด+ธนาคารตามบัญชีแยกประเภท) · งวดเลยกำหนด
3. **ภาพรวมการเงิน** (กราฟแท่ง) และ **บ้านตามสถานะ**
4. **สรุปกำไรทุกหลัง** (ผู้จัดการ): บ้าน · ขายลูกค้า · จ่ายช่าง · วัสดุจริง · กำไรสุทธิ — คลิกแถวเปิดบ้าน
5. **กล่องเตือน 3 กล่อง:** งวดเลยกำหนด (เลย N วัน) · เงินที่ควรไปเก็บ · เงินล่วงหน้าช่างค้างหัก
6. **ภาพรวมแต่ละโครงการ** · **ความคืบหน้าบ้านแต่ละหลัง** (`ดูทั้งหมด →`) · **ปัญหาหน้างานค้างอยู่**

> 💡 ถ้าแถบสุขภาพระบบมีป้ายแดง ให้แก้ก่อนใช้ตัวเลขตัดสินใจ — เช่น "ลงบัญชีค้าง" ไปดูที่หน้า **บัญชีแยกประเภท**, "สำรองค้าง" ไปกด **สำรองข้อมูล** ที่หน้าผู้ใช้งาน

## 7.2 แผนงาน (Gantt / S-Curve)

**ใครใช้ได้:** ทุกคนดู · เพิ่ม/อัปเดตต้องมีสิทธิ์เขียน

- **ความคืบหน้าบ้าน** (คิดจากงวดที่เก็บเงินแล้ว)
- **S-Curve · แผน vs ทำได้จริง** — เลือก "ทุกบ้าน" หรือรหัสบ้าน · แสดง "ตามแผน x%" · "ทำได้จริง y%" · "เร็วกว่า/ช้ากว่าแผน z%"
- **ไทม์ไลน์ก่อสร้าง** — แท่งเวลาต่องาน · ช่อง % แก้ได้ (บันทึกเมื่อคลิกออก) · สถานะ `วางแผน` / `กำลังทำ` / `เสร็จ` / `ล่าช้า`

**เพิ่มงาน:** `+ เพิ่มงาน` → หน้าต่าง "เพิ่มงานในแผน" → ชื่องาน * · รหัสบ้าน (พิมพ์ให้ตรง) · วันเริ่ม * · วันจบ * · น้ำหนัก% · สถานะ → `บันทึก`

**สูตร:** ตามแผน = Σ(น้ำหนัก × สัดส่วนเวลาที่ผ่านไป) ÷ Σน้ำหนัก · ทำได้จริง = Σ(น้ำหนัก × %) ÷ Σน้ำหนัก (ไม่ใส่น้ำหนัก = 1)

> ⚠️ ยังลบงาน/แก้ชื่อ/แก้วันที่ไม่ได้ (แก้ได้เฉพาะ % และสถานะ) · % ในแผนงานไม่เปลี่ยน % ของบ้าน แต่ถูกดึงไปใส่ **รายงานหน้างาน**

## 7.3 รายงาน (Reports)

**ใครใช้ได้:** admin / accounting เท่านั้น (คนอื่นเห็น "ไม่มีสิทธิ์ดูรายงาน")

1. **แถบเครื่องมือ:** เลือกเดือน · **`📊 เปิดรายงานผู้บริหาร`** · **`🖨 พิมพ์ / บันทึก PDF`**
2. **KPI 4 ใบ:** มูลค่าสัญญารวม · เก็บเงินแล้ว · **รายจ่ายรวม** (รายจ่าย + ค่าจ่ายช่าง + ใบจ่ายเงิน — เท่ากับเงินออกในงบกระแสเงินสด) · กำไรเบื้องต้น (= เก็บแล้ว − รายจ่ายรวม)
3. **กำไร-ขาดทุนรายโครงการ** (กราฟ + `ส่งออก Excel`)
4. **งบกระแสเงินสด (สะสม):** เงินเข้า (เก็บจากลูกค้า) · เงินออก (จ่ายช่าง / วัสดุ / เงินเดือนงวดที่ปิดแล้ว / จ่ายอื่นๆ) · กระแสเงินสดสุทธิ
5. **งบประมาณต้นทุน vs จ่ายจริง** ต่อบ้าน (ติดลบ = "เกินงบ" สีแดง) + `ส่งออก Excel`
6. **ต้นทุนแยกตามหมวด** (กราฟโดนัท)

### รายงานผู้บริหารประจำเดือน
เอกสาร A4: กำไรสุทธิเดือนนี้ (ตาม GL) · เงินสด+ธนาคารปลายเดือน (▲/▼) · ลูกหนี้ − เจ้าหนี้ · งบกำไรขาดทุนจาก GL · การใช้จ่ายเดือนนี้ · ยอดค้าง ณ วันนี้ (ลูกหนี้/เจ้าหนี้ + ส่วนที่เลยกำหนด) · สถานะงาน
- ปุ่ม **`💬 ส่งเข้า LINE`** (ส่งสรุปเข้ากลุ่ม/ผู้รับที่ตั้งไว้) · `🖨 พิมพ์` · `ปิด`
- ถ้ามีรายการลงบัญชีไม่สำเร็จ จะมีกล่องเตือนให้ตรวจหน้า **บัญชี** ก่อน

## 7.4 สรุป QC (ผู้บริหาร)

**ใครใช้ได้:** CEO / ผู้ดูแลระบบ — ต้องใส่ **PIN ของตัวเอง** แล้วกด `เข้าดูสรุป` ทุกครั้ง

- การ์ด 5 ใบ: ใบตรวจทั้งหมด · **อัตราผ่าน %** (เขียว ≥90 · ส้ม ≥75 · แดง) · ต้องแก้ไข · กำลังตรวจ · เลยกำหนด
- **ผลงานตามผู้ตรวจ (ผูก KPI):** ผู้ตรวจ · ตรวจ · ผ่าน · อัตราผ่าน + ปุ่ม `→ KPI`
- **ตามบ้าน / โครงการ** · **⚠ ใบตรวจเลยกำหนดเสร็จ**

## 7.5 สั่งงานด้วยเสียง (CEO)

**ใครใช้ได้:** CEO / ผู้ดูแลระบบ — ใส่ PIN แล้วกด `เข้าใช้งาน`

**ขั้นตอน**
1. พิมพ์ในช่อง หรือกด **`🎤 พูด`** (เบราว์เซอร์ที่รองรับเสียงไทย · มือถือใช้ไมค์บนคีย์บอร์ดได้) เช่น *"ให้สมชายไปแก้หลังคาบ้าน A ด่วน"*
2. **`ถัดไป — ตรวจใบสั่งงาน`** — ระบบเดา ผู้รับ (ชื่อ/ชื่อเล่น รองรับ พี่/ช่าง/คุณ/น้อง) · บ้าน · ด่วน ("ด่วน/เร่งด่วน/urgent") · กำหนดส่ง ("วันนี้/พรุ่งนี้")
3. ตรวจกล่อง "ตรวจสอบก่อนออกใบสั่งงาน" — ผู้รับงาน * · บ้าน · กำหนดส่ง · ติ๊ก "🔴 งานด่วน — ต้องรับภายใน N นาที" · รายละเอียด *
4. **`✅ ตรวจแล้ว — ออกใบสั่งงาน`** → ได้ `WO-ปี-NNN` และส่ง LINE ถึงผู้รับ

**งานด่วน:** ถ้ายังไม่มีคนรับทราบ ระบบ **ไล่ระดับ** ไปคนสำรองทุก N นาที (ตั้งในข้อมูลพนักงาน) ครบเวลาแล้วยังไม่มีคนรับ → สถานะ **เกินเวลา** ส่งให้ "ตัวจบสาย" และแจ้ง CEO · หัก KPI −10
- **`⚙ ตั้งค่างานด่วน`**: ต้องรับภายใน (ค่าเริ่มต้น 5 นาที) · ไล่ระดับทุก (2 นาที) · ตัวจบสาย — บันทึกได้เฉพาะ role admin
- กล่อง **สถานะงานด่วน** อัปเดตทุก 5 วินาที: รับทราบแล้ว / เกินกำหนด / เหลือ x นาที · ส่งถึง · 👁 เห็นแล้ว · ➡ ไล่ไปที่ · สายไล่ระดับ

## 8.1 ลงเวลา (Kiosk ในระบบ)

**ใครใช้ได้:** ทุกคน (ปิดรายโมดูลไม่ได้)

**หน้าจอ:** แถบ GPS ("📍 เช็คอินได้เฉพาะในรัศมี N ม." / "ได้ทุกที่") · นาฬิกา · "เลือกชื่อพนักงาน" · แป้น PIN · ปุ่ม **เข้างาน** (เขียว) / **ออกงาน** (แดง) · **🧾 ดูสลิปเงินเดือนของฉัน** · **🕒 ยื่นปรับปรุงเวลาเข้า-ออก (ลืมตอกบัตร)**

**ตอกบัตร:** (รายชื่อเฉพาะพนักงานที่ยังไม่ลาออก — คนที่ลาออกแล้วตอกบัตรและใช้บอท LINE ไม่ได้) เลือกชื่อ → ใส่ PIN 4 หลัก (PIN เดียวกับเข้าเว็บ) → `เข้างาน` / `ออกงาน` (อนุญาต GPS ถ้าเบราว์เซอร์ถาม) → "… เข้างาน HH:MM น. (สาย)"
- เข้างานซ้ำวันเดียวกันไม่ได้ · ออกก่อนเข้าไม่ได้
- **สาย** = เข้าหลัง 08:00 + ผ่อนผัน 5 นาที (ตั้งได้)
- เปิดจำกัดตำแหน่ง: ต้องเปิด GPS และอยู่ในรัศมี
- PIN ผิด 5 ครั้ง → ล็อก 5 นาที

**ดูสลิปของฉัน:** เลือกชื่อ + PIN → `🧾 ดูสลิปเงินเดือนของฉัน` → เลือกงวด (ย้อนหลัง 12 งวด) → `🖨 เปิดสลิป / พิมพ์` (เฉพาะงวดที่ทำจ่ายแล้ว)

**ยื่นปรับปรุงเวลา:** เลือกชื่อ + PIN → `🕒 ยื่นปรับปรุงเวลา…` → วันที่ · เข้า/ออก · เวลา · เหตุผล → `ยื่น`
> กติกา: ห้ามวันอาทิตย์ · ห้ามล่วงหน้า · **ย้อนหลังไม่เกิน 2 วัน** · ผู้จัดการอนุมัติที่ HR → ปรับปรุงเวลา

**ตั้งค่า (admin) `⚙️ ตั้งค่าตำแหน่ง`:** ยืนที่ออฟฟิศ → `📍 ใช้ตำแหน่งปัจจุบันเป็นออฟฟิศ` · รัศมี (≥20 ม., ค่าเริ่มต้น 200) · ติ๊ก "จำกัดให้เช็คอินเฉพาะในออฟฟิศ" · เวลาเข้างาน + ผ่อนผัน (0–120 นาที)

## 8.3 บุคลากร / HR — แท็บ

`พนักงาน` · `เงินเดือน` · `OT` · `ลงเวลา` · `สรุปลงเวลา (เดือน)` · `วันหยุด` · `ติดตามตำแหน่ง` (ผู้จัดการ/admin) · `ลางาน` · `ปรับปรุงเวลา` · `ภงด.1 / ประกันสังคม`

ตัวเลขเงินเดือน/ข้อมูลอ่อนไหวเห็นเฉพาะ admin / บัญชี / ผู้จัดการ / ตำแหน่ง "บุคคล"

### แท็บ พนักงาน
ค้นหา "ชื่อ/รหัส/ตำแหน่ง" · `🧹 ล้างข้อมูลซ้ำ` (admin) · **`+ เพิ่มพนักงาน`** · ตาราง รหัส · ชื่อ · ตำแหน่ง · ประเภทจ้าง · ลาป่วย / ลากิจ / พักร้อน (ใช้ไป/โควต้า) · ลายเซ็น · สถานะ · `แก้ไข` `PIN` `ลบ`

**เพิ่มพนักงาน**
1. `+ เพิ่มพนักงาน` (⤢ ขยายเต็มจอได้)
2. คำนำหน้า · **ชื่อ-สกุล *** · ชื่อเล่น · ตำแหน่ง · **ประเภทจ้าง** รายเดือน/รายวัน · เงินเดือน หรือ ค่าแรง/วัน · (รายวัน) วันทำงานตั้งต้น/เดือน · วันเริ่มงาน · สถานะ (ทดลองงาน/ทำงาน/ลาออก) · PIN ลงเวลา (เว้นว่าง = สุ่ม) · **คนสำรอง (งานด่วน)** · ลายเซ็น
3. **ลดหย่อนภาษี:** คู่สมรส · บุตร · ไม่หักประกันสังคม
4. **ข้อมูลจ่าย:** ธนาคาร · เลขบัญชี · เลขผู้เสียภาษี 13 หลัก · หัก Retention/เดือน (ปกติ 500, หยุดเมื่อครบ 5,000) · Retention สะสมมาแล้ว · หัก กยศ/เดือน
5. **วันลาที่ใช้ไปแล้ว** (เริ่มใช้ระบบกลางปี) — โควต้า ลาป่วย 30 · ลากิจ 3 · พักร้อน 3 (ไม่ถึง 1 ปี) / 6 (ครบ 1 ปี)
6. `บันทึก` → รหัส **EMP-###** + **สร้างบัญชีเข้าระบบให้อัตโนมัติ** (ชื่อผู้ใช้ เช่น `emp012`, บทบาท "หน้างาน")

> ⚠️ **จดชื่อผู้ใช้และ PIN ที่แถบเขียวทันที** — แสดงครั้งเดียว
> 💡 เปลี่ยนสถานะเป็น "ลาออก" = ปิดบัญชีเข้าระบบให้ · ปุ่ม `PIN` เปลี่ยน PIN ลงเวลา (PIN เข้าเว็บเปลี่ยนตาม) · ลายเซ็นในตารางใช้ประทับเอกสาร PR/อนุมัติ

### แท็บ OT
`+ เพิ่ม OT` → พนักงาน * · วันที่ · **ชั่วโมง** · **อัตรา** (1.5x / 2x / 3x) · จำนวนเงิน (ไม่บังคับ) → สถานะ "รออนุมัติ" → ผู้จัดการกด `อนุมัติ` หรือ `ไม่อนุมัติ`
- **ไม่กรอกจำนวนเงิน = ระบบคิดให้** ค่าจ้างต่อชั่วโมง × ชั่วโมง × อัตรา (รายเดือน: เงินเดือน ÷ 30 ÷ 8 · รายวัน: ค่าแรง ÷ 8)
- ตัดสินได้ครั้งเดียว (ใบที่อนุมัติ/ไม่อนุมัติแล้วกดซ้ำไม่ได้) · OT ที่อนุมัติแล้วเข้าเงินเดือนของเดือนนั้น

### แท็บ ลงเวลา
เลือกเดือน / ดูทั้งหมด · แถบ **เพิ่ม/แก้ไข:** พนักงาน · วันที่ · เข้า · ออก → **`บันทึกคนนี้`** · **`มาทำงานทั้งวัน (ทุกคน)`** (บันทึกให้ทุกคนที่ยังไม่มีบันทึกวันนั้น) · ตาราง + `แก้ไข` / `ลบ`

### แท็บ สรุปลงเวลา (เดือน)
คอลัมน์ มาทำงาน (ปรับปรุง N) · สาย · ขาด · ลา — **ขาด** = วัน จ.–ส. ที่ไม่มาและไม่มีใบลา/ปรับปรุงเวลา (ไม่นับอาทิตย์และวันหยุดบริษัท) · CEO/ผู้จัดการและรายวันขึ้น "ไม่ต้องลงเวลา"
- **คลิกชื่อ** → ดูรายวัน · วันที่ "ขาด" มีปุ่ม **`+ เติมมา`** (บันทึก 08:00–17:00)

### แท็บ วันหยุด
(admin) เลือกวันที่ + ชื่อวันหยุด → `+ เพิ่มวันหยุด` · ลบด้วย ✕ — วันหยุดไม่ถูกนับ "ขาด"
> 💡 **เพิ่มวันหยุดบริษัทล่วงหน้า** ไม่อย่างนั้นวันหยุดจะถูกนับขาดและหักเงิน

### แท็บ ลางาน
1. พนักงาน * · ประเภท (ลาป่วย/ลากิจ/พักร้อน) · วันเริ่ม–สิ้นสุด · จำนวนวัน
2. ลักษณะ: **เต็มวัน** / **ครึ่งวัน** (ครึ่งเช้า/บ่าย = 0.5) / **รายชั่วโมง** (8 ชม. = 1 วัน)
3. เหตุผล → `ยื่นใบลา` — ระบบแสดงสิทธิ์คงเหลือ และเตือนถ้าเกิน ("จะเป็นลาไม่รับเงิน")
4. ผู้จัดการกด `อนุมัติ` (ส่วนเกินสิทธิ์ = ลาไม่รับเงิน) / `ไม่อนุมัติ` (ถูกหักเงินทั้งหมด)

> 💡 กดอนุมัติซ้ำไม่นับวันลาซ้ำ · เปลี่ยนจากอนุมัติเป็นไม่อนุมัติ ระบบคืนวันลาให้ · **ขึ้นปีใหม่ตัวนับวันลาที่ใช้ไปเริ่มใหม่** · ใบลาที่คร่อมเดือน หักเงินแบ่งตามสัดส่วนวันของแต่ละเดือน

### แท็บ ปรับปรุงเวลา
ชื่อพนักงาน (เว้นว่าง = ตัวเอง) · วันที่ · เข้า/ออก · เวลา · เหตุผล → `ยื่นคำขอ` → ผู้จัดการ `อนุมัติ` / `ไม่อนุมัติ` — อนุมัติแล้วนับเป็นวันมาทำงาน

## 8.4 เงินเดือน


**ใครทำได้:** ดู = admin / บัญชี / ผู้จัดการ / บุคคล · **ทำจ่าย / บันทึกเบิก-หัก-รายได้ = admin / บัญชี**

**ส่วนบน:** การ์ดรวมจ่ายทั้งปี · ประกันสังคมสะสม · นำส่งรวม 2 ฝ่าย
**แถบเครื่องมือ:** เลือก **งวด** · ป้าย "ยังไม่ได้ทำจ่าย (คำนวณสด)" / "ทำจ่ายแล้ว X/Y คน" / "ทำจ่ายครบทุกคนแล้ว 🔒" · `🖨 สลิปทุกคน` · `🖨 ใบสรุปการจ่ายค่าจ้าง` · `⬇ ไฟล์จ่ายผ่านธนาคาร` · `⬇ ไฟล์ สปส.` · `⬇ ภงด.1ก` · `🧾 50 ทวิ` · **`↺ ดึงวันจากลงเวลา`** · **`💸 ทำจ่าย (N คนที่ยังไม่จ่าย)`**

**ตาราง "รอบจ่ายเดือนนี้":** รอบ `PAY-YYYYMM-n` · วันที่จ่าย · คน · สุทธิ · หมายเหตุรอบ · สถานะ (ปิดแล้ว·ลงบัญชีแล้ว / เปิดแก้ไขอยู่) · ปุ่ม 🖨 สลิป · 🖨 ใบสรุป · ⬇ ไฟล์ธนาคาร · ✎ · `เปิดแก้ไข` / `ปิดรอบอีกครั้ง` / `ยกเลิกรอบ`

**ตารางรายคน:** ชื่อ · **วันทำงาน (แก้ได้)** · ฐานเงิน · OT · รายได้อื่น · ปกส. · **ภาษี (แก้ได้)** · หักลา/ขาด · **Retention (แก้ได้)** · **กยศ (แก้ได้)** · เบิกล่วงหน้า · หักอื่นๆ · สุทธิ · **หมายเหตุ (ขึ้นในสลิป)** · พิมพ์
- **วันทำงาน:** รายเดือนเว้นว่าง = เต็มเดือน · รายวันเว้นว่าง = ตามลงเวลา · ใส่ครึ่งวันได้ (17.5) · **ห้ามเกินจำนวนวันในเดือน**
- คนที่จ่ายแล้วขึ้น "✓ จ่ายแล้ว · PAY-…" และล็อกทุกช่อง · คนที่ยังไม่จ่ายมีลิงก์ "ทำจ่ายคนนี้ก่อน"

### ขั้นตอนทำจ่าย (แนะนำ)
1. เลือก **งวด**
2. ตรวจ ลงเวลา / ลา / OT / ปรับปรุงเวลา ให้ครบและอนุมัติแล้ว
3. กด **`↺ ดึงวันจากลงเวลา`** (⚠️ แทนค่าที่กรอกเองของทุกคนที่ยังไม่จ่าย — กดก่อนแก้รายคน)
4. ตรวจ/แก้ วันทำงาน ภาษี Retention กยศ หมายเหตุ
5. บันทึก **เบิกล่วงหน้า / รายได้อื่นๆ / หักอื่นๆ** (ใต้ตาราง)
6. **`💸 ทำจ่าย`** → วันที่จ่าย · หมายเหตุของรอบ · ติ๊กพนักงาน (เลือกทั้งหมด/ไม่เลือกเลย) → **`ยืนยันทำจ่าย N คน`** (คนสุทธิติดลบทำจ่ายไม่ได้)
7. ได้รอบ `PAY-…` ตัวเลขถูกล็อก + **ลงบัญชีให้อัตโนมัติ** · คนที่เหลือทำจ่ายรอบถัดไปได้ (1 คน/เดือน/รอบเดียว)

**แก้หลังทำจ่าย:** ✎ แก้วันที่/หมายเหตุ · `เปิดแก้ไข` (ถอนบัญชีของรอบ คำนวณสด) → แก้ → **`ปิดรอบอีกครั้ง`** (อย่าลืม) · `ยกเลิกรอบ` (เฉพาะรอบที่เปิดอยู่)

### ส่วนย่อยใต้ตาราง
- **เบิกเงินเดือนล่วงหน้า:** พนักงาน · จำนวน · หมายเหตุ → `บันทึกเบิก` — **เพดาน = ค่าจ้าง/วัน × วันมาทำงาน ÷ 2** (รายเดือน ค่าจ้าง/วัน = เงินเดือน ÷ 30) · หักคืนจากสุทธิของงวด
- **รายได้อื่นๆ:** โบนัส / เบี้ยขยัน / ค่าคอม → `บันทึกรายได้`
- **หักอื่นๆ:** ค่าปรับ / ของเสียหาย → `บันทึกหัก`
- **Retention สะสมต่อคน:** หัก/เดือน · สะสม (X/5,000) · สถานะ

### สูตรคำนวณ
| รายการ | สูตร |
|---|---|
| ฐานเงิน รายเดือน | เงินเดือน (ไม่เต็มเดือน = เงินเดือน ÷ 30 × วัน) |
| ฐานเงิน รายวัน | ค่าแรง/วัน × วันทำงาน |
| OT | ผลรวม OT ที่อนุมัติในเดือน |
| หักลา/ขาด (รายเดือน) | (ลาไม่อนุมัติ + ลาไม่รับเงิน + ขาด) × (เงินเดือน ÷ 30) |
| ประกันสังคม | 5% ของค่าจ้าง เพดาน 17,500 → สูงสุด 875 บาท (นายจ้างสมทบเท่ากัน) |
| ภาษี | ค่าในตาราง (ระบบตั้งต้นให้ตอนสร้างพนักงานรายเดือนตามขั้นบันได) |
| Retention | min(หัก/เดือน, 5,000 − สะสม) — เดือนไม่มีรายได้ไม่หัก |
| **สุทธิ** | ฐาน + OT + รายได้อื่น + คืนประกัน − ปกส. − ภาษี − หักลา/ขาด − Retention − กยศ − เบิกล่วงหน้า − หักอื่นๆ |

> ⚠️ **ขาด** นับเฉพาะ จ.–ส. ระหว่างวันแรกถึงวันสุดท้ายที่ตอกบัตรในเดือน (ไม่ตอกเลย = ไม่หัก) · **ภาษีเป็นค่ากรอกเอง** ปรับเงินเดือนแล้วต้องแก้ภาษีด้วย · แก้ภาษี/Retention/กยศ ในตาราง = แก้ข้อมูลพนักงานถาวร

**ลงบัญชีอัตโนมัติต่อรอบ:** Dr 6010 / Cr 2050 ปกส. · 2040 ภาษี · 2020 Retention · 2060 กยศ/หักอื่น · ธนาคาร

## 8.6 ประเมินผล KPI (PMS)

**ใครใช้ได้:** CEO / admin — **ใส่ PIN ทุกครั้ง**

**ตั้งชุด KPI (`⚙ ชุด KPI ตามตำแหน่ง`)**
- ผูก **ตำแหน่ง → ชุด KPI** (บันทึกทันที) · `+ ชุด KPI ใหม่` / `คัดลอก` / `แก้ไข`
- ชุด KPI มี 3 ส่วน น้ำหนักรวมต้องครบ: **KPI 70** · **Competency 20** · **Behavior 10** (✓ เมื่อครบ)

**ประเมิน**
1. **`+ ประเมินผลรายเดือน`** → เลือกพนักงาน (ดึงชุด KPI + ผลย้อนหลัง 5 ครั้ง) · เดือน (เช่น 7/2568)
2. **KPI:** กรอก "ทำได้จริง %" · ปุ่ม **`↺ ดึงคะแนนใบสั่งงาน`** · **`↺ ดึงผลงาน QC`**
3. **Competency / Behavior:** คะแนน 1–5 (5 ดีเยี่ยม … 1 ไม่ผ่าน)
4. **วินัย:** `↺ ดึงจากลงเวลา + ใบสั่งงาน` (ขาด/ลา/สาย คิดจากเซิร์ฟเวอร์แบบเดียวกับเงินเดือน) หรือกรอก ขาด / สาย / ลา / WO เกินกำหนด
5. จุดแข็ง · จุดที่ต้องพัฒนา · แผนเดือนถัดไป → `บันทึกผลประเมิน`

**สูตร:** KPI = น้ำหนัก × min(จริง ÷ เป้า, 1) · Comp/Behav = น้ำหนัก × คะแนน ÷ 5 · หักวินัย = สาย×1 + ขาด×3 + ลา×0.5 + WO เกินกำหนด×3

| คะแนน | เกรด | โบนัส |
|---|---|---|
| ≥ 95 | A | 120% |
| ≥ 90 | B | 100% |
| ≥ 80 | C | 80% |
| ≥ 75 | D | 50% |
| < 75 | F | ไม่ได้ |

**พิมพ์:** "แบบประเมินผลการปฏิบัติงานรายเดือน (PMS)" — ลงชื่อ ผู้ถูกประเมิน / ผู้ประเมิน / ผู้อนุมัติ

1. **ครั้งแรก (CEO/admin):** ตั้ง **รหัสผ่านหลัก** ≥ 12 ตัว → `ตั้งรหัสผ่านหลักและเปิดคลัง`
2. ครั้งต่อไป: ใส่รหัสผ่านหลัก → `เปิดคลัง`
3. `+ เพิ่มรายการ` → ชื่อระบบ * · หมวด (ธนาคาร / สรรพากร-ประกันสังคม / LINE-โซเชียล / อีเมล / โดเมน-คลาวด์ / ซอฟต์แวร์ / อื่นๆ) · URL · ชื่อผู้ใช้ · รหัสผ่าน (`สุ่ม` 18 ตัว) · 2FA/รหัสกู้คืน · หมายเหตุ
4. ในตาราง: ⧉ คัดลอก · 👁 แสดง 30 วินาที
5. (CEO) `👥 ผู้มีสิทธิ์` · `🔑 เปลี่ยนรหัสผ่านหลัก` · `⬇ ส่งออกสำรอง` (JSON ที่ยังเข้ารหัส) · `🔒 ล็อก` (ล็อกเองเมื่อไม่ใช้ 10 นาที)

> ⚠️ **ลืมรหัสผ่านหลัก = กู้คืนไม่ได้** — จดเก็บนอกระบบ (เช่น ซองปิดผนึก) · ผู้ได้สิทธิ์ต้องได้รับรหัสผ่านหลักจาก CEO โดยตรง

## 9.7 สำรอง / กู้คืนข้อมูล

- **อัตโนมัติทุกวัน** → `server/data/backups` เก็บรายวัน 30 วัน + วันที่ 1 ของเดือนย้อนหลัง 12 เดือน
- **สำรองนอกเครื่อง (แนะนำมาก):** ใส่พาธ เช่น `E:\PPSD-Backup` หรือโฟลเดอร์ OneDrive → `บันทึก` (ระบบทดสอบเขียน) → `⬆ สำรองไปตอนนี้`
- **ด้วยมือ:** `สำรองข้อมูล` (ดาวน์โหลด .sqlite) · `กู้คืนข้อมูล` (เลือกไฟล์ → ข้อมูลปัจจุบันถูกแทนที่ — **สำรองก่อนทุกครั้ง**) · `กู้คืนชุดนี้` จากรายการอัตโนมัติ (ระบบสำรองสถานะปัจจุบันให้ก่อน)

> ⚠️ ถ้าเครื่องเซิร์ฟเวอร์พังโดยไม่มีสำรองนอกเครื่อง ข้อมูลจะหายหมด — ตรวจป้าย "สำรองนอกเครื่องปกติ" ที่หน้าสรุปเป็นประจำ

## 9.8 รีสตาร์ทเซิร์ฟเวอร์
เมื่อเมนูซ้ายขึ้น "⚠ อัปเดตโค้ดแล้ว แต่เซิร์ฟเวอร์ยังรันตัวเก่า" → admin กด `↻ รีสตาร์ทเซิร์ฟเวอร์` → ยืนยัน (ทุกคนใช้งานไม่ได้ ~5–10 วินาที) → หน้าโหลดใหม่เอง · ถ้าไม่กลับมา ดับเบิลคลิก `start.bat` ใหม่

## ง. คำถามที่พบบ่อย (FAQ)

**กดเก็บเงินงวดไม่ได้ ขึ้น "ต้องตรวจรับงวดงานให้ผ่านก่อน"**
→ เปิดบ้าน → งวดงาน → `ตรวจรับ` ที่งวดนั้น บันทึกผล "ผ่าน" หรือ "ผ่านบางส่วน" ก่อน

**กดอนุมัติแล้วขึ้น "อนุมัติได้เฉพาะตำแหน่งผู้จัดการ/CEO"**
→ ตั้งตำแหน่งใน HR ให้เป็น ผู้จัดการ / CEO / ผู้บริหาร ฯลฯ

**PO ค้าง อนุมัติไม่ครบ**
→ ค่าเริ่มต้นต้อง 3 คน — ลดได้ที่ ตรวจสอบ → กติกาควบคุม

**ต้นทุนบ้านไม่ขึ้นหลังซื้อของ**
→ PO ต้อง **ตรวจรับ / รับของแล้ว** ก่อน รายจ่ายจึงเข้าบ้าน

**การ์ด LINE ไม่เด้ง**
→ ดูเหตุผลใต้สถานะในเว็บ: ยังไม่ผูก LINE / ยังไม่เพิ่มเพื่อน / token ผิด / โควตาหมด → `↻ ส่ง LINE อีกครั้ง`

**รูปใบ PR/PO ไม่ส่งเข้า LINE (ได้แต่ข้อความ)**
→ เปิด **ลิงก์สาธารณะอัตโนมัติ** ที่หน้าผู้ใช้งาน

**ตัวเลขบัญชีดูไม่ตรง / มีแถบ "ลงบัญชีค้าง"**
→ GL → `↻ สร้างบัญชีจากข้อมูลเดิม` · ถ้าติดงวดปิด ให้เลื่อนวันปิดงวดก่อน

**พนักงานถูกหัก "ขาด" ในวันหยุด**
→ เพิ่มวันนั้นใน HR → วันหยุด แล้วคำนวณใหม่ (ถ้าทำจ่ายแล้วต้อง เปิดแก้ไข รอบ)

**ลืม PIN**
→ หน้าเข้าสู่ระบบ → `ลืม PIN?` → ให้ผู้ดูแลอนุมัติ

**เมนูหายไป**
→ ผู้ดูแลอาจปิดโมดูลนั้นให้บัญชีของคุณ หรือบทบาท/ตำแหน่งไม่มีสิทธิ์
