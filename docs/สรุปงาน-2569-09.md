## 1. จัดซื้อ (Procurement) — ขั้นตอน 5 ขั้นแบบอัตโนมัติ

**ลำดับงาน** โฟร์แมนสั่งของ → ผู้ตรวจสอบ (พี่มาตร/ธนาพนธ์) ตรวจ → ออก PR อัตโนมัติ + ส่งอนุมัติทาง LINE → ใบเสนอราคาส่งในไลน์ AI เทียบราคา → ออก PO + ส่งอนุมัติ LINE

- **โฟร์แมนสั่งของผ่าน LINE** พิมพ์ภาษาคนได้ เช่น "ขอปูนตราเสือ 30 ถุงไปบ้านคุณพร" · AI อ่านข้อความ (ชื่อของ จำนวน หน่วย บ้าน) · ถามรูปสินค้าก่อนส่ง · รูปติดไปกับใบ PR
- **การ์ดตรวจสอบ** ส่งถึงผู้ตรวจสอบทาง LINE (ปุ่ม ตรวจแล้ว-ออก PR / ส่งกลับแก้ไข) · ปุ่ม "ส่ง LINE อีกครั้ง" · บอกสถานะและ**เหตุผลที่ส่ง LINE ไม่สำเร็จ** (โควตาหมด / token ผิด / ผู้รับยังไม่เพิ่มเพื่อน / รหัสผู้ใช้ผิด)
- **ใบ PR / PO เป็นรูป** (สร้างด้วย Chrome ในเครื่อง) ส่งเข้า LINE ผู้รับที่ตั้งไว้ (เช่น ชมภู่) ผ่านลิงก์สาธารณะ
- **ใบเสนอราคาทาง LINE**: ส่งรูปใบเสนอราคาตอบกลับในแชท → ครบตามจำนวนร้าน AI เทียบราคาและ**ร่าง PO ให้เอง** พร้อมปุ่ม "เลือกร้านอื่น" ในการ์ดอนุมัติ · พิมพ์ "เอาร้านนี้" ออก PO ได้ทันที
- **ช่องทางออนไลน์**: เลือก "ออนไลน์/ทั้งสองอย่าง" → AI ค้นทุกร้านออนไลน์ เลือกดีที่สุด 3 ร้านต่อรายการ ส่งลิงก์ให้จัดซื้อ · ส่งต่อลิงก์ + "เอาร้านนี้" หรือ "เอาร้านที่ 2" → ออก PO จากใบที่ถูกต้อง (หาข้ามใบได้) · พิมพ์เลข PR สลับใบได้
- **เคยซื้อมาก่อน**: ในใบเทียบราคาขึ้นประวัติ PO เก่าที่รายการใกล้เคียง (ไม่ต้องตรงเป๊ะ) ร้าน/ราคาต่อหน่วย/วันที่/เลข PO/ซื้อกี่ครั้ง ป้าย "ถูกสุด" + ปุ่ม "ใช้ราคานี้"
- **PO อ้าง PR ที่ยอด 0 ได้** (PR ส่วนใหญ่ไม่มียอด) · ปฏิเสธ PO/PR = ยกเลิกทันทีพร้อมแจ้ง LINE · ลบ PR ได้
- **VAT + ส่วนลดใน PR/PO**: เลือก ไม่มี VAT / ราคารวม VAT / ราคาก่อน VAT (+7%) + ส่วนลด → ระบบคำนวณ ก่อน VAT · VAT · รวมทั้งสิ้น ลงในใบ PR/PO (ใบ PO แสดงรายการหลายบรรทัด)
- **หมวดสำหรับโครงการออฟฟิศ**: เบิกค่าน้ำมัน / ซ่อมแซมออฟฟิศ / ของใช้สำนักงาน / อื่นๆ

## 2. เงินสดย่อย + ค่าน้ำมันรถ

- **สองกองแยกกัน** เงินสดย่อย (1030) และค่าน้ำมันรถ (1031) แต่ละกองมีวงเงิน (ลิมิต) ของตัวเอง ปรับเพิ่ม-ลด/เติมให้เต็ม/ใบสรุป แยกกัน · ชิปแสดงยอดทุกกอง เตือนใกล้หมด
- **รายการจ่ายแบบมีโครงสร้าง**: รายการสินค้าหลายบรรทัด + จำนวน/หน่วย/ราคา · ร้านค้า (เลือกจากทะเบียน) · ผู้เบิก (เลือกจากพนักงาน) · บ้านที่ซื้อให้ (ต้นทุนรวมที่บ้าน) · ทะเบียนรถ (น้ำมัน)
- **ใบสำคัญรับเงิน (RV)** ออกอัตโนมัติเฉพาะเงินสดย่อยที่ไม่มีเลขบิลร้าน พิมพ์ได้ · กองน้ำมันไม่ออก
- **อ้างอิงเอกสาร** RR ใบรับของ (จาก PO ทุกใบ + ใบตรวจรับ) / PO / OE ใบจ่าย / PS ใบสำคัญจ่าย — เลือกแล้ว**ดึงรายการ ร้าน บ้าน มาใส่ฟอร์มให้** ไม่ต้องพิมพ์ใหม่
- **VAT/ส่วนลด** เลือกได้ ระบบแยกยอดก่อน/หลัง VAT และลงภาษีซื้อ (1160) ให้ · **ปัดเศษสตางค์เป็นบาทเต็ม** (≥50 สต. ปัดขึ้น) ทุกกอง
- **ราคาตามบิล / ราคาจ่ายจริง** (เงินสดย่อย) ตัดเงินจากกองตามที่จ่ายจริง แสดงส่วนต่าง
- **แก้ไข/ลบได้** โดยบัญชี/ผู้ดูแลระบบ รวมถึงรายการเก่าที่ลงไว้ก่อนปรับระบบ และรายการเติมเงิน (จำนวน วันที่ อ้างอิง OE/PS)
- **เบิกค่าน้ำมันผ่าน LINE**: โฟร์แมนพิมพ์ "เบิกน้ำมัน 1500 บ้านคุณพร ทะเบียน กข1234" → การ์ดถึงผู้บริหาร (อนุมัติ/ปฏิเสธ) → หักจากกองน้ำมันทันที กองไม่พอถูกกัน · ตารางคำขอในเว็บ
- ใบสรุปรายจ่ายมีคอลัมน์ ก่อน VAT / VAT / ส่วนลด + สรุปแยกตามบ้าน

## 3. เอกสารขาย

- เลือก **รวม VAT / ไม่รวม VAT (ราคาถูกลง) / ราคารวม VAT แล้ว** ตอนสร้างใบเสนอราคา/ใบแจ้งหนี้/ใบเสร็จ · ใบต่อสืบทอดแบบภาษี · ใบไม่มี VAT ไม่แสดงบรรทัดภาษี
- **อัปโหลดใบเก่า (PDF/รูป)**: เลือกประเภทเอกสาร/ภาษี/บ้านก่อน → AI อ่านรายการ จำนวน ราคา (และชื่อลูกค้าถ้าว่าง) มาเป็นร่าง · หรือแนบไฟล์อย่างเดียว · ไฟล์แนบไว้กับเอกสาร (📎)
- **ลบเอกสารได้** (บัญชี/ผู้ดูแลระบบ) กันลบใบที่ถูกออกใบต่อหรือเซ็นสัญญาแล้ว

## 4. CRM ระดับโลก (8 กลุ่ม)

1. **ลูกค้า 360°** — บ้านทุกหลัง (ความคืบหน้าจาก QC 10 เฟส งวดเงิน เคส ประกัน รูป) เอกสารขาย timeline การติดต่อ Lead คนที่แนะนำมา · ผูกลูกค้า↔บ้านอัตโนมัติจากชื่อ · บันทึกการติดต่อมี "ต้องทำต่อ + วันนัด" ขึ้นกระดิ่ง
2. **LINE ลูกค้า** — ผูกด้วยรหัส 6 หลัก · ลูกค้าพิมพ์ ความคืบหน้า / งวด / เอกสาร / ประกัน / เคส / บอกต่อ / ติดต่อ · ข้อความอื่นเข้า timeline + แจ้งโฟร์แมน/ผู้บริหาร · ทีมงานส่งข้อความ/ความคืบหน้าถึงลูกค้าจากหน้า 360
3. **ข้อความอัตโนมัติ** (เปิด-ปิดรายข้อ) — ความคืบหน้ารายสัปดาห์+รูป · เตือนงวดล่วงหน้า · ผ่าน QC ครบเฟส · ส่งมอบ (ยินดี+ประกัน+NPS) · ครบรอบเข้าบ้าน/วันเกิด · ประกันใกล้หมด 30 วัน · นัดตรวจบ้านฟรี 6/12 เดือน
4. **เคสบริการ/แจ้งซ่อม** — ลูกค้าพิมพ์ "แจ้งซ่อม …" + รูป → เคส CS- SLA 24 ชม. โฟร์แมนประจำบ้านรับผิดชอบ แจ้งทีม LINE+กระดิ่ง · เปลี่ยนสถานะแจ้งลูกค้าอัตโนมัติ · ปิดเคสขอคะแนน · เกิน SLA เตือนแดง
5. **NPS / บอกต่อ** — ถามคะแนน 0-10 ทาง LINE (หลัง QC เฟส 5, ส่งมอบ, ปิดเคส) · คะแนน ≤6 แจ้งผู้บริหารทันที · รหัสบอกต่อ REF- ต่อลูกค้า
6. **Lead / Pipeline** Kanban — สนใจ → นัดคุย → เสนอราคา/แบบ → ต่อรอง → เซ็นสัญญา · ช่องทาง มูลค่า ผู้ดูแล โน้ต · Lead เงียบเกิน 3 วันขึ้นกระดิ่ง · ปิดการขายสร้างลูกค้า+บ้าน
7. **Customer Portal** `/portal/<token>` — ลูกค้าเปิดบนมือถือไม่ต้องล็อกอิน: ความคืบหน้า งวด แจ้งซ่อม ประกัน เอกสาร
8. **รายงาน CRM** — Lead/เดือน ช่องทาง อัตราปิด เวลาปิดเฉลี่ย บอกต่อ เคสค้าง/เกิน SLA/เวลาแก้ NPS

## 5. QC / งานหน้างาน / HR

- QC checklist 10 เฟส (0–9 แยกโครงสร้างชั้น 1 / ชั้น 2) 60 ฟอร์ม PPSD
- **ยื่นปรับปรุงเวลาเอง**ที่หน้าลงเวลาด้วย PIN (ไม่ต้องมีสิทธิ์ HR)
- ผู้ใช้↔พนักงาน HR ผูกกันได้ (จับคู่ชื่อแบบยืดหยุ่น) · ตำแหน่งจาก HR ใช้กำหนดสิทธิ์ · CEO = สิทธิ์ผู้จัดการ · แก้ไข/ลบ/ปิดใช้งานผู้ใช้
- ทุกช่องเงินใส่ทศนิยม (เศษสตางค์) ได้

## 6. ระบบ / ประสิทธิภาพ

- **อัปเดตสด (SSE)**: ข้อมูลเปลี่ยนจากคนอื่น/บอท LINE → หน้าเว็บโหลดเฉพาะส่วนที่เปลี่ยน ไม่ต้องกด F5
- **โหลดหน้าแรกเร็วขึ้น**: ยิงคำขอพร้อมกัน แสดงหน้าได้ก่อนโหลดครบ (แถบบางบนสุดระหว่างโหลดส่วนที่เหลือ) · รายการ PR/PO ไม่แนบรูป/ลายเซ็น (ใบเต็มดึงตอนพิมพ์) · gzip JSON
- build ไม่ลบ dist ระหว่างอัปเดต (ไม่เจอหน้า error) · หน้า 503 รอ build
- กระดิ่งแจ้งเตือนรวม: งานด่วน, Lead เงียบ, นัดติดตามลูกค้า, เคสเกิน SLA, คะแนนต่ำ ฯลฯ

## 7. บัญชี — จุดที่ควรรู้

- เจ้าหนี้การค้า (2010) เกิดเมื่อ **PO เครดิตถูกกด "รับของแล้ว"** (ไม่ใช่ตอนออก PO) · PO เงินสดตัดเงินสด/ธนาคาร · ใบสำคัญจ่ายชำระ PO ลดยอดค้าง · หน้าตรวจสอบเช็ก 2010 ↔ ยอดค้าง PO
- เงินสดย่อย/น้ำมัน: Dr ค่าใช้จ่าย (ก่อน VAT) + Dr ภาษีซื้อ 1160 / Cr กอง · เติมกอง Dr กอง / Cr ธนาคาร · แก้ไขแล้วลงใหม่แทน ไม่ซ้ำ · งวดปิดแล้วใช้กลับรายการ

## สิ่งที่ต้องตั้งค่า/ทำต่อฝั่งออฟฟิศ

- ตั้งกุญแจ AI (ผู้ใช้งาน → ตั้งค่า AI) สำหรับอ่านข้อความ/ใบเสนอราคา/ใบเก่า/ค้นออนไลน์
- LINE: ผู้รับทุกคนต้องเพิ่ม LINE OA เป็นเพื่อน · แพ็กเกจฟรี 200 ข้อความ/เดือน (โควตาหมดระบบจะบอก)
- CRM: ใส่เบอร์/ไลน์ทีมงาน ตรวจรายการประกัน · บ้านที่ส่งมอบใส่ "กำหนดส่งมอบ" เป็น ปี-เดือน-วัน · ผูก LINE ลูกค้าที่กำลังสร้าง
- PO ที่ของมาแล้วให้กด "รับของแล้ว" เพื่อให้เจ้าหนี้และต้นทุนบ้านขึ้นในระบบ
