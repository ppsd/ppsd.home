# สรุป 1 หน้า ตามบทบาท — PPSD ERP

> ให้พนักงานแต่ละตำแหน่งอ่านแค่หน้าของตัวเอง (พิมพ์แยกแผ่นแจกได้)
> รายละเอียดเต็มอยู่ใน `docs/คู่มือการใช้งาน-PPSD-ERP.md` — เลขข้อในวงเล็บ เช่น (→ 4.3) คือหัวข้อในคู่มือเต็ม
> อัปเดตล่าสุด: 4 พ.ย. 2569

**ทุกคนต้องรู้ 7 ข้อ**
1. เข้าระบบ: ชื่อผู้ใช้ + PIN 4 หลัก (PIN เดียวกับลงเวลา) · ลืม PIN กด `ลืม PIN?` แล้วแจ้งแอดมิน
2. ผูก LINE: กด 💬 มุมขวาบน → ส่งรหัส 6 หลักให้บอท **PPSD Assistant** · กดปุ่ม **เมนู PPSD** ใต้แชท (ไม่ต้องจำคำสั่ง) หรือพิมพ์ **ช่วย** ในแชทเพื่อดูคำสั่ง
3. ฟอร์มที่เปิดค้าง กด **Esc** = ย่อเก็บไว้มุมขวาล่าง ไม่หาย · แต่ **F5 / ปิดเบราว์เซอร์ = ข้อมูลที่ยังไม่บันทึกหาย**
4. 🔔 กระดิ่งมุมขวาบน = งานที่รอเรา กดแล้วไปหน้านั้นเลย
5. **ความเคลื่อนไหวบ้าน** (ใต้เมนูบ้าน) = ดูว่าบ้านไหนมีอะไรเปลี่ยน · เพิ่ม-ลดงาน/แก้ยอดเงิน ถ้าไม่ใช่แอดมิน/ผู้จัดการ จะขึ้น "ส่งขออนุมัติแล้ว" — ยังไม่มีผลจนกว่าจะอนุมัติ (→ 2.0)
6. **หาข้อมูลเก่า:** พิมพ์ที่ช่องค้นหาบนสุด (ชื่อบ้าน/ลูกค้า เลขเอกสาร ร้าน วัสดุ ยอดเงิน) → กด Enter ได้หน้าผลทั้งหมด กรองปี พ.ศ./แผนกได้ (→ 1.3)
7. เจอปัญหา: แคปหน้าจอ (`Win + Shift + S`) ส่งแอดมิน พร้อมบอกว่าอยู่หน้าไหน กดอะไร

## 👷 โฟร์แมน / หน้างาน (บทบาท site)

| อยากทำ | ทำที่ไหน / พิมพ์อะไร |
|---|---|
| ลงเวลาเข้า-ออก | มือถือ: `<ลิงก์ระบบ>/#checkin` หรือเครื่อง kiosk ออฟฟิศ (→ 8.1, 8.2) |
| ถึงหน้างาน (เช็คอินหน้างาน) | หน้าเช็คอินมือถือ (ลิงก์ https จากแอดมิน) → เลือกชื่อ + PIN → **🏠 เลือกหน้างาน** → เลือกบ้าน → **📍 เช็คอินถึงหน้างาน** (กดครั้งเดียวตอนถึง) |
| ลืมตอกบัตร / ตอกผิด | ยื่น **ปรับปรุงเวลา** (หน้าลงเวลา ใส่ PIN) → ผู้จัดการอนุมัติ · แก้บันทึกเวลาเองไม่ได้ (เฉพาะแอดมิน/บัญชี/ผู้จัดการ/บุคคล) |
| **สั่งของ / ขอจ้างช่าง** | LINE: *"สั่งของ ปูน 50 ถุง บ้านคุณพร"* / *"ขอจ้าง ช่างทาสี …"* → ตอบ **ตกลง** (→ 4.3) |
| **รับของที่ร้านมาส่ง** | LINE: *"รับของ PO-69-0123"* → ส่งรูปใบส่งของ + รูปของ → **ครบ** → ตอบ **ของครบ** หรือ *"ขาด ปูน 2 ถุง"* |
| รับของแบบไม่มีรูป | LINE: *"รับของ PO-69-0123 ได้รับครบ"* |
| เบิกค่าน้ำมัน | LINE: *"เบิกน้ำมัน 1500 บ้านคุณพร ทะเบียน กข1234"* |
| รับทราบใบสั่งงาน / ดูงานค้าง | LINE: **รับ** / **งาน** |
| เพิ่มงวด / แก้ยอดงวด / จ้างช่าง | ทำได้ตามปกติ แต่ขึ้น **ส่งขออนุมัติแล้ว** — ดูผลที่ ความเคลื่อนไหวบ้าน → แท็บ รออนุมัติ (→ 2.0) |
| ให้ช่างใช้ LINE (ส่งรูปงาน · แจ้งปัญหา · ขอเบิกงวด) | บ้าน → แท็บ ช่าง → **🔗 ผูก LINE** → ส่งรหัส 6 หลักให้ช่าง (ผู้จัดการ/บัญชี/แอดมินกดได้) (→ 2.6.2) |
| แจ้งปัญหาหน้างาน | เมนู ปัญหาหน้างาน หรือแท็บ "ปัญหา" ในบ้าน (→ 3.1) |
| ตรวจ QC ตามงวด | เมนู ตรวจงาน QC (→ 3.3) |
| รายงานประจำวัน / ความปลอดภัย | เมนู รายงานหน้างาน / ความปลอดภัย (→ 3.5, 3.6) |

⚠️ ของมาแล้ว **ต้องกดรับของ** — ไม่งั้นต้นทุนบ้านไม่ขึ้น และร้านไม่ได้เงิน

| ตรวจรับของในเว็บ | จัดซื้อ / จ่าย → แท็บ PO → **📦 ตรวจรับของ** |
| พิมพ์ PO / PR | ปุ่ม 🖨 ในแต่ละแถว (→ 4.6) |
| ดูราคาที่เคยซื้อ | จัดซื้อ / จ่าย → แท็บ ประวัติการซื้อ / ราคา |
| ซื้อ/จ้างงานโฆษณา (ป้าย แอด บูธ ถ่ายภาพ) | ใบขอซื้อเลือกโครงการ **📣 การตลาด / สื่อโฆษณา** + เลือกหมวด · LINE: พิมพ์คำว่า *โฆษณา* ในข้อความสั่งของ (→ 2.2) |
| ตั้งเครดิต / VAT ของร้าน | แท็บ ผู้ขาย / ผู้รับเหมา (ตั้งให้ถูก PO จะคิดให้อัตโนมัติ) |

## 💰 บัญชี (บทบาท accounting)

| อยากทำ | ทำที่ไหน |
|---|---|
| บันทึกรายจ่าย | เมนู รายจ่าย → `+ เพิ่มรายจ่าย` (มีใบกำกับ ใส่เลขที่ + VAT) (→ 5.1) |
| จ่ายเจ้าหนี้ (PO เครดิต) | จัดซื้อ / จ่าย → แท็บ ยอดค้างจ่าย → 💸 จ่าย · PO เงินสด **ไม่ต้อง** ทำใบจ่าย |
| ตั้งงวดลูกค้าตอนเซ็นสัญญา | เอกสารขาย → `เซ็นสัญญา` → เลือกแบบบ้าน ชั้นเดียว / 2 ชั้น / 3 ชั้น → ได้งวดตามเอกสารบริษัท · บ้านที่ยังไม่มีงวด: บ้าน → `⬆ นำเข้างวดงาน` → **📐 งวดมาตรฐานบริษัท** (→ 2.4) |
| เก็บเงินงวดลูกค้า | บ้าน → แท็บงวดงาน (ต้อง **ตรวจรับงวด** ผ่านก่อน) → ออกใบเสร็จ (→ 2.3) |
| บันทึกสัญญาลูกค้า/ช่าง · ดูประวัติรับ-จ่ายของบ้าน | บ้าน → แท็บ **การเงิน & สัญญา** · กด `แก้` ที่รายการเงินเพื่อใส่วันที่จริง วิธีจ่าย เลขใบเสร็จ (→ 2.6.1) |
| ดูเงิน 4 ขา (บ้าน / บริษัท / โฆษณา / ลูกค้า) รายเดือน | เมนู รายงาน → ส่วน **ภาพรวมเงิน 4 ขา** · ค่าโฆษณาลงโครงการ **การตลาด / สื่อโฆษณา** (→ 7.3) |
| บัญชีแยกประเภท / กระทบยอด | เมนู บัญชีแยกประเภท (GL) (→ 5.2) |
| เงินสดย่อย / ค่าน้ำมัน | GL → แท็บเงินสดย่อย / ค่าน้ำมันรถ (→ 5.3) |
| ภาษี ภ.พ.30 / ภงด.1/3/53 | ดาวน์โหลดไฟล์ e-Filing (ระบบสร้างไฟล์ ไม่ได้ยื่นแทน) (→ 5.6) |
| ส่งออกโปรแกรม Express | เมนู ส่งออกบัญชี (Express) (→ 5.5) |
| ปิดเงินเดือน | HR → เงินเดือน → ดึงวันจากลงเวลา → ตรวจ → 💸 ทำจ่าย (→ 8.4) · กรอกวันทำงานเอง = ยอดสุดท้าย (ไม่หักขาด/ลาซ้ำ) |
| มีคนทำงานวันหยุด | HR → สรุปลงเวลา → กล่อง **ทำงานวันหยุด** → **สร้างค่าทำงานวันหยุด** (ตามกฎหมาย) → ผู้จัดการอนุมัติที่แท็บ OT |
| พนักงานเข้าใหม่ | HR → พนักงาน → **+ เพิ่มพนักงาน** (ที่เดียว ไม่ต้องไปหน้าผู้ใช้งาน) · ติ๊ก "ให้เข้าใช้ระบบ ERP" เฉพาะคนที่ใช้หน้าเว็บ · คนอื่นลงเวลาด้วย PIN ได้เลย |
| พนักงานลาออก | HR → พนักงาน → แก้ไข → สถานะ **ลาออก** + **วันที่ลาออก** (อย่าลบ) — เงินเดือน (รวมช่องเลือกชื่อเบิก/รายได้อื่น/หักอื่น) ขึ้นถึงเดือนที่ลาออกแล้วหยุด · คืนเงินประกันในตาราง Retention |
| ส่งสลิปเงินเดือนเข้า LINE พนักงาน | หลังทำจ่าย → **📨 ส่งสลิปเข้า LINE** → 📎 แนบสลิปโอนทีละคน → ติ๊ก → ส่ง (รูปสลิปเต็มใบ + สลิปโอน) |
| ช่างขอเบิกงวดทาง LINE | อนุมัติแล้วได้ข้อความ LINE · งวดขึ้นป้าย **อนุมัติเบิกแล้ว** → กดจ่ายได้เลยไม่ต้องรออนุมัติซ้ำ (→ 2.6.2) |
| จ่ายเงินช่างตามงวด | บ้าน → งวดงาน → `จ่ายเงินเต็ม`/`บางส่วน` → ขึ้น "ส่งขออนุมัติแล้ว" รอแอดมิน/ผู้จัดการอนุมัติก่อน (→ 2.0) |
| บันทึกเบิกล่วงหน้า | HR → เงินเดือน → ใต้ตาราง (ไม่จำกัดยอด — ดู "เงินเดือนงวดนี้ประมาณ" ก่อน · เกินแล้วสุทธิติดลบ ทำจ่ายไม่ได้) · 📎 แนบสลิปเป็นหลักฐานได้ |
| คืนเงินประกันสะสม | HR → เงินเดือน → ตาราง Retention → **คืนเงินประกัน** (จ่ายพร้อมเงินเดือนงวดนั้น) |

**ทุกสิ้นเดือน** (→ ภาคผนวก ก.4): แก้ "ลงบัญชีค้าง" ที่หน้าสรุป → กระทบยอดธนาคาร → สรุปภาษี → ปิดงวด
⚠️ ใบกำกับภาษีที่มาทีหลัง หน้างานส่งผ่าน LINE ได้ (*"ใบกำกับ PO-…"*) — ถ้าเลขไม่ตรง ระบบไม่ทับ จะแจ้งให้บัญชีตรวจ

| ตรวจสัญญาณผิดปกติ (จ่ายซ้ำ แตกใบ ราคาสูง) | เมนู ตรวจสอบ (→ 9.5) |
| **จุดอ่อนบริษัท · กำไรรายหลัง · เงินพอจ่ายไหม · ข่าวเศรษฐกิจ/วัสดุ/คู่แข่ง · แผนการตลาด-การขาย** | เมนู **ศูนย์วิเคราะห์ธุรกิจ (AI)** · AI ทำรายงานให้ทุกเช้าวันจันทร์ (อยากได้ใหม่กด อัปเดต เอง) · เรื่องด่วนเด้ง LINE (ผู้รับตั้งได้ที่ ⚙ ตั้งค่า) · กด รับทราบ เมื่อจัดการแล้ว · แท็บ **กลยุทธ์การตลาด/การขาย** ส่งต่อให้ฝ่ายขายใช้ (→ 7.7) |
| ตรวจสัญญาก่อนให้ลูกค้าเซ็น | เมนู ตรวจเอกสาร (AI) หรือส่งไฟล์ให้บอท LINE (→ 1.5) |
| **ลูกค้าอยากได้บ้าน X ชั้น Y ห้องนอน งบ Z — ขอดูแปลน/ภาพ 3D** | เมนู **ออกแบบบ้านเบื้องต้น (AI)** → `+ ออกแบบใหม่` (แนบรูปบ้านที่ลูกค้าชอบได้) → รอ 1–3 นาที ได้แปลนทุกชั้น + 3D หมุนได้ + ราคาประมาณ · สั่งแก้เป็นข้อความได้ · `⬇ บันทึก` ส่งลูกค้า (เป็นแบบร่าง ไม่ใช่แบบก่อสร้าง) (→ 1.6) |
| **ลูกค้ายังนึกไม่ออกว่าอยากได้บ้านแบบไหน** | ส่งลิงก์เว็บลูกค้า หน้า `ห้องรวมไอเดีย` (#ideas) ให้ลูกค้ากด ♡ แล้วกดออกแบบเอง → แบบขึ้นใน ERP ชื่อ "เว็บ:" ให้เกลาต่อ · หรือในหน้าเดียวกันของ ERP แท็บ `💡 ห้องรวมไอเดีย` → ให้ลูกค้าดูรูป/แปลน/บ้านดัง หรือ `🔎 ค้นรูปเพิ่มจากเน็ต` → กด `♡ ชอบแบบนี้` (ไม่เกิน 3) → `✨ ให้ AI ออกแบบตามนี้` · นำรูปไปใช้ที่อื่นต้องใส่เครดิตใต้รูปด้วย (→ 1.6) |
| (CEO) KPI · สรุป QC · สั่งงานด้วยเสียง · คลังรหัสผ่าน | เมนูกลุ่ม **สำหรับผู้บริหาร / ผู้ดูแลระบบ** (→ 7.4, 7.5, 8.6, 9.6) |

⚠️ ห้ามอนุมัติใบที่ตัวเองขอ (ระบบกันไว้) · อนุมัติแล้วการ์ด LINE ไม่เด้งต่อ → ให้แอดมินดูสาเหตุ

## 🔨 ช่าง / ผู้รับเหมา (ใช้ผ่าน LINE — ไม่ต้องเข้าเว็บ)

เริ่มใช้: เพิ่มเพื่อนบอท **PPSD** → ส่งรหัส 6 หลักที่ทีมงานให้ (ใช้ได้ 3 วัน) (→ 2.6.2)

> 🧪 **ตอนนี้ยังอยู่ในช่วงทดสอบ** — ช่างจริงยังผูกไม่ได้ (ทดลองโดยศิตาพิชญ์ก่อน)

| อยากทำ | พิมพ์ในแชท |
|---|---|
| รายงานงาน | ส่งรูปงานมาได้เลย (ไม่เกิน 10 รูป) + พิมพ์รายละเอียด → **ส่ง** |
| แจ้งปัญหา | *แจ้งปัญหา ท่อน้ำรั่วห้องน้ำชั้น 2* (แนบรูปได้) → **ส่ง** |
| ขอของ | *ขอของ ปูน 10 ถุง* → **ส่ง** |
| ขอเบิกเงินงวด | **เบิกงวด** → ตอบเลขงวด → แนบรูปงานที่เสร็จ → **ส่ง** |
| ดูงานและเงินของฉัน | **งาน** |
| ดูผลเรื่องที่ส่ง | **สถานะ** |

⚠️ ทุกเรื่องทีมงานตรวจก่อน แล้วบอทแจ้งผลกลับ · พิมพ์ **ยกเลิก** เพื่อเริ่มใหม่ · **ช่วย** = ดูคำสั่ง

## 🛠 แอดมิน (ผู้ดูแลระบบ)

| อยากทำ | ทำที่ไหน |
|---|---|
| เพิ่ม / ปิดผู้ใช้ · รีเซ็ต PIN | เมนู ผู้ใช้งาน (คนลาออก = ตั้งสถานะ **ลาออก** ที่ HR → ปิดบัญชีให้เอง · อย่าลบ · เจ้าของ/คนนอกที่ไม่รับเงินเดือน = ประเภท **บัญชีระบบ**) (→ 9.1) |
| ตั้งค่า LINE · แก้ข้อความบอท · โหมดทดสอบ | เมนู ส่วนกลางบริษัท → LINE (→ 9.2) |
| ตั้งกุญแจ AI · ดูค่าใช้จ่าย AI | ผู้ใช้งาน → 🤖 ตั้งค่า AI (→ 9.3) |
| ปรับกติกาอนุมัติ (จำนวนคน, % ราคาเกิน) | ตรวจสอบ → กติกาควบคุม (→ 9.5) |
| เลือกว่าเรื่องไหนต้องรออนุมัติ (เพิ่ม-ลดงาน · จ่ายช่าง · เก็บเงิน ฯลฯ) | ความเคลื่อนไหวบ้าน → แท็บ **ตั้งค่า** (→ 2.0) |
| ช่วงทดสอบ: บอทช่างเฉพาะผู้ทดสอบ · ข้อความลูกค้าส่งให้ศิตาพิชญ์ตรวจก่อน / เปิดใช้จริง | ความเคลื่อนไหวบ้าน → แท็บ **ตั้งค่า** → 🧪 ช่วงทดสอบ LINE (→ 2.6.2) |
| ส่งเรื่องสำคัญของบ้านเข้ากลุ่ม LINE ทีม | เชิญบอทเข้ากลุ่ม + พิมพ์ `id` → ความเคลื่อนไหวบ้าน → แท็บ **ตั้งค่า** → 🔔 แจ้งเตือนเข้ากลุ่ม LINE → เลือกกลุ่ม/เรื่อง → ส่งข้อความทดสอบ (→ 2.0) |
| สำรอง / กู้คืน · กู้รายการที่ถูกลบผิด | ผู้ใช้งาน → สำรองข้อมูล → `🔍 ดูข้อมูล` (→ 9.7) |
