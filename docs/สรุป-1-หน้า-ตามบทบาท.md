# สรุป 1 หน้า ตามบทบาท — PPSD ERP

> ให้พนักงานแต่ละตำแหน่งอ่านแค่หน้าของตัวเอง (พิมพ์แยกแผ่นแจกได้)
> รายละเอียดเต็มอยู่ใน `docs/คู่มือการใช้งาน-PPSD-ERP.md` — เลขข้อในวงเล็บ เช่น (→ 4.3) คือหัวข้อในคู่มือเต็ม
> อัปเดตล่าสุด: 4 พ.ย. 2569

**ทุกคนต้องรู้ 5 ข้อ**
1. เข้าระบบ: ชื่อผู้ใช้ + PIN 4 หลัก (PIN เดียวกับลงเวลา) · ลืม PIN กด `ลืม PIN?` แล้วแจ้งแอดมิน
2. ผูก LINE: กด 💬 มุมขวาบน → ส่งรหัส 6 หลักให้บอท **PPSD Assistant** · พิมพ์ **ช่วย** ในแชทเพื่อดูคำสั่ง
3. ฟอร์มที่เปิดค้าง กด **Esc** = ย่อเก็บไว้มุมขวาล่าง ไม่หาย · แต่ **F5 / ปิดเบราว์เซอร์ = ข้อมูลที่ยังไม่บันทึกหาย**
4. 🔔 กระดิ่งมุมขวาบน = งานที่รอเรา กดแล้วไปหน้านั้นเลย
5. เจอปัญหา: แคปหน้าจอ (`Win + Shift + S`) ส่งแอดมิน พร้อมบอกว่าอยู่หน้าไหน กดอะไร

## 👷 โฟร์แมน / หน้างาน (บทบาท site)

| อยากทำ | ทำที่ไหน / พิมพ์อะไร |
|---|---|
| ลงเวลาเข้า-ออก | มือถือ: `<ลิงก์ระบบ>/#checkin` หรือเครื่อง kiosk ออฟฟิศ (→ 8.1, 8.2) |
| **สั่งของ / ขอจ้างช่าง** | LINE: *"สั่งของ ปูน 50 ถุง บ้านคุณพร"* / *"ขอจ้าง ช่างทาสี …"* → ตอบ **ตกลง** (→ 4.3) |
| **รับของที่ร้านมาส่ง** | LINE: *"รับของ PO-69-0123"* → ส่งรูปใบส่งของ + รูปของ → **ครบ** → ตอบ **ของครบ** หรือ *"ขาด ปูน 2 ถุง"* |
| รับของแบบไม่มีรูป | LINE: *"รับของ PO-69-0123 ได้รับครบ"* |
| เบิกค่าน้ำมัน | LINE: *"เบิกน้ำมัน 1500 บ้านคุณพร ทะเบียน กข1234"* |
| รับทราบใบสั่งงาน / ดูงานค้าง | LINE: **รับ** / **งาน** |
| แจ้งปัญหาหน้างาน | เมนู ปัญหาหน้างาน หรือแท็บ "ปัญหา" ในบ้าน (→ 3.1) |
| ตรวจ QC ตามงวด | เมนู ตรวจงาน QC (→ 3.3) |
| รายงานประจำวัน / ความปลอดภัย | เมนู รายงานหน้างาน / ความปลอดภัย (→ 3.5, 3.6) |

⚠️ ของมาแล้ว **ต้องกดรับของ** — ไม่งั้นต้นทุนบ้านไม่ขึ้น และร้านไม่ได้เงิน

## 🛒 จัดซื้อ

| อยากทำ | ทำที่ไหน / พิมพ์อะไร |
|---|---|
| ได้รูปใบ PR ทาง LINE แล้ว | ส่งรูปใบเสนอราคาของแต่ละร้าน **ตอบในแชทเดิม** → ครบจำนวนร้าน AI เทียบให้เอง (→ 4.3) |
| ไม่มีรูปใบเสนอราคา | LINE: *"ราคา ไทวัสดุ 12500"* ทีละร้าน → กดเลือกร้านในการ์ด |
| คุยหลาย PR พร้อมกัน | พิมพ์เลข PR ก่อนส่งรูป เช่น *"ใบเสนอราคา PR-69-0012"* |
| ออก PO | LINE: **เอาร้านนี้** / *"ออก PO PR-…"* · เว็บ: จัดซื้อ / จ่าย → แท็บ PR → `→ PO` (→ 4.2) |
| ตรวจรับของในเว็บ | จัดซื้อ / จ่าย → แท็บ PO → **📦 ตรวจรับของ** |
| พิมพ์ PO / PR | ปุ่ม 🖨 ในแต่ละแถว (→ 4.6) |
| ดูราคาที่เคยซื้อ | จัดซื้อ / จ่าย → แท็บ ประวัติการซื้อ / ราคา |
| ตั้งเครดิต / VAT ของร้าน | แท็บ ผู้ขาย / ผู้รับเหมา (ตั้งให้ถูก PO จะคิดให้อัตโนมัติ) |

⚠️ PO ≥ 100,000 บาท ต้องมีใบเทียบราคา 3 ร้าน · ผลค้นออนไลน์เป็นราคาประมาณ เช็คค่าส่งจริงก่อนสั่ง

## 💰 บัญชี (บทบาท accounting)

| อยากทำ | ทำที่ไหน |
|---|---|
| บันทึกรายจ่าย | เมนู รายจ่าย → `+ เพิ่มรายจ่าย` (มีใบกำกับ ใส่เลขที่ + VAT) (→ 5.1) |
| จ่ายเจ้าหนี้ (PO เครดิต) | จัดซื้อ / จ่าย → แท็บ ยอดค้างจ่าย → 💸 จ่าย · PO เงินสด **ไม่ต้อง** ทำใบจ่าย |
| เก็บเงินงวดลูกค้า | บ้าน → แท็บงวดงาน (ต้อง **ตรวจรับงวด** ผ่านก่อน) → ออกใบเสร็จ (→ 2.3) |
| บันทึกสัญญาลูกค้า/ช่าง · ดูประวัติรับ-จ่ายของบ้าน | บ้าน → แท็บ **การเงิน & สัญญา** · กด `แก้` ที่รายการเงินเพื่อใส่วันที่จริง วิธีจ่าย เลขใบเสร็จ (→ 2.6.1) |
| บัญชีแยกประเภท / กระทบยอด | เมนู บัญชีแยกประเภท (GL) (→ 5.2) |
| เงินสดย่อย / ค่าน้ำมัน | GL → แท็บเงินสดย่อย / ค่าน้ำมันรถ (→ 5.3) |
| ภาษี ภ.พ.30 / ภงด.1/3/53 | ดาวน์โหลดไฟล์ e-Filing (ระบบสร้างไฟล์ ไม่ได้ยื่นแทน) (→ 5.6) |
| ส่งออกโปรแกรม Express | เมนู ส่งออกบัญชี (Express) (→ 5.5) |
| ปิดเงินเดือน | HR → เงินเดือน → ดึงวันจากลงเวลา → ตรวจ → 💸 ทำจ่าย (→ 8.4) · กรอกวันทำงานเอง = ยอดสุดท้าย (ไม่หักขาด/ลาซ้ำ) |
| บันทึกเบิกล่วงหน้า | HR → เงินเดือน → ใต้ตาราง (ไม่จำกัดยอด — ดู "เงินเดือนงวดนี้ประมาณ" ก่อน · เกินแล้วสุทธิติดลบ ทำจ่ายไม่ได้) |

**ทุกสิ้นเดือน** (→ ภาคผนวก ก.4): แก้ "ลงบัญชีค้าง" ที่หน้าสรุป → กระทบยอดธนาคาร → สรุปภาษี → ปิดงวด
⚠️ ใบกำกับภาษีที่มาทีหลัง หน้างานส่งผ่าน LINE ได้ (*"ใบกำกับ PO-…"*) — ถ้าเลขไม่ตรง ระบบไม่ทับ จะแจ้งให้บัญชีตรวจ

## 👔 ผู้จัดการ / ผู้บริหาร / CEO

| อยากทำ | ทำที่ไหน / พิมพ์อะไร |
|---|---|
| **อนุมัติ PR / PO / ใบจ่ายเงิน** | กดปุ่มในการ์ด LINE · หรือพิมพ์ *"อนุมัติ PR-69-0144"* / *"ปฏิเสธ PV-69-0208 ราคาสูงไป"* |
| ดูรายการรออนุมัติ | LINE: **รออนุมัติ** |
| เรื่องค้างวันนี้ | LINE: **สรุป** |
| สั่งงานพนักงาน | LINE: พิมพ์สั่งงาน → **ตกลง** · งานด่วน: **งานด่วน** |
| อนุมัติ ลา / OT | 🔔 กระดิ่ง หรือ HR (→ 8.3) |
| ดูสัญญา + เงินเข้า-ออกของบ้านหลังหนึ่ง (ค้างรับ / ค้างจ่ายช่าง) | บ้าน → แท็บ **การเงิน & สัญญา** (→ 2.6.1) |
| ภาพรวมบริษัท | เมนู หน้าสรุป · รายงาน · แผนงาน (→ 7.1–7.3) |
| ตรวจสัญญาณผิดปกติ (จ่ายซ้ำ แตกใบ ราคาสูง) | เมนู ตรวจสอบ (ใส่ PIN) (→ 9.5) |
| ตรวจสัญญาก่อนให้ลูกค้าเซ็น | เมนู ตรวจเอกสาร (AI) หรือส่งไฟล์ให้บอท LINE (→ 1.5) |
| (CEO) KPI · สรุป QC · สั่งงานด้วยเสียง · คลังรหัสผ่าน | เมนูกลุ่ม ภาพรวม / อื่นๆ (→ 7.4, 7.5, 8.6, 9.6) |

⚠️ ห้ามอนุมัติใบที่ตัวเองขอ (ระบบกันไว้) · อนุมัติแล้วการ์ด LINE ไม่เด้งต่อ → ให้แอดมินดูสาเหตุ

## 🛠 แอดมิน (ผู้ดูแลระบบ)

| อยากทำ | ทำที่ไหน |
|---|---|
| เพิ่ม / ปิดผู้ใช้ · รีเซ็ต PIN | เมนู ผู้ใช้งาน (คนลาออก = **ปิดใช้งาน** อย่าลบ · เจ้าของ/คนนอกที่ไม่รับเงินเดือน = ประเภท **บัญชีระบบ**) (→ 9.1) |
| ตั้งค่า LINE · แก้ข้อความบอท · โหมดทดสอบ | เมนู ส่วนกลางบริษัท → LINE (→ 9.2) |
| ตั้งกุญแจ AI · ดูค่าใช้จ่าย AI | ผู้ใช้งาน → 🤖 ตั้งค่า AI (→ 9.3) |
| ปรับกติกาอนุมัติ (จำนวนคน, % ราคาเกิน) | ตรวจสอบ → กติกาควบคุม (→ 9.5) |
| สำรอง / กู้คืน · กู้รายการที่ถูกลบผิด | ผู้ใช้งาน → สำรองข้อมูล → `🔍 ดูข้อมูล` (→ 9.7) |
| รีสตาร์ตเซิร์ฟเวอร์ | ท้ายเมนูซ้าย `↻ รีสตาร์ทเซิร์ฟเวอร์` (เมื่อขึ้นกล่องแดง) (→ 9.8) |
