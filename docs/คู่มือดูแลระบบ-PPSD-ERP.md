## 1. ภาพรวม: ระบบนี้ประกอบด้วยอะไร

```
 มือถือ / คอมพนักงาน ──(Wi-Fi ออฟฟิศ หรือ ลิงก์ https)──►  เครื่องเซิร์ฟเวอร์ (ออฟฟิศราชบุรี)
                                                          C:\ppsd-erp   พอร์ต 3001
 LINE (บอท PPSD Assistant) ──(ลิงก์สาธารณะอัตโนมัติ)───►     ├─ โปรแกรม ERP (Node.js)
                                                          ├─ ฐานข้อมูล server\data\ppsd.sqlite
 Claude API (AI อ่านเอกสาร) ◄──────────────────────────     └─ ไฟล์แนบ  server\data\files
 GitHub ppsd/ppsd.home (เก็บโค้ด) ◄── git push ─────────
```

| ส่วน | อยู่ที่ไหน | หมายเหตุ |
|---|---|---|
| เครื่องเซิร์ฟเวอร์ | ออฟฟิศราชบุรี, IP วงแลน `192.168.1.91` | ต้องเปิดและล็อกอินค้างไว้ตลอด |
| ที่อยู่เข้าใช้ (ในออฟฟิศ) | `http://192.168.1.91:3001` | บนเครื่องเซิร์ฟเวอร์เองใช้ `http://localhost:3001` |
| ข้อมูลทั้งหมด | `C:\ppsd-erp\server\data\` | **หัวใจของบริษัท** — หายคือหายหมด |
| โค้ดโปรแกรม | `C:\ppsd-erp` + GitHub `ppsd/ppsd.home` | แก้โค้ดผ่าน Claude |
| ตัวเปิดเซิร์ฟเวอร์ | `run-server.bat` (เปิดเองตอนล็อกอินเครื่อง) | ถ้าโปรแกรมล่ม จะเปิดใหม่เองใน 5 วินาที |

**สาขากรุงเทพ / หน้างาน** ใช้ระบบผ่านอินเทอร์เน็ตมาที่เครื่องราชบุรีเครื่องเดียว → ไฟดับหรือเน็ตล่มที่ราชบุรี = ทุกสาขาใช้ไม่ได้

## 2. สิ่งที่ต้องรับมอบ (บัญชีและรหัส)

> ⚠️ **ห้ามจดรหัสลงในเอกสารนี้หรือไฟล์ใดในโฟลเดอร์ `C:\ppsd-erp`** (ไฟล์พวกนี้ขึ้น GitHub)
> ให้เก็บใน **คลังรหัสผ่านบริษัท (Vault)** ในระบบ ERP หรือซองปิดผนึก

เช็คลิสต์ตอนรับมอบงาน — ติ๊กเมื่อได้รับและทดสอบเข้าได้จริงแล้ว:

| ☐ | ผู้ใช้ ERP บทบาท **admin** ของตัวเอง | ตั้งค่าระบบ | เข้าหน้า "ผู้ใช้งาน" ได้ |
| ☐ | รหัสผ่านหลักของ Vault | เปิดคลังรหัสผ่าน | **ลืม = กู้ไม่ได้** ต้องได้จาก CEO โดยตรง |

| ☐ | Router / อินเทอร์เน็ตออฟฟิศ | จอง IP เครื่องเซิร์ฟเวอร์ | — |

## 3. งานประจำ

### ทุกวัน (1 นาที)
- เปิดหน้า **หน้าสรุป** ใน ERP → ดูแถบสุขภาพระบบ
  - `สำรองนอกเครื่องปกติ` ต้องเป็นสีเขียว
  - ถ้าขึ้น 🔔 "ยังไม่มีสำรองข้อมูลล่าสุด" หรือ "สำรองนอกเครื่องล้มเหลว" → ดู [ข้อ 5](#5-สำรองและกู้คืนข้อมูล)

### ทุกสัปดาห์
- ดูท้ายเมนูซ้ายว่า **ไม่มีกล่องแดง** "อัปเดตโค้ดแล้ว แต่เซิร์ฟเวอร์ยังรันตัวเก่า"
- ดูว่าไดรฟ์สำรองนอกเครื่อง (External / OneDrive) ยังเสียบ / ซิงก์อยู่

### ทุกเดือน
- ดู **ค่าใช้จ่าย AI ในระบบ** (หน้า ผู้ใช้งาน) ว่าฟีเจอร์ไหนใช้เยอะผิดปกติ แล้วเข้า console.anthropic.com ดูยอดเงินคงเหลือ (เงินหมด = ฟีเจอร์ AI และการอ่านข้อความ LINE หยุดทำงาน)
- ดูโควตาข้อความ LINE (แพ็กเกจฟรี 200 ข้อความ/เดือน)
- ก๊อปโฟลเดอร์ `C:\ppsd-erp\server\data` ทั้งโฟลเดอร์ใส่ไดรฟ์แยกอีก 1 ชุด เก็บนอกออฟฟิศ
- Windows Update: ให้ทำ **นอกเวลางาน** เพราะเครื่องจะรีสตาร์ต (หลังรีสตาร์ตต้องล็อกอินเครื่อง ระบบถึงจะเปิดเอง)

## 4. แก้ปัญหาตามอาการ

### 4.1 ทุกคนเข้าระบบไม่ได้ (หน้าเว็บไม่ขึ้น)
1. ไปที่เครื่องเซิร์ฟเวอร์ — เครื่องเปิดอยู่ไหม? ล็อกอินอยู่ไหม? (ถ้าไฟดับ ต้องเปิดเครื่องและ **ล็อกอิน** ก่อน)
2. มีหน้าต่างดำชื่อ **"PPSD ERP Server (running - do not close)"** ไหม?
   - ไม่มี → ดับเบิลคลิก `C:\ppsd-erp\run-server.bat` แล้วรอ 20 วินาที
   - มี แต่ขึ้นข้อความ error ซ้ำๆ → ถ่ายรูปหน้าจอ ส่งให้ Claude ดู (ดูข้อ 4.8)
3. บนเครื่องเซิร์ฟเวอร์ เปิดเบราว์เซอร์ `http://localhost:3001`
   - เข้าได้ แต่เครื่องอื่นเข้าไม่ได้ → ไปข้อ 4.2
   - เข้าไม่ได้ → ไปข้อ 4.8

### 4.2 เครื่องเซิร์ฟเวอร์เข้าได้ แต่มือถือ/เครื่องอื่นในออฟฟิศเข้าไม่ได้
- อยู่ Wi-Fi วงเดียวกับเซิร์ฟเวอร์ไหม?
- IP เครื่องเซิร์ฟเวอร์เปลี่ยนไหม? (ดูบรรทัด `มือถือ/เครื่องอื่น: http://192.168.x.x:3001` ในหน้าต่างเซิร์ฟเวอร์) — ถ้าเปลี่ยนบ่อย ให้จอง IP ที่ router (DHCP Reservation)
- Firewall: คลิกขวา `allow-network.bat` → **Run as administrator** (ทำครั้งเดียว)
  - ไฟล์นี้ลบกฎ **"Node.js JavaScript Runtime" ที่ตั้งเป็นบล็อก** ให้ด้วย (เกิดเมื่อมีคนกด Cancel ตอน Windows ถามสิทธิ์ครั้งแรก — กฎบล็อกชนะกฎอนุญาต) · เคยเจอจริง 6 พ.ย. 69
  - ถ้ากดแล้วไม่มีผล (หน้าต่างขออนุญาตไม่ขึ้น/กด No) ทำมือ: Start → `powershell` → คลิกขวา Run as administrator → วาง
    `netsh advfirewall firewall delete rule name="Node.js JavaScript Runtime"` แล้ว
    `netsh advfirewall firewall add rule name="PPSD ERP 3001" dir=in action=allow protocol=TCP localport=3001 profile=private,domain`
  - **มือถือใช้ GPS ไม่ได้ (ลิงก์ http)** → เมนู LINE → การเชื่อมต่อ → ☑ "เปิดหน้าเช็คอินพนักงานผ่านลิงก์นี้" (ตั้งค่า `tunnel_checkin`) → ลิงก์ `https://…trycloudflare.com/checkin` · ด่านลิงก์สาธารณะเปิดเฉพาะ GET /checkin, GET /api/kiosk/employees, GET /api/settings/attendance, POST /api/kiosk/punch, POST /api/kiosk/location · ลิงก์เปลี่ยนเมื่อรีบูต → แอดมินคัดลอกลิงก์ใหม่ส่งพนักงานเอง (ไม่มีการส่ง LINE อัตโนมัติแล้ว)
  - ทดสอบจากมือถือ: เปิด `http://192.168.1.91:3001/api/version` — ขึ้นตัวหนังสือ = ถึงเซิร์ฟเวอร์แล้ว · ค้าง = ยังโดนกั้น (ไฟร์วอลล์ หรือ Wi-Fi แยกอุปกรณ์/Wi-Fi แขก)

### 4.3 เมนูซ้ายขึ้นกล่องแดง "อัปเดตโค้ดแล้ว แต่เซิร์ฟเวอร์ยังรันตัวเก่า"
- admin กด `↻ รีสตาร์ทเซิร์ฟเวอร์` ที่ท้ายเมนู → ระบบหยุด ~10 วินาที แล้วกลับมาเอง
- ถ้าไม่กลับมา: ปิดหน้าต่าง "PPSD ERP Server" ทุกอัน → ดับเบิลคลิก `run-server.bat`

### 4.4 บอท LINE ไม่ตอบ / ไม่ส่งแจ้งเตือน
0. **โหมดทดสอบลืมปิดหรือเปล่า?** เมนู **ส่วนกลางบริษัท → LINE** ถ้ามีแถบส้ม "🧪 โหมดทดสอบเปิดอยู่" → กด `ปิดโหมดทดสอบ` (ตอนเปิดอยู่ บอทคุยกับคนทดสอบคนเดียว) · ปิดแล้ว ใบที่ค้างอยู่ก่อนหน้า กด **📨 ส่งการ์ดใบที่ค้างอนุมัติอีกครั้ง** ในหน้าเดียวกัน (การ์ดที่ระงับไว้ไม่ส่งย้อนหลังเอง)
1. เมนู **ส่วนกลางบริษัท → LINE** → แท็บ **🔌 การเชื่อมต่อ / สรุปเช้า** → ดูสถานะที่ขึ้น
   - `no_token` → ยังไม่ได้ใส่ Channel access token
   - โควตาหมด → รอเดือนใหม่ หรืออัปแพ็กเกจที่ LINE Official Account Manager
2. ดูว่า **ลิงก์สาธารณะอัตโนมัติ** เปิดอยู่และมีลิงก์ขึ้น → ถ้าไม่มี กด `↻ เปิดลิงก์ใหม่`
3. กด `📨 ส่งทดสอบ`
4. คนที่บอทไม่ตอบ: เขาผูก LINE แล้วหรือยัง (คอลัมน์ LINE ในตารางผู้ใช้) และ **ไม่ใช่พนักงานที่ลาออก** (คนลาออกถูกตัดสิทธิ์บอทอัตโนมัติ)
5. บอทตอบแต่ "อ่านข้อความไม่เข้าใจ" ทั้งหมด → มักเป็นเรื่อง AI ดูข้อ 4.5

### 4.5 ฟีเจอร์ AI ไม่ทำงาน (อ่านใบเสนอราคา, ตรวจเอกสาร, ถอดแบบ ฯลฯ)
1. หน้า **ผู้ใช้งาน** → **🤖 ตั้งค่า AI** → `🧪 ทดสอบ`
2. ไม่ผ่าน → เข้า console.anthropic.com ดูว่า **เงินในบัญชีหมด** หรือกุญแจถูกยกเลิกไหม
3. สร้างกุญแจใหม่ (`sk-ant-...`) → วางในหน้าตั้งค่า AI → `บันทึก` → `🧪 ทดสอบ`

### 4.6 พนักงานลืม PIN
- เขากด `ลืม PIN?` ที่หน้าเข้าสู่ระบบ → admin เห็นใน **ผู้ใช้งาน → คำขอรีเซ็ต PIN**
- **ยืนยันตัวตนก่อน** (เจอหน้า/โทร) → `อนุมัติ + ตั้ง PIN ชั่วคราว` → บอก PIN ชั่วคราว

### 4.7 พนักงานเข้าใหม่ / ลาออก
- **เข้าใหม่:** ผู้ใช้งาน → `+ เพิ่มผู้ใช้` → ประเภท **พนักงาน** → เลือกบทบาทให้น้อยที่สุดที่พอทำงาน → ให้เขาผูก LINE
- **เจ้าของ / ผู้ดูแลภายนอก** (ไม่รับเงินเดือนผ่านระบบ): เลือกประเภท **บัญชีระบบ** → ไม่ขึ้นใน HR / เงินเดือน / ลงเวลา
- **ลาออก:** ตั้งสถานะพนักงานใน HR เป็นลาออก + ผู้ใช้งาน → `ปิดใช้งาน` (อย่าลบ — ประวัติเอกสารจะยังผูกชื่อเขาอยู่)
- ถ้าเขาเคยรู้รหัสใน Vault → เปลี่ยนรหัสของระบบนั้นๆ

### 4.8 ไม่รู้ว่าเป็นอะไร / error แปลกๆ
เปิด Claude ในโฟลเดอร์ `C:\ppsd-erp` แล้วพิมพ์ (ดูแบบฟอร์มเต็มใน `docs/คู่มือสั่งงาน-Claude.md`):

```
ระบบมีปัญหา: <อาการ เช่น เปิดหน้าเว็บไม่ขึ้นทั้งออฟฟิศ ตั้งแต่ 9 โมง>
ลองทำไปแล้ว: <เช่น เปิด run-server.bat ใหม่แล้ว>
ช่วยตรวจหาสาเหตุก่อน ยังไม่ต้องแก้อะไร แล้วอธิบายให้ฟังแบบง่ายๆ
```
แนบรูปหน้าจอ error ด้วยถ้ามี

## 5. สำรองและกู้คืนข้อมูล

### ระบบสำรองที่มีอยู่
| ชนิด | ทำงานยังไง | เก็บที่ |
|---|---|---|
| อัตโนมัติรายวัน | ระบบทำเอง เก็บ 30 วัน + วันที่ 1 ของเดือนย้อนหลัง 12 เดือน | `server\data\backups` (ในเครื่องเดียวกัน — **ไม่พอ**) |
| สำรองนอกเครื่อง | ระบบก๊อปไปโฟลเดอร์ที่ตั้งไว้ | ตั้งที่ ผู้ใช้งาน → 💾 สำรองนอกเครื่อง (เช่น `E:\PPSD-Backup` หรือ OneDrive) |
| ด้วยมือ | กด `สำรองข้อมูล` ได้ไฟล์ `.sqlite` | ที่ที่เราเก็บเอง |

> ⚠️ ไฟล์ `.sqlite` มีเฉพาะ **ข้อมูลในตาราง** — ไฟล์แนบ (สัญญา, รูป, แบบบ้าน) อยู่ที่ `server\data\files`
> การก๊อปเก็บเองรายเดือน ให้ก๊อป **ทั้งโฟลเดอร์ `server\data`**

### กู้คืน
- **มีคนลบผิดแค่บางรายการ** → ใช้ `🔍 ดูข้อมูล` ของวันก่อนลบ → กรอง "ถูกลบไปแล้ว" → กู้คืนเฉพาะรายการนั้น (ข้อมูลอื่นไม่กระทบ) — **ลองวิธีนี้ก่อนเสมอ**
- กู้ทั้งชุด: ผู้ใช้งาน → สำรอง/กู้คืน → เลือกชุดจากรายการอัตโนมัติ → `กู้คืนชุดนี้` (ระบบสำรองสถานะปัจจุบันให้ก่อนเสมอ)
- **ข้อมูลหลังเวลาสำรองชุดนั้นจะหาย** → ก่อนกู้คืน แจ้งทุกคนหยุดคีย์ และคิดให้ดีว่าจำเป็นจริงไหม
- ถ้าไม่แน่ใจ ให้ถาม Claude ก่อน: "ข้อมูล X หายไป ช่วยหาว่ากู้คืนเฉพาะส่วนนี้ได้ไหม โดยไม่กระทบข้อมูลอื่น"

### ถ้าเครื่องเซิร์ฟเวอร์พัง (ย้ายเครื่องใหม่)
1. ติดตั้ง Node.js (nodejs.org ปุ่ม LTS) และ Git (git-scm.com) บนเครื่องใหม่
2. เปิด Command Prompt: `git clone https://github.com/ppsd/ppsd.home C:\ppsd-erp`
3. ก๊อปโฟลเดอร์ `server\data` จากที่สำรองไว้ มาวางที่ `C:\ppsd-erp\server\data`
4. ดับเบิลคลิก `install-autostart.bat` แล้ว `allow-network.bat` (Run as administrator)
5. แจ้ง IP ใหม่ให้ทุกคน / ตั้ง Tailscale ใหม่
6. ตรวจ LINE (เมนู LINE → `📨 ส่งทดสอบ`) และ AI (ผู้ใช้งาน → `🧪 ทดสอบ`) ว่ายังผ่าน

## 6. อัปเดตระบบ / แก้ไขโปรแกรม

### เวลาให้ Claude แก้โปรแกรม
Claude ถูกตั้งไว้ (ในไฟล์ `CLAUDE.md`) ให้ทำเองครบหลังแก้เสร็จ: บันทึก (commit) → build → รีสตาร์ตเซิร์ฟเวอร์ → ส่งขึ้น GitHub
ผู้ใช้จะเห็นของใหม่หลังกด F5 · ระหว่างรีสตาร์ต ทุกคนใช้งานไม่ได้ ~10 วินาที

> 💡 ถ้าจะแก้เรื่องใหญ่ ให้สั่งทำ **ช่วงเย็น / นอกเวลางาน** และบอก Claude ว่า "ยังไม่ต้อง build ขึ้นจริง ให้ฉันดูก่อน"

### branch คืออะไร (รู้ไว้พอ)
- โค้ดแบ่งเป็น "สาย" (branch): `master` = สายหลัก, `dev/...` = สายที่กำลังทำงาน (ตอนนี้ `dev/combined-3`)
- งานใหม่ๆ อยู่ใน `dev/...` ก่อน เมื่อมั่นใจแล้วค่อยรวม (merge) เข้า `master`
- สั่ง Claude ได้: "สรุปให้ฟังว่า branch นี้ต่างจาก master ยังไง แล้วถ้ารวมเข้า master มีความเสี่ยงอะไร"

### `update.bat`
ใช้ดึงโค้ดจาก GitHub สาย **master** มาติดตั้ง — **ถ้างานล่าสุดยังอยู่ใน branch dev จะไม่ได้ของใหม่**
บนเครื่องที่ Claude แก้โค้ดโดยตรง (เครื่องเซิร์ฟเวอร์) ไม่ต้องใช้ไฟล์นี้

### ถ้าอัปเดตแล้วพัง
บอก Claude: "หลังแก้เมื่อกี้ หน้า X พัง อาการคือ ... ช่วยย้อนการแก้ล่าสุดกลับไปก่อน แล้วค่อยหาสาเหตุ"
(git เก็บประวัติทุกครั้ง ย้อนกลับได้เสมอ ข้อมูลใน `server\data` ไม่ได้ถูกย้อนด้วย)

## 8. สิ่งที่ห้ามทำเด็ดขาด

1. ❌ ลบ / ย้าย / เปลี่ยนชื่อโฟลเดอร์ `server\data`
2. ❌ ปิดหน้าต่าง "PPSD ERP Server" ในเวลางาน (ทุกคนหลุด)
3. ❌ ส่งไฟล์ `.env`, `secret.key`, `ppsd.sqlite` ทางแชท/อีเมล หรืออัปขึ้นที่สาธารณะ
4. ❌ กดอนุญาต (Allow) คำสั่งที่ Claude ขอ ถ้าไม่เข้าใจว่ามันจะทำอะไร — ให้ถามก่อน

6. ❌ ใช้ `tailscale funnel` (เปิดสู่อินเทอร์เน็ตทั้งโลก) — ใช้ `tailscale serve` เท่านั้น
7. ❌ ลบผู้ใช้ admin จนเหลือไม่ถึง 1 คน / ลืมรหัสผ่านหลัก Vault

## เว็บลูกค้าบน Cloudflare (ppsd-web.pages.dev)
เว็บลูกค้าตัวอย่าง (`public/web/`) ขึ้นที่ Cloudflare Pages โปรเจกต์ `ppsd-web` แยกจากเซิร์ฟเวอร์ ERP

**อัปเดตเว็บ:** `npm run build` แล้ว `node scripts/deploy-web.mjs` (ใช้ wrangler 4.20.0 เท่านั้น — รุ่นใหม่จะพยายามย้ายไป Workers)

**ปุ่ม "ออกแบบบ้านให้ดูเลย" บน Cloudflare** — ตัวเรียก AI อยู่ที่ `cloudflare/ppsd-web/functions/` ใช้กติกาจัดผังห้องจาก `server/house-concept.js` (คัดลอกตอนอัปเดตเว็บ)
- ใช้กุญแจเดียวกับ ERP ได้ (เจ้าของเลือก 11 พ.ย. 69): คัดลอกจาก ERP หน้าผู้ใช้งาน → ตั้งค่า AI → `👁 ดู/คัดลอกกุญแจ` (ใส่ PIN) · ถ้าเปลี่ยนกุญแจใน ERP ต้องเปลี่ยนใน Cloudflare ด้วย
- ตั้งกุญแจ AI: เข้า dash.cloudflare.com → Workers & Pages → `ppsd-web` → Settings → Variables and Secrets → Add → ชนิด **Secret** ชื่อ `ANTHROPIC_API_KEY` ใส่กุญแจ → Save → แล้วอัปเดตเว็บ 1 ครั้ง (หรือกด Retry deployment ล่าสุด) ให้ค่าใหม่มีผล
- แนะนำสร้างกุญแจแยกสำหรับเว็บนี้ที่ console.anthropic.com และตั้งเพดานค่าใช้จ่ายต่อเดือนของ workspace นั้น — ถ้าหลุดหรือโดนใช้เกิน เสียหายไม่เกินเพดาน และลบกุญแจทิ้งได้โดยไม่กระทบ ERP
- ค่าที่ปรับได้ (ชนิด Text ในหน้าเดียวกัน): `PER_IP` ครั้งต่อเครื่องต่อวัน (ค่าเริ่ม 3) · `PER_DAY` ครั้งรวมต่อวัน (40) · `AI_MODEL` (claude-sonnet-5-5) · ปิดปุ่มชั่วคราว: `HOUSE_OFF` = 1
- ตัวนับจำนวนครั้งอยู่ใน KV `ppsd-web-limits` (ผูกใน `cloudflare/ppsd-web/wrangler.toml`)
- แบบที่ลูกค้าสร้างบน Cloudflare ยังไม่เข้า ERP · ค่า AI ดูได้ที่ console.anthropic.com (ไม่อยู่ในหน้าสรุปค่า AI ของ ERP)
