# PPSD Construction ERP

ระบบ ERP ภายในสำหรับบริษัทรับสร้างบ้าน **PPSD Construction** — ภาษาไทยทั้งหมด สกุลเงินบาท
ออกแบบสำหรับใช้บนเดสก์ท็อปในออฟฟิศเป็นหลัก รองรับแท็บเล็ต/มือถือ

สร้างจากดีไซน์ต้นแบบ Claude Design (ทิศทางสี **C · สเลทการเงิน**, ฟอนต์ **Kanit**, ความหนาแน่นแบบแน่น)

## เทคโนโลยี

- **Frontend:** React 18 + TypeScript + Vite (inline style ตามต้นแบบ + `src/index.css`)
- **Backend:** Node + Express + **SQLite** (better-sqlite3) — REST API จริง มีฐานข้อมูล + เซ็ดข้อมูลเริ่มต้น
- **Auth:** ล็อกอินด้วย username + PIN → bearer token, บังคับสิทธิ์ตามบทบาทฝั่งเซิร์ฟเวอร์

## เริ่มใช้งาน

```bash
npm install      # ติดตั้ง dependencies (รวม backend)
npm run dev      # โหมดพัฒนา: API (:3001) + เว็บ (:5173) — เปิด http://localhost:5173
npm start        # โหมดใช้งานจริง: build + เสิร์ฟทั้งเว็บ+API บนพอร์ตเดียว (:3001)
npm run build    # type-check + build frontend ไปที่ dist/
```

### Windows: เปิดง่ายๆ ด้วย start.bat

ดับเบิลคลิก **`start.bat`** ได้เลย — มันจะติดตั้ง (ครั้งแรก) แล้วรัน `npm start` ให้ และเปิดเบราว์เซอร์อัตโนมัติ
(ใช้ผ่าน cmd จึงไม่ติดปัญหา PowerShell บล็อกสคริปต์)

ถ้าจะพิมพ์คำสั่งเองบน Windows แนะนำใช้ **Command Prompt (cmd)** ไม่ใช่ PowerShell:
พิมพ์ `cmd` ที่ address bar ของโฟลเดอร์ → Enter → แล้วพิมพ์ `npm install` ตามด้วย `npm start`
(ถ้าจะใช้ PowerShell ให้รัน `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` ครั้งเดียวก่อน)

### เปิดจากมือถือ / เครื่องอื่นในออฟฟิศ (LAN)

ใช้ `npm start` แล้วเซิร์ฟเวอร์จะเปิดบนทุก network interface และพิมพ์ที่อยู่ให้ เช่น:

```
PPSD ERP — เปิดใช้งานแล้ว
  เครื่องนี้:        http://localhost:3001
  มือถือ/เครื่องอื่น: http://192.168.1.45:3001   ← เปิดที่อยู่นี้บนมือถือ
```

มือถือ/เครื่องอื่นต้องอยู่ **Wi-Fi/เครือข่ายเดียวกัน** แล้วเปิด URL ที่ขึ้นต้นด้วย IP นั้น
(ถ้าเข้าไม่ได้ ให้เปิด firewall ของเครื่องที่รันให้ผ่านพอร์ต 3001 — ดูหัวข้อแก้ปัญหาด้านล่าง)

> โหมด `npm run dev` ก็เปิด LAN ได้เช่นกัน (Vite ตั้ง `host: true`) แต่แนะนำ `npm start`
> สำหรับใช้งานจริงเพราะรวมเป็นพอร์ตเดียว เร็วกว่า และไม่ต้องเปิด 2 พอร์ต

> Vite proxy `/api` → `http://localhost:3001` ให้อัตโนมัติ ฐานข้อมูลถูกสร้าง+เซ็ดที่
> `server/data/ppsd.sqlite` ครั้งแรกที่รัน (ลบไฟล์นี้เพื่อรีเซ็ตข้อมูล)

### บัญชีเข้าระบบ

เริ่มต้นเป็นระบบเปล่า มีผู้ใช้ **ผู้ดูแลคนเดียว**:

| ชื่อ | username / PIN | บทบาท |
|---|---|---|
| ธวัช วรรณสุข | `thawat` / `1234` | ผู้ดูแล (สิทธิ์ทั้งหมด) |

> เพิ่มผู้ใช้/บ้าน/PR ฯลฯ เองได้ในระบบ — ข้อมูลตัวอย่างถูกล้างออกหมดแล้ว

### ฟีเจอร์เพิ่มเติม

- **ลูกค้า (CRM)** — รายชื่อลูกค้า + ประวัติการติดต่อ (โทร/Line/นัดพบ)
- **รายงาน + กราฟ** — กำไรรายโครงการ, ต้นทุนแยกหมวด (กราฟ SVG) — เฉพาะผู้ดูแล/บัญชี
- **แผนงาน (Gantt)** — ไทม์ไลน์ก่อสร้าง + อัปเดต % ความคืบหน้า
- **เอกสารขาย** — ใบเสนอราคา / ใบแจ้งหนี้ / ใบเสร็จ (คำนวณ VAT + พิมพ์)
- **อัปโหลดไฟล์จริง** — แนบแบบบ้าน/สัญญา/รูป ในหน้ารายละเอียดบ้าน (ดาวน์โหลด/ลบได้)
- **ส่งออก Excel** — ปุ่มส่งออก CSV (เปิดใน Excel ได้, รองรับไทย) ในหน้ารายการ
- **แจ้งเตือน** — กระดิ่งมุมขวาบน รวมงวดเลยกำหนด/รอเก็บ, PR/OT รออนุมัติ → กดไปหน้าที่เกี่ยว

### ลายเซ็น + อนุมัติ PR

- แต่ละผู้ใช้ **อัปโหลดลายเซ็นของตัวเอง** ได้ที่หน้า **ผู้ใช้งาน** (คอลัมน์ "ลายเซ็น")
- สร้างใบขอซื้อ (**+ ขอซื้อ (PR)** ในหน้าจัดซื้อ/จ่าย) → ลายเซ็น "ผู้ขอ" ถูกแนบอัตโนมัติ
- กด **อนุมัติ** → ลายเซ็น "ผู้อนุมัติ" ถูกแนบ → กด **ใบอนุมัติ** เพื่อดู/พิมพ์เอกสารที่มี
  **ลายเซ็นทั้งผู้ขอและผู้อนุมัติ**

## Backend / API

```
server/
  index.js     Express app + REST routes (+ บังคับสิทธิ์ต่อ route)
  db.js        SQLite schema + seed
  seed.js      ข้อมูลตั้งต้น
  auth.js      login / token / requireRole middleware
  efiling.js   ตัวสร้างไฟล์ e-Filing (ภงด.1/3/53, ภพ.30, ประกันสังคม)
```

- **บังคับสิทธิ์ฝั่งเซิร์ฟเวอร์:** เงินเดือน/จัดซื้อ/ภาษี = เฉพาะ admin+accounting,
  จัดการผู้ใช้ = admin, เขียนข้อมูลปฏิบัติการ = ทุกบทบาทยกเว้น viewer (กันที่ API จริง ตอบ 403)
- **ฟอร์มบันทึกจริง:** เพิ่มบ้าน/งวดงาน/ปัญหา/รายจ่าย/ผู้ใช้, อนุมัติ OT, อนุมัติ/ปฏิเสธ PR,
  เปลี่ยนบทบาทผู้ใช้ — บันทึกลง SQLite แล้วรายการรีเฟรชทันที
- **e-Filing:** ปุ่มดาวน์โหลดไฟล์อัปโหลด (text/CSV มี BOM ภาษาไทย) — *สร้างไฟล์ให้ ไม่ได้ยื่นแทน*

## โครงสร้างหน้าจอที่ทำเสร็จแล้ว

- **หน้าสรุป (Dashboard)** — การ์ดสถิติ 8 ใบ, แผงเตือน 3 ชุด (งวดเลยกำหนด · เงินที่ควรไปเก็บ ·
  เงินล่วงหน้าช่างค้างหัก), ภาพรวมแต่ละโครงการ, ความคืบหน้าบ้านรายหลัง, ตารางปัญหาหน้างานค้าง
- **บ้าน (House list)** — การ์ดบ้าน + ค้นหาสด + กรองตามสถานะ (กดใช้งานได้จริง)
- **รายละเอียดบ้าน (House detail)** — แถบสรุปการเงิน 5 ช่อง, ข้อมูลบ้าน, ไฟล์, และแท็บ
  **งวดงาน / ช่าง-ผู้รับเหมา / ปัญหา / รายจ่าย**
- **Modal** เพิ่มบ้าน / แก้ไขข้อมูลบ้าน / เพิ่มงวดงาน
- **งวดงานรวม (Installments)** — การ์ดสรุป + ค้นหา/กรอง + ตารางงวดงานทุกหลัง
- **จัดซื้อ / จ่าย (Procurement)** — 6 แท็บ: ใบขอซื้อ(PR) · ใบสั่งซื้อ(PO) · จ่ายเงิน-หัก ณ ที่จ่าย ·
  ยอดค้างจ่าย · ผู้ขาย/ผู้รับเหมา · รายงานภาษี (ภงด.3/53 + ภาษีซื้อ)
- **บุคลากร / HR** — 6 แท็บ: พนักงาน · เงินเดือน(สลิป+ประกันสังคม) · OT(รออนุมัติ/อนุมัติ) ·
  ลงเวลา · ลางาน · ภงด.1/กท.20
- **ลงเวลา (kiosk)** — นาฬิกาเรียลไทม์ + เลือกชื่อ + ใส่ PIN + ปุ่มใหญ่ เข้างาน/ออกงาน (ตรวจ PIN จริง)
- **เอกสารพิมพ์** — สลิปเงินเดือน · ใบ 50 ทวิ · ใบสั่งซื้อ (หัวบริษัท + ปุ่มพิมพ์จริงผ่าน `window.print`)
- **ปัญหาหน้างาน (รวมทุกหลัง)** — การ์ดสรุป + กรองความเร่งด่วน + ตารางปัญหาทุกหลัง
- **รายจ่าย (รวมทุกหลัง)** — สรุปตามหมวด + ค้นหา/กรอง + ตาราง + ยอดรวม
- **ผู้ใช้งาน + ระบบสิทธิ์ 4 ระดับ** — การ์ดบทบาท, รายชื่อผู้ใช้, ตารางสิทธิ์ (matrix)
- **ระบบสิทธิ์ตามบทบาท** — สลับบทบาทได้ที่มุมขวาบน (ผู้ดูแล/บัญชี/หน้างาน/ดูอย่างเดียว);
  ข้อมูล **เงินเดือนเห็นเฉพาะผู้ดูแล+บัญชี** (บทบาทอื่นเห็นหน้าจอ "ไม่มีสิทธิ์")

> ครบทั้ง 9 เมนูแล้ว ไม่มีหน้า placeholder เหลือ

## โครงสร้างโค้ด

```
src/
  App.tsx              เชลล์หลัก + การจัดการ state/การนำทาง + นิยาม modal
  data.ts              ข้อมูลตัวอย่าง + helper สี/สถานะ (พอร์ตจากต้นแบบ)
  index.css            global style, keyframe, hover/focus helper
  components/
    Sidebar.tsx        เมนูซ้าย 9 หมวด + แบดจ์เตือน
    Topbar.tsx         แถบบน: breadcrumb, ค้นหา, ผู้ใช้/บทบาท
    Dashboard.tsx      หน้าสรุป
    HouseList.tsx      รายการบ้าน + ค้นหา/กรอง
    HouseDetail.tsx    รายละเอียดบ้าน + 4 แท็บ
    Placeholder.tsx    หน้าหมวดที่ยังไม่ลงรายละเอียด
    Modal.tsx          ฟอร์ม modal
    Icon.tsx           SVG icon helper
  assets.ts            โลโก้แบรนด์ (ตราปมทอง + โลโก้เต็ม) inline เป็น base64 data URI
```

> โลโก้ฝังเป็น data URI ในโค้ดเลย (ไม่มีไฟล์ binary ในรีโป) — `PPSD_MARK` ใช้ในแถบเมนู/favicon
> ส่วน `PPSD_LOGO_FULL` เก็บไว้สำหรับหัวเอกสารพิมพ์ในอนาคต

## สิ่งที่อยู่ในลำดับถัดไป

1. เปลี่ยน token store เป็น JWT + เก็บรหัสผ่านแบบ hash (ตอนนี้ใช้ PIN + token ใน memory)
2. ย้าย SQLite → PostgreSQL/MySQL เมื่อขึ้น production + migration
3. อัปโหลดไฟล์จริง (แบบบ้าน/สัญญา/รูปหน้างาน) + จัดเก็บ
4. เชื่อมไฟล์ e-Filing เข้ารูปแบบ RDePrep/e-Filing ของกรมสรรพากรแบบเป๊ะตามสเปกล่าสุด
